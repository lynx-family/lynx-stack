# @lynx-js/rspeedy

The programmatic API of `@lynx-js/rspeedy`: load a config, create an Rspeedy instance and drive builds from a script instead of the CLI.

## Functions \{#functions\}

### `createRspeedy()` \{#createrspeedy\}

```ts
createRspeedy(options: CreateRspeedyOptions): Promise<RspeedyInstance>
```

The `createRspeedy` method can let you create a Rspeedy instance and you can customize the build or development process in Node.js Runtime.

```ts
import { createRspeedy } from '@lynx-js/rspeedy'

void async function () {
  const rspeedy = await createRspeedy({})
  await rspeedy.build()
}()
```

**Returns:** `Promise<`[`RspeedyInstance`](#rspeedyinstance)`>` — - Rspeedy instance.

### `mergeRspeedyConfig()` \{#mergerspeedyconfig\}

```ts
mergeRspeedyConfig(configs: Config[]): Config
```

Merge multiple Rspeedy configuration objects.

This is actually an alias of [mergeRsbuildConfig](https://rsbuild.rs/api/javascript-api/core#mergersbuildconfig).

```ts
import { mergeRspeedyConfig } from '@lynx-js/rspeedy';

const config1 = {
  dev: {
    writeToDisk: false,
  },
};
const config2 = {
  dev: {
    writeToDisk: true,
  },
};

const mergedConfig = mergeRspeedyConfig(config1, config2);

console.log(mergedConfig); // { dev: { writeToDisk: true } }
```

| Parameters | Type | Description |
| --- | --- | --- |
| `configs` | `Config[]` | The Rspeedy configuration objects to merge. |

**Returns:** `Config` — The merged Rspeedy configuration object.
