Creates a native Lynx library: native modules, Node-API native modules, elements and services for Android, iOS, HarmonyOS and Lynxtron.

## Usage

```bash
npm create lynx-library
```

The prompts ask which features and platforms to generate. See the [README](https://github.com/lynx-family/lynx-stack/tree/main/packages/lynx/create-lynx-library) for the non-interactive flags.
