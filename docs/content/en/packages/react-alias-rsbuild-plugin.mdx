Aliases `react` and `react-dom` imports to `@lynx-js/react`, so libraries written against React resolve to the ReactLynx runtime.

## Installation

import { PackageManagerTabs } from '@rspress/core/theme';

<PackageManagerTabs command="add @lynx-js/react-alias-rsbuild-plugin -D" />

## Usage

You don't need to register it: [`pluginReactLynx`](/packages/react-rsbuild-plugin) applies it for you.
