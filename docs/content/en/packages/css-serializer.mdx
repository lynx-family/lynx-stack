## Functions \{#functions\}

### `cssChunksToMap()` \{#csschunkstomap\}

```ts
cssChunksToMap(cssChunks: (string | CSSChunkAsset)[], plugins: Plugin[], enableCSSSelector: boolean): { contentMap: Map<number, string[]>; cssMap: Record<string, LynxStyleNode[]>; cssSource: Record<string, string> }
```

Convert CSS chunks into `cssMap` / `cssSource`.

`loc` fields remain in bundle CSS coordinates so they can be resolved later
via `main.css.map`.

`cssSource` intentionally keeps the historical `/cssId/<id>.css` shape.
