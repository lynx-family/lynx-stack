## Classes \{#classes\}

### `ReactWebpackPlugin` \{#reactwebpackplugin\}

ReactWebpackPlugin allows using ReactLynx with webpack

```js
// webpack.config.js
import { ReactWebpackPlugin } from '@lynx-js/react-webpack-plugin'
export default {
  plugins: [new ReactWebpackPlugin()],
}
```
