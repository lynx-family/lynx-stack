Prebuilt ReactLynx runtime bundles for external bundles, exposed as `@lynx-js/react-umd/dev` and `@lynx-js/react-umd/prod`.

## Usage

You don't need to reference it yourself: the `reactlynx` preset of [`pluginExternalBundle`](/packages/external-bundle-rsbuild-plugin) resolves one of the two entry points from `NODE_ENV`. When you build a component external bundle that depends on ReactLynx, turn on the same preset in [`defineExternalBundleRslibConfig`](/packages/lynx-bundle-rslib-config):

```ts title="rslib.config.ts"
import { defineExternalBundleRslibConfig } from '@lynx-js/lynx-bundle-rslib-config'
import { pluginReactLynx } from '@lynx-js/react-rsbuild-plugin'

export default defineExternalBundleRslibConfig({
  id: 'comp',
  source: {
    entry: {
      './components': './src/components/index.js',
    },
  },
  plugins: [pluginReactLynx()],
  output: {
    externalsPresets: {
      reactlynx: true,
    },
  },
})
```
