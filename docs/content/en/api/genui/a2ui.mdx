# `@lynx-js/genui/a2ui`

`@lynx-js/genui/a2ui` is the ReactLynx client runtime for [A2UI](https://a2ui.org/) v0.9. It takes the A2UI server-to-client messages your app receives, keeps them in a message store and renders the latest surface with trusted ReactLynx components. It does not call a model or own the transport: your app pushes the messages in. See the [A2UI guide](https://lynxjs.org/react/genui/a2ui) for a walkthrough.

```ts
import { A2UI, createMessageStore } from '@lynx-js/genui/a2ui';
```

The store, the React bindings, the built-in catalog and the basic functions are also available on their own from `@lynx-js/genui/a2ui/store`, `/react`, `/catalog` and `/functions`.

### `defineCatalog()` \{#definecatalog\}

```ts
function defineCatalog(inputs: readonly CatalogInput[]): Catalog
```

Build a catalog from a list of components, `[component, manifest]` pairs,
and/or function entries. Duplicate names within the same kind are rejected.
Function entries register their impls into `functionRegistry` immediately,
so any `executeFunctionCall` after `defineCatalog` can route to them.

```ts
import { Text, Button } from '@lynx-js/genui/a2ui';
import { defineCatalog, defineFunction } from '@lynx-js/genui/a2ui';
import { required } from '@lynx-js/genui/a2ui/functions';
import textManifest from '@lynx-js/genui/a2ui/catalog/Text/catalog.json'
  with { type: 'json' };

const catalog = defineCatalog([
  [Text, textManifest],
  Button,
  defineFunction(required),
]);
```

| Parameters | Type | Description |
| --- | --- | --- |
| `inputs` | `readonly `[`CatalogInput`](#cataloginput)`[]` |  |

### `MessageStore` \{#messagestore\}

A pure append-only buffer of raw protocol messages produced by the
developer's IO module. The store knows nothing about the v0.9 protocol —
it does not parse, process, or interpret messages. It only:

 1. Stores them in arrival order.
 2. Notifies subscribers when new ones land.
 3. Hands the current snapshot back via `getSnapshot()` (referentially
    stable between mutations — required by `useSyncExternalStore`).

Protocol-aware processing — surfaces, signals, resources, action
dispatch — is the responsibility of `<A2UI>` (the renderer component).
Developers who don't want to learn the protocol should use `<A2UI>`;
developers who do can run their own `MessageProcessor` against the
snapshot directly.

| Members | Type | Description |
| --- | --- | --- |
| <a id="messagestore-getsnapshot"></a>`getSnapshot` | `() => readonly `[`ServerToClientMessage`](#servertoclientmessage)`[]` | `useSyncExternalStore` getSnapshot contract — stable between pushes. |
| <a id="messagestore-subscribe"></a>`subscribe` | `(cb: () => void) => () => void` | `useSyncExternalStore` subscribe contract. |
| <a id="messagestore-clear"></a>`clear` | `clear(): void` | Reset the buffer. Notifies subscribers. |
| <a id="messagestore-push"></a>`push` | `push(message: ServerToClientMessage \| readonly ServerToClientMessage[]): void` | Append one or more raw messages to the buffer. Notifies subscribers once per call (batches a single array argument into a single notify). |
