# `@lynx-js/genui/openui`

`@lynx-js/genui/openui` is the ReactLynx client runtime for [OpenUI Lang](https://www.openui.com/docs/openui-lang/specification-v05) v0.5. It parses the OpenUI text an agent produces, evaluates its state and data operations, and renders the result with the component library you pass in. The agent only emits data: it can instantiate the components in that library and nothing else. See the [OpenUI guide](https://lynxjs.org/react/genui/openui) for a walkthrough.

```ts
import { OpenUiRenderer, createOpenUiLibrary } from '@lynx-js/genui/openui';
```

To leave out the built-in components you do not use, create the library from [`@lynx-js/genui/openui/explicit`](./openui-explicit) instead.
