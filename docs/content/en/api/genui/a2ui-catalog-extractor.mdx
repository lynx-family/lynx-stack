# `@lynx-js/genui/a2ui-catalog-extractor`

`@lynx-js/genui/a2ui-catalog-extractor` turns the TypeScript interfaces of your components, and their TypeDoc comments, into the A2UI catalog JSON an agent reads. It is the engine behind `genui a2ui generate catalog`; in scripts, prefer that command and use this entry point when you need the extraction in code.

```ts
import { extractCatalogComponents } from '@lynx-js/genui/a2ui-catalog-extractor';
```
