# `@lynx-js/genui/openui/prompt`

`@lynx-js/genui/openui/prompt` builds the system prompt that teaches a model to answer in OpenUI Lang with the components of your library. Use it on the agent side, next to the [`@lynx-js/genui/openui`](./openui) renderer in the app.

```ts
import { buildOpenUiSystemPrompt } from '@lynx-js/genui/openui/prompt';
```
