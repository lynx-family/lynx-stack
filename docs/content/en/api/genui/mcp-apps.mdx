# `@lynx-js/genui/mcp-apps`

`@lynx-js/genui/mcp-apps` is a Lynx host for MCP Apps. It validates the app data it receives, picks the renderer you registered for it and renders it with ReactLynx, and falls back to streaming Markdown when no registered renderer matches. Define renderers with `defineAppRenderer`, collect them with `createAppRendererRegistry` and pass the registry to `McpApps`.

```ts
import {
  McpApps,
  createAppRendererRegistry,
  defineAppRenderer,
} from '@lynx-js/genui/mcp-apps';
```
