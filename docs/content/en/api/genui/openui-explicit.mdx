# `@lynx-js/genui/openui/explicit`

`@lynx-js/genui/openui/explicit` exports the same API as [`@lynx-js/genui/openui`](./openui), except that `createOpenUiLibrary` does not include the default catalog. Import each built-in component you need from `@lynx-js/genui/openui/catalog/<Component>` and pass it in, so the components you leave out are not bundled.

```ts
import { createOpenUiLibrary } from '@lynx-js/genui/openui/explicit';
import { Stack } from '@lynx-js/genui/openui/catalog/Stack';
import { TextContent } from '@lynx-js/genui/openui/catalog/TextContent';
```
