# `@lynx-js/genui/a2ui-prompt`

`@lynx-js/genui/a2ui-prompt` builds the system prompt that teaches a model to answer with A2UI messages, from the built-in basic catalog or from your own catalog. Use it in a CLI or on the agent side, next to the [`@lynx-js/genui/a2ui`](./a2ui) renderer in the app.

```ts
import { buildA2UISystemPrompt } from '@lynx-js/genui/a2ui-prompt';
```

### `readA2UICatalogFromDirectory()` \{#reada2uicatalogfromdirectory\}

```ts
function readA2UICatalogFromDirectory(options: ReadA2UICatalogDirectoryOptions): A2UICatalog
```

Read generated manifests and convert them into a prompt-ready A2UI catalog.
Components and functions come from a full `catalog.json` in `catalogDir`
or its parent when one exists; otherwise only components are read, from
per-component `<Name>/catalog.json` files, and the catalog has no
functions.

| --- | --- | --- |
| `options` | [`ReadA2UICatalogDirectoryOptions`](#reada2uicatalogdirectoryoptions) |  |
