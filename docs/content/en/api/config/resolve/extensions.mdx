# resolve.extensions

{/* @api ConfigOption package="rspeedy" path="resolve.extensions" */}

- **Type:** `string[]`
- **Default:** `['.ts', '.tsx', '.mjs', '.js', '.jsx', '.json', '.cjs']`

Lynx changes the default of this Rsbuild option; everything else works as in Rsbuild. See the [Rsbuild documentation](https://rsbuild.rs/config/resolve/extensions).

{/* @api-end */}
