# output.inlineScripts

{/* @api ConfigOption package="rspeedy" path="output.inlineScripts" */}

- **Type:** `InlineChunkConfig`

Lynx changes the default of this Rsbuild option; everything else works as in Rsbuild. See the [Rsbuild documentation](https://rsbuild.rs/config/output/inline-scripts).

## Default \{#default\}

- Rspeedy defaults this to `true` and only switches it to `false` when the user explicitly enables the top-level `splitChunks` option.
