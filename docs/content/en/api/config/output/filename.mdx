# output.filename

{/* @api ConfigOption package="rspeedy" path="output.filename" */}

- **Type:** `string | Filename`
- **Default:** `{ bundle: '[name].[platform].bundle', template: '[name].[platform].bundle' }`

Lynx changes the default of this Rsbuild option; everything else works as in Rsbuild. See the [Rsbuild documentation](https://rsbuild.rs/config/output/filename).

{/* @api-end */}
