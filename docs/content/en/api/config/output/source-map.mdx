# output.sourceMap

{/* @api ConfigOption package="rspeedy" path="output.sourceMap" */}

- **Type:** `boolean | SourceMap`

Lynx changes the default of this Rsbuild option; everything else works as in Rsbuild. See the [Rsbuild documentation](https://rsbuild.rs/config/output/source-map).

## Default \{#default\}

- When this option is unset in Lynx builds, JavaScript source maps use `'cheap-module-source-map'` in development and `'source-map'` in production; CSS source maps are also generated.
- All `.map` assets are removed before emit.
