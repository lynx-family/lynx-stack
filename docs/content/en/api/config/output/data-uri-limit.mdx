# output.dataUriLimit

{/* @api ConfigOption package="rspeedy" path="output.dataUriLimit" */}

- **Type:** `number | DataUriLimit`
- **Default:** `2048`

Lynx changes the default of this Rsbuild option; everything else works as in Rsbuild. See the [Rsbuild documentation](https://rsbuild.rs/config/output/data-uri-limit).
