# dev.writeToDisk

{/* @api ConfigOption package="rspeedy" path="dev.writeToDisk" */}

- **Type:** `boolean | ((filename: string) => boolean)`
- **Default:** `true`

Lynx changes the default of this Rsbuild option; everything else works as in Rsbuild. See the [Rsbuild documentation](https://rsbuild.rs/config/dev/write-to-disk).
