# environments

{/* @api ConfigOption package="rspeedy" path="environments" */}

- **Type:** `Record<string, EnvironmentConfig>`

Lynx changes the default of this Rsbuild option; everything else works as in Rsbuild. See the [Rsbuild documentation](https://rsbuild.rs/config/environments).

## Default \{#default\}

- When this option is unset, Rspeedy passes `{ lynx: {} }` to Rsbuild.
