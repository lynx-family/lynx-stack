### `WebSocket` \{#websocket\}

The implementation of [WebSocket](https://developer.mozilla.org/en-US/docs/Web/API/WebSocket)

| Parameters | Type | Description |

#### `WebSocket.ping` \{#websocket-ping\}

- **Type:** `ping(): void`

The `ping` method send an empty message to the server over the [`WebSocket`](#websocket) connection.

It will throw an exception if you call `ping()` when the connection is in the [`CONNECTING `](#websocket-connecting) state. If you call `ping()` when the connection is in the [`CLOSING `](#websocket-closing) or [`CLOSED `](#websocket-closed) states, it will silently discard the data.

#### `WebSocket.removeEventListener` \{#websocket-removeeventlistener\}

- **Type:** `removeEventListener(type: T, callback: (event: EventMap[T]) => void): void`

The `removeEventListener()` method of the `EventTarget` interface removes an event listener from the WebSocket.

| Parameters | Type | Description |
| --- | --- | --- |
| `type` | `T` | The type of event to stop listening for. |
| `callback` | `(event: `[`EventMap`](#eventmap)`[T]) => void` | The function to remove as an event listener. |

#### `WebSocket.send` \{#websocket-send\}

- **Type:** `send(data: string): void`

The `send` method send the specified data to be transmitted to the server over the [`WebSocket`](#websocket) connection.

It will throw an exception if you call `send()` when the connection is in the [`CONNECTING `](#websocket-connecting) state. If you call `send()` when the connection is in the [`CLOSING `](#websocket-closing) or [`CLOSED `](#websocket-closed) states, it will silently discard the data.

| Parameters | Type | Description |
| --- | --- | --- |
| `data` | `string` | The specified data to be transmitted. |

## Types \{#types\}

### `ReadyState` \{#readystate\}

The `ReadyState` describe the state of a `WebSocket` connection.

| Members | Type | Description |
| --- | --- | --- |
| <a id="readystate-closed"></a>`CLOSED` | `3` | The connection is closed or couldn't be opened. |
| <a id="readystate-closing"></a>`CLOSING` | `2` | The connection is in the process of closing. |
| <a id="readystate-connecting"></a>`CONNECTING` | `0` | Socket has been created. The connection is not yet open. |
| <a id="readystate-open"></a>`OPEN` | `1` | The connection is open and ready to communicate. |
