Updates `@lynx-js/rspeedy` and the Rspeedy-related packages in `package.json` to matching versions.

## Usage

Run it in a project that uses `@lynx-js/rspeedy`, then install the dependencies again:

```bash
npx upgrade-rspeedy@latest
npm install
```

To move to a canary version of Rspeedy, run `upgrade-rspeedy-canary` at that version. It writes the packages as `npm:` aliases:

```bash
# Replace the version with the canary you want
npx upgrade-rspeedy-canary@0.8.2-canary-20250309-870106fc
```
