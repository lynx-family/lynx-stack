# @lynx-js/motion

{/* @api PackageHeader package="motion" */}

<div className="api-pkg-header"><code>@lynx-js/motion</code> <span className="api-pkg-version">v0.0.6</span> · <a href="https://www.npmjs.com/package/@lynx-js/motion" target="_blank" rel="noopener">npm</a> · <a href="https://github.com/lynx-family/lynx-stack/tree/main/packages/motion" target="_blank" rel="noopener">Source</a> · <a href="https://github.com/lynx-family/lynx-stack/tree/main/packages/motion/CHANGELOG.md" target="_blank" rel="noopener">Changelog</a></div>

A powerful animation library for Lynx, ported from [Motion for React (framer-motion)](https://motion.dev/). It brings declarative animations and gesture handling to the Lynx ecosystem.

## Installation

import { PackageManagerTabs } from '@rspress/core/theme';
