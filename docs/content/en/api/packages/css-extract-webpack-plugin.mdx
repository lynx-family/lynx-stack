## Classes \{#classes\}

### `CssExtractRspackPlugin` \{#cssextractrspackplugin\}

CssExtractRspackPlugin is the CSS extract plugin for Lynx.
It works just like the [CssExtractRspackPlugin](https://rspack.rs/plugins/rspack/css-extract-rspack-plugin.html) in Web.

```js
import { CssExtractRspackPlugin } from '@lynx-js/css-extract-webpack-plugin'
export default {
  plugins: [new CssExtractRspackPlugin()],
  module: {
    rules: [
      {
        test: /\.css$/,
        uses: [CssExtractRspackPlugin.loader, 'css-loader'],
      },
    ],
  },
}
```

#### `CssExtractRspackPlugin.loader` \{#cssextractrspackplugin-loader\}

- **Type:** `string`

The loader to extract CSS.

It should be used with the ['css-loader'](https://github.com/webpack-contrib/css-loader).

```js
import { CssExtractRspackPlugin } from '@lynx-js/css-extract-webpack-plugin'
export default {
  plugins: [new CssExtractRspackPlugin()],
  module: {
    rules: [
      {
        test: /\.css$/,
        uses: [CssExtractRspackPlugin.loader, 'css-loader'],
      },
    ],
  },
}
```

#### `LoaderOptions.emit?` \{#loaderoptions-emit\}

- **Type:** `boolean`
- **Default:** ```ts
true
@public
```

The same as [mini-css-extract-plugin](https://github.com/webpack-contrib/mini-css-extract-plugin/tree/master?tab=readme-ov-file#emit).
Control whether emit the CSS to filesystem.

- If `true`(default), emits a file (writes a file to the filesystem).

- If `false`, the plugin will extract the CSS but will not emit the file.

It is often useful to disable this option for server-side packages.

#### `LoaderOptions.layer?` \{#loaderoptions-layer\}

- **Type:** `string`

The layer of the CSS execution.

This should be combined with `experiments.layers`.
