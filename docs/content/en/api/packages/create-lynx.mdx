Creates a Lynx app or library with one command.

## Usage

```bash
npm create @lynx-js/lynx@latest
```

Pass a directory and a template on the command line:

```bash
npm create @lynx-js/lynx@latest my-app -- --template rsbuild-react-ts
```

## Templates

Templates are named `<build tool>-<DSL>-<language>`. Parts that are left out take their default, so `rsbuild`, `rsbuild-ts` and `rsbuild-react-ts` name the same template.

| Template | Creates | Build tool | Config |
| --- | --- | --- | --- |
| `rsbuild-react-ts` / `rsbuild-react-js` | App | [Rsbuild](https://rsbuild.rs/) with [`pluginLynx`](/api/packages/rsbuild-plugin) | `rsbuild.config.*` |
| `rspeedy-react-ts` / `rspeedy-react-js` | App | [Rspeedy](/api/packages/rspeedy) | `lynx.config.*` |
| `rslib-react-ts` / `rslib-react-js` | Library | [Rslib](https://rslib.rs/) | `rslib.config.*` |

Every template comes with [Rstest](https://rstest.rs/) and `@lynx-js/react/testing-library` set up; run the tests with `npm run test`. See the [README](https://github.com/lynx-family/lynx-stack/tree/main/packages/rspeedy/create-lynx) for the other options.
