An MCP server that gives coding agents such as Claude Code, Codex, Cursor and Copilot the Lynx documentation, through [llms.txt](https://lynxjs.org/next/llms.txt).

## Usage

Add it to the MCP configuration of your client:

```json
{
  "mcpServers": {
    "lynx-docs": {
      "command": "npx",
      "args": ["-y", "@lynx-js/docs-mcp-server@latest"]
    }
  }
}
```

With Claude Code:

```bash
claude mcp add lynx-docs npx @lynx-js/docs-mcp-server@latest
```

It needs Node.js 18.17 or later. See the [README](https://github.com/lynx-family/lynx-stack/tree/main/packages/mcp-servers/docs-mcp-server) for other clients.
