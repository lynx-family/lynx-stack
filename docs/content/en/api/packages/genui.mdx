Generative UI primitives for Lynx applications.

`@lynx-js/genui` is the single npm package for the GenUI toolchain. It exposes A2UI rendering, OpenUI rendering, A2UI prompt/catalog utilities, and the CLI from one package while keeping implementation directories private to this monorepo.

## Installation

import { PackageManagerTabs } from '@rspress/core/theme';

<PackageManagerTabs command="add @lynx-js/genui" />

### `MessageStore` \{#messagestore\}

A pure append-only buffer of raw protocol messages produced by the
developer's IO module. The store knows nothing about the v0.9 protocol —
it does not parse, process, or interpret messages. It only:

 1. Stores them in arrival order.
 2. Notifies subscribers when new ones land.
 3. Hands the current snapshot back via `getSnapshot()` (referentially
    stable between mutations — required by `useSyncExternalStore`).

Protocol-aware processing — surfaces, signals, resources, action
dispatch — is the responsibility of `<A2UI>` (the renderer component).
Developers who don't want to learn the protocol should use `<A2UI>`;
developers who do can run their own `MessageProcessor` against the
snapshot directly.

| Members | Type | Description |
| --- | --- | --- |
| <a id="messagestore-getsnapshot"></a>`getSnapshot` | `() => readonly `[`ServerToClientMessage`](#servertoclientmessage)`[]` | `useSyncExternalStore` getSnapshot contract — stable between pushes. |
| <a id="messagestore-subscribe"></a>`subscribe` | `(cb: () => void) => () => void` | `useSyncExternalStore` subscribe contract. |
| <a id="messagestore-clear"></a>`clear` | `clear(): void` | Reset the buffer. Notifies subscribers. |
| <a id="messagestore-push"></a>`push` | `push(message: ServerToClientMessage \| readonly ServerToClientMessage[]): void` | Append one or more raw messages to the buffer. Notifies subscribers once per call (batches a single array argument into a single notify). |
