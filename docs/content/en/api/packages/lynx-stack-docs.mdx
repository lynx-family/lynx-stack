This API reference as MDX pages, in English and Chinese, for documentation sites that show it next to their own pages. It is published with every Lynx Stack release.

## Installation

import { PackageManagerTabs } from '@rspress/core/theme';

<PackageManagerTabs command="add @lynx-js/lynx-stack-docs -D" />

## Layout

```
content/
  en/
    config/      build configuration
    react/api/   ReactLynx API
    packages/    every @lynx-js package, the Rsbuild plugins included
  zh/            the same pages in Chinese
```

Each directory carries its Rspress `_meta.json`. Copy a directory to the same path under your docs root. See the [README](https://github.com/lynx-family/lynx-stack/tree/main/packages/lynx-stack-docs) for what the pages expect.
