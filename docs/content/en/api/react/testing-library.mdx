# Testing Library

{/* @api PackageHeader package="react-testing-library" */}

`@lynx-js/react/testing-library` renders ReactLynx components in a simulated dual-thread environment so they can be tested with Vitest or Rstest. It follows the [Testing Library](https://testing-library.com/) conventions: render a component, query the element tree the way a user would find things, fire events and assert on the result.

```tsx title="App.test.tsx"
import { expect, test } from 'vitest'
import { fireEvent, render } from '@lynx-js/react/testing-library'

import { App } from './App.jsx'

test('increments the counter', () => {
  const { getByText } = render(<App />)
  fireEvent.tap(getByText('Count: 0'))
  expect(getByText('Count: 1')).toBeTruthy()
})
```

For setup and the dual-thread rendering options, see the [guide on lynxjs.org](https://lynxjs.org/react/reactlynx-testing-library).

#### `RenderHookOptions.wrapper?` \{#renderhookoptions-wrapper\}

- **Type:** `any`

Pass a React Component as the wrapper option to have it rendered around the inner element. This is most useful for creating
 reusable custom render functions for common data providers. See setup for examples.

```ts
import { renderHook } from '@lynx-js/react/testing-library'
import { ThemeProvider } from 'my-ui-lib'
import { TranslationProvider } from 'my-i18n-lib'
import defaultStrings from 'i18n/en-x-default'

const AllTheProviders = ({children}) => {
  return (
    <ThemeProvider theme="light">
      <TranslationProvider messages={defaultStrings}>
        {children}
      </TranslationProvider>
    </ThemeProvider>
  )
}

const customRenderHook = (ui, options) =>
  renderHook(ui, { wrapper: AllTheProviders, ...options })

// re-export everything
export * from '@lynx-js/react/testing-library'

// override renderHook method
export { customRender as renderHook }
```

#### `RenderOptions.queries?` \{#renderoptions-queries\}

- **Type:** `Q`

Queries to bind. Overrides the default set from DOM Testing Library unless merged.

```ts
// Example, a function to traverse table contents
import * as tableQueries from 'my-table-query-library'
import { queries } from '@lynx-js/react/testing-library'

const { getByRowColumn, getByText } = render(<MyTable />, {
  queries: {...queries, ...tableQueries},
})

```

#### `RenderOptions.wrapper?` \{#renderoptions-wrapper\}

- **Type:** `any`

Pass a React Component as the wrapper option to have it rendered around the inner element. This is most useful for creating
 reusable custom render functions for common data providers. See setup for examples.

```ts
import { render } from '@lynx-js/react/testing-library'
import { ThemeProvider } from 'my-ui-lib'
import { TranslationProvider } from 'my-i18n-lib'
import defaultStrings from 'i18n/en-x-default'

const AllTheProviders = ({children}) => {
  return (
    <ThemeProvider theme="light">
      <TranslationProvider messages={defaultStrings}>
        {children}
      </TranslationProvider>
    </ThemeProvider>
  )
}

const customRender = (ui, options) =>
  render(ui, { wrapper: AllTheProviders, ...options })

// re-export everything
export * from '@lynx-js/react/testing-library'

// override render method
export { customRender as render }
```
