# performance.profile

{/* @api ConfigOption package="rspeedy" path="performance.profile" */}

- **Type:** `boolean`
- **Default:** Rspeedy sets this to `true` when `DEBUG` contains `rspeedy`; otherwise it leaves the option unset.

Whether capture timing information in Lynx runtime integrations such as ReactLynx.

Enable profile.

- Frameworks like ReactLynx will include runtime information using `console.profile`.
- Rspeedy will emit `dist/stats.json` after build for bundle analysis compatibility.

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: { profile: true },
})
```

## Usage \{#usage\}

With Rsbuild, pass it to [`pluginLynx`](/plugins/plugin-lynx#performance-profile):

```ts title="rsbuild.config.ts"
import { defineConfig } from '@rsbuild/core'
import { pluginLynx } from '@lynx-js/rsbuild-plugin'

export default defineConfig({
  plugins: [
    pluginLynx({
      performance: {
        profile: true,
      },
    }),
  ],
})
```

With Rspeedy, set it in `lynx.config.ts`:

```ts title="lynx.config.ts"
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: {
    profile: true,
  },
})
```
