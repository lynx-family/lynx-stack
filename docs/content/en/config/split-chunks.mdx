# splitChunks

{/* @api ConfigOption package="rspeedy" path="splitChunks" */}

- **Type:** `false | SplitChunksConfig`
- **Lynx default:** Rspeedy defaults this to `false`; if configured, Rsbuild handles it with its top-level `splitChunks` option. See [Rsbuild - splitChunks](https://rsbuild.rs/config/split-chunks) for details.

Configure chunk splitting.

This is a standard Rsbuild option with a different default in Lynx builds. See the [Rsbuild documentation](https://rsbuild.rs/config/split-chunks) for the full description.
