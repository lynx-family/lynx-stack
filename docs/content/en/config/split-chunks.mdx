# splitChunks

{/* @api ConfigOption package="rspeedy" path="splitChunks" */}

- **Type:** `false | SplitChunksConfig`

Lynx changes the default of this Rsbuild option; everything else works as in Rsbuild. See the [Rsbuild documentation](https://rsbuild.rs/config/split-chunks).

## Default \{#default\}

Rspeedy defaults this to `false`; if configured, Rsbuild handles it with its top-level `splitChunks` option.

See [Rsbuild - splitChunks](https://rsbuild.rs/config/split-chunks) for details.
