# splitChunks

Chunk splitting. It is the standard [Rsbuild `splitChunks` option](https://rsbuild.rs/config/split-chunks). Rspeedy defaults it to `false`; enabling it turns off `output.inlineScripts` so that background-thread chunks are emitted as separate files.
