# server.host

{/* @api ConfigOption package="rspeedy" path="server.host" */}

- **Type:** `string`
- **Lynx default:** `"0.0.0.0"`
- **Rsbuild default:** `'localhost'`

Specify the host that the Rspeedy Server listens to.

This is a standard Rsbuild option with a different default in Lynx builds. See the [Rsbuild documentation](https://rsbuild.rs/config/server/host) for the full description.
