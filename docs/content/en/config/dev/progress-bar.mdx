# dev.progressBar

{/* @api ConfigOption package="rspeedy" path="dev.progressBar" */}

- **Type:** `boolean | { id?: string }`
- **Lynx default:** `true`
- **Rsbuild default:** `false`

Whether to display progress bar during compilation.

This is a standard Rsbuild option with a different default in Lynx builds. See the [Rsbuild documentation](https://rsbuild.rs/config/dev/progress-bar) for the full description.
