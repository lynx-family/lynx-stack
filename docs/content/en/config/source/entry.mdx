# source.entry

{/* @api ConfigOption package="rspeedy" path="source.entry" */}

- **Type:** `Entry`
- **Lynx default:** `'./src/index.js'`
- **Rsbuild default:** `{ index: './src/index.js', }`

The `Entry` option is used to set the entry module.

This is a standard Rsbuild option with a different default in Lynx builds. See the [Rsbuild documentation](https://rsbuild.rs/config/source/entry) for the full description.
