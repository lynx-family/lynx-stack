# output.inlineScripts

{/* @api ConfigOption package="rspeedy" path="output.inlineScripts" */}

- **Type:** `InlineChunkConfig` (from [@rsbuild/core](https://rsbuild.rs/config/))
- **Lynx default:** Rspeedy defaults this to `true` and only switches it to `false` when the user explicitly enables the top-level `splitChunks` option.
- **Rsbuild default:** `false`

The `Output.inlineScripts` option controls whether to inline scripts into Lynx bundle (`.lynx.bundle`).

This is a standard Rsbuild option with a different default in Lynx builds. See the [Rsbuild documentation](https://rsbuild.rs/config/output/inline-scripts) for the full description.
