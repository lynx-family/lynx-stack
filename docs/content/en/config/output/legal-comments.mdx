# output.legalComments

{/* @api ConfigOption package="rspeedy" path="output.legalComments" */}

- **Type:** `"none" | "inline" | "linked"`
- **Lynx default:** `'none'`
- **Rsbuild default:** `'linked'`

The `Output.legalComments` controls how to handle the legal comment.

This is a standard Rsbuild option with a different default in Lynx builds. See the [Rsbuild documentation](https://rsbuild.rs/config/output/legal-comments) for the full description.
