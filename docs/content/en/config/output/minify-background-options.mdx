# output.minify.backgroundOptions

{/* @api ConfigOption package="rspeedy" path="output.minify.backgroundOptions" */}

- **Type:** `SwcJsMinimizerRspackPluginOptions`

`Minify.backgroundOptions` is used to override
`Minify.jsOptions` for background-thread bundles.

This option is deep-merged into `Minify.jsOptions`.
It is mainly used together with ReactLynx dual-thread outputs so that
main-thread and background-thread bundles can use different compress rules.

## Usage \{#usage\}

With Rsbuild, pass it to [`pluginLynx`](/packages/rsbuild-plugin#output-minify-backgroundoptions):

```ts title="rsbuild.config.ts"
import { defineConfig } from '@rsbuild/core'
import { pluginLynx } from '@lynx-js/rsbuild-plugin'

export default defineConfig({
  plugins: [
    pluginLynx({
      output: {
        minify: {
          backgroundOptions: {},
        },
      },
    }),
  ],
})
```

With Rspeedy, set it in `lynx.config.ts`:

```ts title="lynx.config.ts"
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  output: {
    minify: {
      backgroundOptions: {},
    },
  },
})
```
