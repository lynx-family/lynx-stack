# mode

The build mode. It is the standard [Rsbuild `mode` option](https://rsbuild.rs/config/mode). With Rspeedy, it defaults to `production` for `rspeedy build` and `development` for `rspeedy dev`.

## At a glance

{/* @api ConfigOverview package="rspeedy" type="Config" path="mode" */}

| Name | Type | Description |
| --- | --- | --- |
| [`mode`](#mode) | `"production" \| "development" \| "none"` | Specify the build mode for Rsbuild and Rspack, as each mode has different default behavior and optimizations. |

{/* @api-end */}
