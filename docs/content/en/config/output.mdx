# output

Options for what the build writes to disk: where it goes, how files are named, and whether they are minified or come with source maps.

Most of them are standard Rsbuild options: set them under `output` in `rsbuild.config.ts`, or in `lynx.config.ts` when you build with Rspeedy, and see the Rsbuild documentation for the details. The options specific to Lynx are described below, each with where to set it when you build with Rsbuild.

```ts title="rsbuild.config.ts"
import { defineConfig } from '@rsbuild/core'
import { pluginLynx } from '@lynx-js/rsbuild-plugin'

export default defineConfig({
  output: {
    sourceMap: true,
  },
  plugins: [
    pluginLynx({
      output: {
        filename: { bundle: '[name].[platform].bundle' },
      },
    }),
  ],
})
```

```ts title="lynx.config.ts"
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  output: {
    filename: { bundle: '[name].[platform].bundle' },
    sourceMap: true,
  },
})
```

## Lynx-specific options \{#lynx-options\}

### `output.filename.bundle` \{#output-filename-bundle\}

- **Type:** `BundleFilename`
- **Default:** `'[name].[platform].bundle'`

The name of the bundle files.

The following placeholder is supported:

- `[name]`: the name of the entry.
- `[contenthash]`: the contenthash of the bundle.
- `[platform]`: the environment name of the bundle.

- Using content hash in bundle filename:

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  output: {
    filename: {
      bundle: '[name].[contenthash].bundle',
    },
  },
})
```

- Using content hash with length in bundle filename:

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  output: {
    filename: {
      bundle: '[name].[contenthash:8].bundle',
    },
  },
})
```

- Using a function to control the main bundle and the lazy bundles
  separately (e.g. emit lazy bundles into another directory with a git
  commit hash appended):

```js
import { execSync } from 'node:child_process'

import { defineConfig } from '@lynx-js/rspeedy'

const gitHash = execSync('git rev-parse --short HEAD').toString().trim()

export default defineConfig({
  output: {
    filename: {
      bundle: ({ lazyBundle, platform }) =>
        lazyBundle
          ? `my-lazy-bundles/[name].[fullhash]-${gitHash}.bundle`
          : `[name].${platform}.bundle`,
    },
  },
})
```

With Rsbuild, pass this option to [`pluginLynx`](/plugins/plugin-lynx#output-filename-bundle).

### `output.filename.template` <span className="api-badge api-badge-deprecated">Deprecated</span> \{#output-filename-template\}

- **Type:** `string`
- **Default:** `'[name].[platform].bundle'`

:::warning Deprecated
Deprecated.
:::

The name of the template files.



Use [`Filename.bundle`](#output-filename) instead.

The following placeholder is supported:

- `[name]`: the name of the entry.
- `[contenthash]`: the contenthash of the template.

- Using content hash in bundle filename:

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  output: {
    filename: {
      template: '[name].[contenthash].bundle',
    },
  },
})
```

- Using content hash with length in bundle filename:

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  output: {
    filename: {
      template: '[name].[contenthash:8].bundle',
    },
  },
})
```

### `output.minify.backgroundOptions` \{#output-minify-backgroundoptions\}

- **Type:** `SwcJsMinimizerRspackPluginOptions` (from [@rspack/core](https://rspack.rs/config/))
- **Default:** `undefined`

[`Minify.backgroundOptions`](#output-minify) is used to override
[`Minify.jsOptions`](#output-minify) for background-thread bundles.

This option is deep-merged into [`Minify.jsOptions`](#output-minify).
It is mainly used together with ReactLynx dual-thread outputs so that
main-thread and background-thread bundles can use different compress rules.

With Rsbuild, pass this option to [`pluginLynx`](/plugins/plugin-lynx#output-minify-backgroundoptions).

### `output.minify.mainThreadOptions` \{#output-minify-mainthreadoptions\}

- **Type:** `SwcJsMinimizerRspackPluginOptions` (from [@rspack/core](https://rspack.rs/config/))
- **Default:** `undefined`

[`Minify.mainThreadOptions`](#output-minify) is used to override
[`Minify.jsOptions`](#output-minify) for main-thread bundles.

This option is deep-merged into [`Minify.jsOptions`](#output-minify).
It is mainly used together with ReactLynx dual-thread outputs so that
main-thread and background-thread bundles can use different compress rules.

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  output: {
    minify: {
      jsOptions: {
        minimizerOptions: {
          compress: {
            pure_funcs: ['console.log'],
          },
        },
      },
      mainThreadOptions: {
        minimizerOptions: {
          compress: {
            pure_funcs: ['NativeModules.call', 'lynx.getJSModule'],
          },
        },
      },
    },
  },
})
```

With Rsbuild, pass this option to [`pluginLynx`](/plugins/plugin-lynx#output-minify-mainthreadoptions).
