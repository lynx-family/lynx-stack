# performance

Options that trade build output for runtime performance: chunk splitting, console removal, runtime profiling and the bundle analyzer.

Most of them are standard Rsbuild options: set them under `performance` in `rsbuild.config.ts`, or in `lynx.config.ts` when you build with Rspeedy, and see the Rsbuild documentation for the details. The options specific to Lynx are described below, each with where to set it when you build with Rsbuild.

{/* @api ConfigOptions package="rspeedy" type="Config" path="performance" */}

## Lynx-specific options \{#lynx-options\}

### `performance.profile` \{#performance-profile\}

- **Type:** `boolean`
- **Default:** Rspeedy sets this to `true` when `DEBUG` contains `rspeedy`; otherwise it leaves the option unset.

Whether capture timing information in Lynx runtime integrations such as ReactLynx.

Enable profile.

- Frameworks like ReactLynx will include runtime information using `console.profile`.
- Rspeedy will emit `dist/stats.json` after build for bundle analysis compatibility.

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: { profile: true },
})
```

With Rsbuild, pass this option to [`pluginLynx`](/plugins/plugin-lynx#performance-profile).
