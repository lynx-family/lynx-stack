# plugins

The list of Rsbuild plugins to apply. It is the standard [Rsbuild `plugins` option](https://rsbuild.rs/config/plugins). With Rsbuild, add [`pluginLynx`](/plugins/plugin-lynx) or a DSL plugin such as [`pluginReactLynx`](/plugins/plugin-react) here; Rspeedy applies `pluginLynx` itself before the plugins listed here.
