# environments

{/* @api ConfigOption package="rspeedy" path="environments" */}

- **Type:** `Record<string, EnvironmentConfig>` (from typescript)
- **Lynx default:** When this option is unset, Rspeedy passes `{ lynx: {} }` to Rsbuild.

The `Config.environments` option is used to set the output environment.

This is a standard Rsbuild option with a different default in Lynx builds. See the [Rsbuild documentation](https://rsbuild.rs/config/environments) for the full description.

{/* @api-end */}
