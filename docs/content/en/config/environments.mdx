# environments

Each Rsbuild environment produces one Lynx bundle, and the environment name becomes the `[platform]` placeholder of `output.filename.bundle`. `environments` is a standard [Rsbuild option](https://rsbuild.rs/config/environments), set in `rsbuild.config.ts` or `lynx.config.ts`.

## At a glance

{/* @api ConfigOverview package="rspeedy" type="Config" path="environments" */}

| Name | Type | Description |
| --- | --- | --- |
| [`environments`](#environments) | `Record<string, EnvironmentConfig>` (from typescript) | The [`Config.environments`](#environments) option is used to set the output environment. |
