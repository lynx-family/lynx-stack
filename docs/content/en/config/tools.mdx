# tools

Escape hatches to the underlying tools: modify the Rspack configuration, the SWC options or the Rsbuild config directly when an option is not exposed.

Most of them are standard Rsbuild options: set them under `tools` in `rsbuild.config.ts`, or in `lynx.config.ts` when you build with Rspeedy, and see the Rsbuild documentation for the details. The options specific to Lynx are described below, each with where to set it when you build with Rsbuild.

## Lynx-specific options \{#lynx-options\}

### `tools.rsdoctor` \{#tools-rsdoctor\}

- **Type:** [`RsdoctorRspackPluginOptions`](#tools-rsdoctor)
- **Default:** `undefined`

The `Tools.rsdoctor` controls the options of [Rsdoctor](https://rsdoctor.dev/).

Setting `RSDOCTOR=true` enables Rsdoctor. When it is enabled, Rspeedy merges additional plugin defaults during config normalization.

- Use the built-in Rsdoctor.

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    rsdoctor: {
      disableClientServer: true,
    },
  },
})
```

See [Rsdoctor - Configuration](https://rsdoctor.dev/config/options/options) for details.

Available only in `lynx.config.ts` (Rspeedy).
