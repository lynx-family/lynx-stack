# Configuration

Rspeedy reads `lynx.config.ts` (or `.js`, `.mjs`) from the project root. Wrap the object in `defineConfig` from `@lynx-js/rspeedy` to get completion and type checking:

```ts title="lynx.config.ts"
import { defineConfig } from '@lynx-js/rspeedy'
import { pluginReactLynx } from '@lynx-js/react-rsbuild-plugin'

export default defineConfig({
  source: {
    entry: './src/index.tsx',
  },
  plugins: [pluginReactLynx()],
})
```

The options are a subset of the [Rsbuild configuration](https://rsbuild.rs/config/). Options that would break a Lynx bundle (`html`, `security`, `moduleFederation`, the polyfill settings) are not exposed; the ones below are, with Lynx-specific defaults where they differ from Rsbuild.

## All options

{/* @api ConfigOverview package="rspeedy" type="Config" */}

| Name | Type | Description |
| --- | --- | --- |
| [`dev`](/rspeedy/config/dev) | [`Dev`](/rspeedy/config/dev) | The [`Dev`](/rspeedy/config/dev) option is used to control the behavior related with development. Including: HMR, DevServer, etc. |
| [`environments`](/rspeedy/config/environments#environments) | `Record<string, EnvironmentConfig>` (from typescript) | The [`Config.environments`](/rspeedy/config/environments#environments) option is used to set the output environment. |
| [`mode`](/rspeedy/config/mode#mode) | `"production" \| "development" \| "none"` | Specify the build mode for Rsbuild and Rspack, as each mode has different default behavior and optimizations. |
| [`output`](/rspeedy/config/output) | [`Output`](/rspeedy/config/output) | The [`Output`](/rspeedy/config/output) option is used to set how and where should the bundles and assets output. |
| [`performance`](/rspeedy/config/performance) | [`Performance`](/rspeedy/config/performance) | The [`Performance`](/rspeedy/config/performance) option is used to optimize the build-time and runtime performance. |
| [`plugins`](/rspeedy/config/plugins#plugins) | `RsbuildPlugins` (from [@rsbuild/core](https://rsbuild.rs/config/)) | The `plugins` option is used to customize the build process in a variety of ways. |
| [`resolve`](/rspeedy/config/resolve) | [`Resolve`](/rspeedy/config/resolve) | The [`Resolve`](/rspeedy/config/resolve) option is used to control the resolution behavior of Rspack. |
| [`server`](/rspeedy/config/server) | [`Server`](/rspeedy/config/server) | The [`Server`](/rspeedy/config/server) option changes the behavior of dev-server. |
| [`source`](/rspeedy/config/source) | [`Source`](/rspeedy/config/source) | The [`Source`](/rspeedy/config/source) option changes the behavior of source files. |
| [`splitChunks`](/rspeedy/config/splitChunks#splitchunks) | `false \| SplitChunksConfig` | Configure chunk splitting. |
| [`tools`](/rspeedy/config/tools) | [`Tools`](/rspeedy/config/tools) | The [`Tools`](/rspeedy/config/tools) options changes the behavior of various building tools. |

{/* @api-end */}
