# environments

Rspeedy builds one Lynx bundle per Rsbuild environment. `environments` is the [Rsbuild `environments` option](https://rsbuild.rs/config/environments); the environment name becomes the `[platform]` placeholder of `output.filename.bundle`.

## Options

{/* @api ConfigOptions package="rspeedy" type="Config" path="environments" */}

### `environments` \{#environments\}

- **Type:** `Record<string, EnvironmentConfig>` (from typescript)
- **Default:** When this option is unset, Rspeedy passes `{ lynx: {} }` to Rsbuild.

The [`Config.environments`](#environments) option is used to set the output environment.

Normally you don't need this if you are not using Lynx for Web.

- Using different entries for Lynx and Web.

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  environments: {
    lynx: {},
    web: {
      source: { entry: { web: './src/index.web.jsx' } },
    },
  },
  source: {
    entry: './src/index.jsx',
  },
})
```

- Building Web-only outputs.

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  environments: {
    web: {
      source: { entry: { web: './src/index.web.jsx' } },
    },
  },
})
```
