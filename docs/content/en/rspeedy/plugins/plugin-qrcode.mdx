# pluginQRCode

Prints a QR code of the bundle URL in the terminal during `dev`, so a Lynx Explorer app can scan it and load the bundle from the local server.

## Installation

import { PackageManagerTabs } from '@rspress/core/theme';

<PackageManagerTabs command="add @lynx-js/qrcode-rsbuild-plugin -D" />

## Usage

```ts title="lynx.config.ts"
import { defineConfig } from '@lynx-js/rspeedy'
import { pluginQRCode } from '@lynx-js/qrcode-rsbuild-plugin'

export default defineConfig({
  plugins: [pluginQRCode()],
})
```

## Options

### `schema` \{#schema\}

- **Type:** [`CustomizedSchemaFn`](#customizedschemafn)

Customize the generated schema.

```js
import { pluginQRCode } from '@lynx-js/qrcode-rsbuild-plugin'
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  plugins: [
    pluginQRCode({
      schema(url) {
        return `lynx://${url}?dev=1`
      },
    }),
  ],
})
```

- Use multiple schemas:

You may press `a` in the terminal to switch between schemas.

```js
import { pluginQRCode } from '@lynx-js/qrcode-rsbuild-plugin'
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  plugins: [
    pluginQRCode({
      schema(url) {
        return {
          http: url,
          foo: `foo://lynx?url=${encodeURIComponent(url)}&dev=1`,
          bar: `bar://lynx?url=${encodeURIComponent(url)}`,
        }
      },
    }),
  ],
})
```

### Other options \{#other-options\}

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| <a id="fullscreen"></a>`fullscreen` | `boolean` | `false` | Opt in to the fullscreen variant of the Lynx bundle URL (appends `?fullscreen=true`, opening the bundle in LynxExplorer with the in-app navigation chrome stripped). When enabled, the plugin: - Appends a `fullscreen` entry to the schema rotation — the QR keeps   opening on your default schema; press `a` in the dev console to switch   to the `fullscreen` variant. - Appends an `∟ Fullscreen` URL line under each Lynx bundle URL printed   by the dev server. |
