`@lynx-js/testing-environment` 是 [Lynx 规范](https://lynxjs.org/zh/api/engine/element-api) 的纯 JavaScript 实现，主要包括 [Element PAPI](https://lynxjs.org/zh/api/engine/element-api) 和 [双线程模型](https://lynxjs.org/zh/guide/spec#dual-threaded-model)，可在 Node.js 中使用。总体而言，该项目的目标是模拟 Lynx 环境中足够大的一个子集，以满足测试需要。

Element PAPI 的实现基于 jsdom，例如 `__CreateElement` 会返回一个 `LynxElement`，它继承自 jsdom 的 `HTMLElement`。你可以复用 DOM 测试中常用的测试工具，例如 [`@testing-library/dom`](https://github.com/testing-library/dom-testing-library)（用于查询 DOM）和 [`@testing-library/jest-dom`](https://github.com/testing-library/jest-dom)（面向 DOM 的自定义 jest matcher）等。

### `LynxTestingEnv` \{#lynxtestingenv\}

[Lynx 规范](https://lynxjs.org/guide/spec.html) 的纯 JavaScript 实现，
主要包括 [Element PAPI](https://lynxjs.org/api/engine/element-api) 和 [双线程模型](https://lynxjs.org/guide/spec#dual-threaded-model)，供 Node.js 环境使用。

```ts
import { LynxTestingEnv } from '@lynx-js/testing-environment';
import { JSDOM } from 'jsdom';

const lynxTestingEnv = new LynxTestingEnv({ window: new JSDOM().window });

lynxTestingEnv.switchToMainThread();
// use the main thread Element PAPI
const page = __CreatePage('0', 0);
const view = __CreateView(0);
__AppendElement(page, view);

```
