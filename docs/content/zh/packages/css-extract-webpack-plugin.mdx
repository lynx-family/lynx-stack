## 类 \{#\}

### `CssExtractRspackPlugin` \{#cssextractrspackplugin\}

CssExtractRspackPlugin 是 Lynx 的 CSS 提取插件。
其用法与 Web 中的 [CssExtractRspackPlugin](https://rspack.rs/plugins/rspack/css-extract-rspack-plugin.html) 相同。

```js
import { CssExtractRspackPlugin } from '@lynx-js/css-extract-webpack-plugin'
export default {
  plugins: [new CssExtractRspackPlugin()],
  module: {
    rules: [
      {
        test: /\.css$/,
        uses: [CssExtractRspackPlugin.loader, 'css-loader'],
      },
    ],
  },
}
```
