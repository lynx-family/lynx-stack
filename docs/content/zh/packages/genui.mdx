面向 Lynx 应用的生成式 UI 原语。

`@lynx-js/genui` 是 GenUI 工具链唯一的 npm 包。它在一个包中提供 A2UI 渲染、OpenUI 渲染、A2UI prompt/catalog 工具以及 CLI，同时实现目录仍作为此 monorepo 的私有部分。

## 安装

import { PackageManagerTabs } from '@rspress/core/theme';

<PackageManagerTabs command="add @lynx-js/genui" />

### `MessageStore` \{#messagestore\}

一个纯追加式的缓冲区，存放由开发者 IO 模块产生的原始协议消息。该 store 对 v0.9 协议一无所知——它不解析、不处理，也不解释消息，只负责：

 1. 按到达顺序存储消息。
 2. 有新消息到达时通知订阅者。
 3. 通过 `getSnapshot()` 返回当前快照（两次变更之间引用保持稳定——这是 `useSyncExternalStore` 所要求的）。

感知协议的处理——surface、signal、resource、action 分发——由 `<A2UI>`（渲染器组件）负责。不想了解协议的开发者应使用 `<A2UI>`；了解协议的开发者可以直接基于快照运行自己的 `MessageProcessor`。

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| <a id="messagestore-getsnapshot"></a>`getSnapshot` | `() => readonly `[`ServerToClientMessage`](#servertoclientmessage)`[]` | `useSyncExternalStore` 的 getSnapshot 约定——在两次 push 之间保持稳定。 |
| <a id="messagestore-subscribe"></a>`subscribe` | `(cb: () => void) => () => void` | `useSyncExternalStore` 的 subscribe 约定。 |
| <a id="messagestore-clear"></a>`clear` | `clear(): void` | 重置缓冲区，并通知订阅者。 |
| <a id="messagestore-push"></a>`push` | `push(message: ServerToClientMessage \| readonly ServerToClientMessage[]): void` | 向缓冲区追加一条或多条原始消息。每次调用只通知订阅者一次（传入单个数组参数时会合并为一次通知）。 |
