## 函数 \{#\}

### `cssChunksToMap()` \{#csschunkstomap\}

```ts
cssChunksToMap(cssChunks: (string | CSSChunkAsset)[], plugins: Plugin[], enableCSSSelector: boolean): { contentMap: Map<number, string[]>; cssMap: Record<string, LynxStyleNode[]>; cssSource: Record<string, string> }
```

将 CSS chunk 转换为 `cssMap` / `cssSource`。

`loc` 字段保留 bundle CSS 中的坐标，以便后续
通过 `main.css.map` 解析。

`cssSource` 有意保留历史上的 `/cssId/<id>.css` 形式。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `cssChunks` | `(string \| CSSChunkAsset)[]` |  |
| `plugins` | `Plugin[]` |  |
| `enableCSSSelector` | `boolean` |  |

**返回值:** `{ contentMap: Map<number, string[]>; cssMap: Record<string, LynxStyleNode[]>; cssSource: Record<string, string> }`
