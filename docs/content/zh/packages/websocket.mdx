## 类型 \{#\}

### `ReadyState` \{#readystate\}

`ReadyState` 描述 `WebSocket` 连接的状态。

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| <a id="readystate-closed"></a>`CLOSED` | `3` | 连接已关闭或无法打开。 |
| <a id="readystate-closing"></a>`CLOSING` | `2` | 连接正在关闭。 |
| <a id="readystate-connecting"></a>`CONNECTING` | `0` | Socket 已创建，连接尚未打开。 |
| <a id="readystate-open"></a>`OPEN` | `1` | 连接已打开，可以进行通信。 |

### `Event` \{#event\}

`Event` 接口的实现，用于包装给定的事件对象。

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| <a id="event-type"></a>`type` | `T` | 该事件的类型。 |

### `EventMap` \{#eventmap\}

`EventMap` 描述 `@lynx-js/websocket#WebSocket` 可能触发的事件。
