# @lynx-js/motion

{/* @api PackageHeader package="motion" */}

<div className="api-pkg-header"><code>@lynx-js/motion</code> <span className="api-pkg-version">v0.0.6</span> · <a href="https://www.npmjs.com/package/@lynx-js/motion" target="_blank" rel="noopener">npm</a> · <a href="https://github.com/lynx-family/lynx-stack/tree/main/packages/motion" target="_blank" rel="noopener">源码</a> · <a href="https://github.com/lynx-family/lynx-stack/tree/main/packages/motion/CHANGELOG.md" target="_blank" rel="noopener">更新日志</a></div>

一个功能强大的 Lynx 动画库，移植自 [Motion for React (framer-motion)](https://motion.dev/)，为 Lynx 生态带来声明式动画和手势处理能力。

## 安装

import { PackageManagerTabs } from '@rspress/core/theme';

<PackageManagerTabs command="add @lynx-js/motion" />
