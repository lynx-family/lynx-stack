# output.legalComments

{/* @api ConfigOption package="rspeedy" path="output.legalComments" */}

- **类型:** `"none" | "inline" | "linked"`
- **Lynx 默认值:** `'none'`
- **Rsbuild 默认值:** `'linked'`

`Output.legalComments` 用于控制如何处理法律注释（legal comment）。

这是标准的 Rsbuild 配置，在 Lynx 构建中默认值不同。完整说明请查看 [Rsbuild 文档](https://rsbuild.rs/zh/config/output/legal-comments)。
