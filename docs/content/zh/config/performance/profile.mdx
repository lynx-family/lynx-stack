# performance.profile

{/* @api ConfigOption package="rspeedy" path="performance.profile" */}

- **类型：** `boolean`

是否在 ReactLynx 等 Lynx 运行时集成中采集耗时信息。

启用 profile。

- ReactLynx 等框架会通过 `console.profile` 输出运行时信息。
- Rspeedy 会在构建后输出 `dist/stats.json`，以兼容 bundle 分析工具。

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: { profile: true },
})
```

## 默认值 \{#default\}

- 当 `DEBUG` 包含 `rspeedy` 时，Rspeedy 会将其设置为 `true`；否则不设置该选项。

## 使用方式 \{#usage\}

使用 Rsbuild 构建时，将它传给 [`pluginLynx`](/zh/packages/rsbuild-plugin#performance-profile)：

```ts title="rsbuild.config.ts"
import { defineConfig } from '@rsbuild/core'
import { pluginLynx } from '@lynx-js/rsbuild-plugin'

export default defineConfig({
  plugins: [
    pluginLynx({
      performance: {
        profile: true,
      },
    }),
  ],
})
```

使用 Rspeedy 时，在 `lynx.config.ts` 中设置：

```ts title="lynx.config.ts"
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: {
    profile: true,
  },
})
```
