# splitChunks

{/* @api ConfigOption package="rspeedy" path="splitChunks" */}

- **类型:** `false | SplitChunksConfig`
- **Lynx 默认值:** Rspeedy 默认将其设置为 `false`；如果进行了配置，则由 Rsbuild 的顶层 `splitChunks` 选项处理。 详见 [Rsbuild - splitChunks](https://rsbuild.rs/config/split-chunks)。

配置 chunk 拆分。

这是标准的 Rsbuild 配置，在 Lynx 构建中默认值不同。完整说明请查看 [Rsbuild 文档](https://rsbuild.rs/zh/config/split-chunks)。
