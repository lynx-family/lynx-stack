# performance

在构建产物与运行时性能之间进行取舍的选项：chunk 拆分、移除 console、运行时性能分析以及 bundle 分析器。

其中大多数是标准的 Rsbuild 配置：在 `rsbuild.config.ts` 的 `performance` 下设置，使用 Rspeedy 构建时则在 `lynx.config.ts` 中设置，详细说明请查看 Rsbuild 文档。Lynx 特有的配置项在下文完整说明，并注明使用 Rsbuild 构建时应在哪里设置。

{/* @api ConfigOptions package="rspeedy" type="Config" path="performance" */}

## Lynx 特有配置 \{#lynx-options\}

### `performance.profile` \{#performance-profile\}

- **类型:** `boolean`
- **默认值:** 当 `DEBUG` 包含 `rspeedy` 时，Rspeedy 会将其设置为 `true`；否则不设置该选项。

是否在 ReactLynx 等 Lynx 运行时集成中采集耗时信息。

启用 profile。

- ReactLynx 等框架会通过 `console.profile` 输出运行时信息。
- Rspeedy 会在构建后输出 `dist/stats.json`，以兼容 bundle 分析工具。

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: { profile: true },
})
```

使用 Rsbuild 构建时，将此选项传给 [`pluginLynx`](/zh/plugins/plugin-lynx#performance-profile)。
