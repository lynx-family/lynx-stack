# tools.rsdoctor

{/* @api ConfigOption package="rspeedy" path="tools.rsdoctor" */}

- **类型：** `RsdoctorRspackPluginOptions`

`Tools.rsdoctor` 用于控制 [Rsdoctor](https://rsdoctor.dev/) 的选项。

设置 `RSDOCTOR=true` 可启用 Rsdoctor。启用后，Rspeedy 会在配置规范化阶段合并额外的插件默认配置。

- 使用内置的 Rsdoctor。

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    rsdoctor: {
      disableClientServer: true,
    },
  },
})
```

详见 [Rsdoctor - Configuration](https://rsdoctor.dev/config/options/options)。

## 使用方式 \{#usage\}

仅在 `lynx.config.ts`（Rspeedy）中可用：

```ts title="lynx.config.ts"
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    rsdoctor: {},
  },
})
```
