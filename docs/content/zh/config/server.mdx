# server

开发期间向设备提供 bundle 的本地服务器相关选项：host、端口、响应头和基础路径。

它们都是标准的 Rsbuild 配置：在 `rsbuild.config.ts` 的 `server` 下设置，使用 Rspeedy 构建时则在 `lynx.config.ts` 中设置。每一项都链接到 Rsbuild 文档，与 Rsbuild 默认值不同时注明 Lynx 的默认值。

## 概览

{/* @api ConfigOverview package="rspeedy" type="Config" path="server" */}

| 名称 | 类型 | 说明 |
| --- | --- | --- |
| [`base`](#server-base) | `string` | 配置服务器的基础路径。 |
| [`compress`](#server-compress) | `boolean \| CompressOptions` | 配置是否对开发服务器或预览服务器提供的静态资源启用 [gzip 压缩](https://developer.mozilla.org/en-US/docs/Glossary/gzip_compression)。 |
| [`cors`](#server-cors) | `boolean \| CorsOptions` | 为开发服务器或预览服务器配置 CORS。 |
| [`headers`](#server-headers) | `Record<string, string \| string[]>` (来自 typescript) | 为所有响应添加响应头。 |
| [`host`](#server-host) | `string` | 指定 Rspeedy Server 监听的 host。 |
| [`port`](#server-port) | `number` | 指定 Rspeedy Server 监听的端口。 |
| [`proxy`](#server-proxy) | `ProxyConfig` (来自 [@rsbuild/core](https://rsbuild.rs/config/)) | 为开发服务器或预览服务器配置代理规则，将请求代理到指定的服务。 |
| [`strictPort`](#server-strictport) | `boolean` | 当端口被占用时，Rspeedy 会自动递增端口号，直到找到可用的端口。 |

## Rsbuild 配置 \{#rsbuild-options\}

以下是标准的 Rsbuild 配置。与 Rsbuild 默认值不同时会列出 Lynx 的默认值，详细说明请查看 Rsbuild 文档。

| 名称 | 类型 | Lynx 默认值 | 说明 |
| --- | --- | --- | --- |
| <a id="server-base"></a>`base` | `string` |  | 配置服务器的基础路径。 [Rsbuild 文档](https://rsbuild.rs/zh/config/server/base) |
| <a id="server-compress"></a>`compress` | `boolean \| CompressOptions` |  | 配置是否对开发服务器或预览服务器提供的静态资源启用 [gzip 压缩](https://developer.mozilla.org/en-US/docs/Glossary/gzip_compression)。 [Rsbuild 文档](https://rsbuild.rs/zh/config/server/compress) |
| <a id="server-cors"></a>`cors` | `boolean \| CorsOptions` | 使用 Rsbuild 默认的 CORS 选项。 - 设置为对象时，使用指定的选项启用 CORS。 - 设置为 `true` 时，使用默认选项启用 CORS（允许所有来源，不推荐）。 - 设置为 `false` 时，禁用 CORS。 详见 [Rsbuild - server.cors](https://rsbuild.rs/config/server/cors)。 | 为开发服务器或预览服务器配置 CORS。 [Rsbuild 文档](https://rsbuild.rs/zh/config/server/cors) |
| <a id="server-headers"></a>`headers` | `Record<string, string \| string[]>` (来自 typescript) |  | 为所有响应添加响应头。 [Rsbuild 文档](https://rsbuild.rs/zh/config/server/headers) |
| <a id="server-host"></a>`host` | `string` | `"0.0.0.0"` | 指定 Rspeedy Server 监听的 host。 [Rsbuild 文档](https://rsbuild.rs/zh/config/server/host) |
| <a id="server-port"></a>`port` | `number` | Rsbuild 默认将该选项设置为 `3000`。 | 指定 Rspeedy Server 监听的端口。 [Rsbuild 文档](https://rsbuild.rs/zh/config/server/port) |
| <a id="server-proxy"></a>`proxy` | `ProxyConfig` (来自 [@rsbuild/core](https://rsbuild.rs/config/)) |  | 为开发服务器或预览服务器配置代理规则，将请求代理到指定的服务。 [Rsbuild 文档](https://rsbuild.rs/zh/config/server/proxy) |
| <a id="server-strictport"></a>`strictPort` | `boolean` | `false By default, strict port mode is disabled. Set strictPort to true and Rspeedy will throw an exception when the port is occupied.` | 当端口被占用时，Rspeedy 会自动递增端口号，直到找到可用的端口。 [Rsbuild 文档](https://rsbuild.rs/zh/config/server/strict-port) |
