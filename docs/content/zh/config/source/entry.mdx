# source.entry

{/* @api ConfigOption package="rspeedy" path="source.entry" */}

- **类型:** `Entry`
- **Lynx 默认值:** `'./src/index.js'`
- **Rsbuild 默认值:** `{ index: './src/index.js', }`

`Entry` 选项用于设置入口模块。

这是标准的 Rsbuild 配置，在 Lynx 构建中默认值不同。完整说明请查看 [Rsbuild 文档](https://rsbuild.rs/zh/config/source/entry)。

{/* @api-end */}
