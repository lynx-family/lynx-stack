# plugins

要应用的 Rsbuild 插件列表。即标准的 [Rsbuild `plugins` 配置](https://rsbuild.rs/zh/config/plugins)。使用 Rsbuild 构建时，在这里加入 [`pluginLynx`](/zh/plugins/plugin-lynx) 或 [`pluginReactLynx`](/zh/plugins/plugin-react) 等 DSL 插件；Rspeedy 会在这里列出的插件之前自动应用 `pluginLynx`。

{/* @api ConfigOptions package="rspeedy" type="Config" path="plugins" */}

## Rsbuild 配置 \{#rsbuild-options\}

以下是标准的 Rsbuild 配置。与 Rsbuild 默认值不同时会列出 Lynx 的默认值，详细说明请查看 Rsbuild 文档。

| 名称 | 类型 | Lynx 默认值 | 说明 |
| --- | --- | --- | --- |
| <a id="plugins"></a>`plugins` | `RsbuildPlugins` (来自 [@rsbuild/core](https://rsbuild.rs/config/)) |  | `plugins` 选项用于以多种方式自定义构建流程。 [Rsbuild 文档](https://rsbuild.rs/zh/config/plugins) |

{/* @api-end */}
