# splitChunks

Chunk 拆分。即标准的 [Rsbuild `splitChunks` 配置](https://rsbuild.rs/zh/config/split-chunks)。Rspeedy 默认将其设为 `false`；启用后会关闭 `output.inlineScripts`，使后台线程的 chunk 作为独立文件输出。

{/* @api ConfigOptions package="rspeedy" type="Config" path="splitChunks" */}

## Rsbuild 配置 \{#rsbuild-options\}

以下是标准的 Rsbuild 配置。与 Rsbuild 默认值不同时会列出 Lynx 的默认值，详细说明请查看 Rsbuild 文档。

| 名称 | 类型 | Lynx 默认值 | 说明 |
| --- | --- | --- | --- |
| <a id="splitchunks"></a>`splitChunks` | `false \| SplitChunksConfig` | Rspeedy 默认将其设置为 `false`；如果进行了配置，则由 Rsbuild 的顶层 `splitChunks` 选项处理。 详见 [Rsbuild - splitChunks](https://rsbuild.rs/config/split-chunks)。 | 配置 chunk 拆分。 [Rsbuild 文档](https://rsbuild.rs/zh/config/split-chunks) |

{/* @api-end */}
