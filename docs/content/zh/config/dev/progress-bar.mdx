# dev.progressBar

{/* @api ConfigOption package="rspeedy" path="dev.progressBar" */}

- **类型:** `boolean | { id?: string }`
- **Lynx 默认值:** `true`
- **Rsbuild 默认值:** `false`

是否在编译过程中显示进度条。

这是标准的 Rsbuild 配置，在 Lynx 构建中默认值不同。完整说明请查看 [Rsbuild 文档](https://rsbuild.rs/zh/config/dev/progress-bar)。

{/* @api-end */}
