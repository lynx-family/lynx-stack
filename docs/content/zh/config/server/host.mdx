# server.host

{/* @api ConfigOption package="rspeedy" path="server.host" */}

- **类型:** `string`
- **Lynx 默认值:** `"0.0.0.0"`
- **Rsbuild 默认值:** `'localhost'`

指定 Rspeedy Server 监听的 host。

这是标准的 Rsbuild 配置，在 Lynx 构建中默认值不同。完整说明请查看 [Rsbuild 文档](https://rsbuild.rs/zh/config/server/host)。

{/* @api-end */}
