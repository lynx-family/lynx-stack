# source

控制构建输入的选项：入口、`define` 常量、`include`/`exclude` 规则，以及从 `tsconfig.json` 读取的 TypeScript 路径别名。

其中大多数是标准的 Rsbuild 配置：在 `rsbuild.config.ts` 的 `source` 下设置，使用 Rspeedy 构建时则在 `lynx.config.ts` 中设置，详细说明请查看 Rsbuild 文档。Lynx 特有的配置项在下文完整说明，并注明使用 Rsbuild 构建时应在哪里设置。
