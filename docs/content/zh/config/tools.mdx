# tools

直接操作底层工具的途径：当某个选项没有暴露时，可以直接修改 Rspack 配置、SWC 选项或 Rsbuild 配置。

其中大多数是标准的 Rsbuild 配置：在 `rsbuild.config.ts` 的 `tools` 下设置，使用 Rspeedy 构建时则在 `lynx.config.ts` 中设置，详细说明请查看 Rsbuild 文档。Lynx 特有的配置项在下文完整说明，并注明使用 Rsbuild 构建时应在哪里设置。

{/* @api ConfigOptions package="rspeedy" type="Config" path="tools" */}

## Lynx 特有配置 \{#lynx-options\}

### `tools.rsdoctor` \{#tools-rsdoctor\}

- **类型:** [`RsdoctorRspackPluginOptions`](#tools-rsdoctor)
- **默认值:** `undefined`

`Tools.rsdoctor` 用于控制 [Rsdoctor](https://rsdoctor.dev/) 的选项。

设置 `RSDOCTOR=true` 可启用 Rsdoctor。启用后，Rspeedy 会在配置规范化阶段合并额外的插件默认配置。

- 使用内置的 Rsdoctor。

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    rsdoctor: {
      disableClientServer: true,
    },
  },
})
```

详见 [Rsdoctor - Configuration](https://rsdoctor.dev/config/options/options)。

仅在 `lynx.config.ts`（Rspeedy）中可用。

| 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| <a id="tools-rsdoctor-linter"></a>`linter` | `{ extends?: unknown[]; level?: "Ignore" \| "Warn" \| "Error"; rules?: Record<string, unknown> }` |  |  |

## Rsbuild 配置 \{#rsbuild-options\}

以下是标准的 Rsbuild 配置。与 Rsbuild 默认值不同时会列出 Lynx 的默认值，详细说明请查看 Rsbuild 文档。

| 名称 | 类型 | Lynx 默认值 | 说明 |
| --- | --- | --- | --- |
| <a id="tools-bundlerchain"></a>`bundlerChain` | `ToolsBundlerChainConfig` (来自 [@rsbuild/core](https://rsbuild.rs/config/)) |  | `Tools.bundlerChain` 通过 [rspack-chain](https://github.com/rspack-contrib/rspack-chain) 修改 [Rspack](https://rspack.rs) 的选项。 [Rsbuild 文档](https://rsbuild.rs/zh/config/tools/bundler-chain) |
| <a id="tools-cssextract"></a>`cssExtract` | [`CssExtract`](#tools-cssextract) |  | [`CssExtract`](#tools-cssextract) 用于控制 [CssExtractRspackPlugin](https://rspack.rs/plugins/rspack/css-extract-rspack-plugin) 的选项。 [Rsbuild 文档](https://rsbuild.rs/zh/config/tools/css-extract) |
| <a id="tools-cssloader"></a>`cssLoader` | [`CssLoader`](#tools-cssloader) | 使用基于 `output.cssModules` 和 `output.sourceMap` 推导出的默认值，其中 CSS 文件的 `importLoaders` 设置为 `1`，Sass/Less 文件设置为 `2`。 | [`CssLoader`](#tools-cssloader) 用于控制 [css-loader](https://github.com/webpack-contrib/css-loader) 的选项。 [Rsbuild 文档](https://rsbuild.rs/zh/config/tools/css-loader) |
| <a id="tools-rspack"></a>`rspack` | `ToolsRspackConfig` (来自 [@rsbuild/core](https://rsbuild.rs/config/)) |  | `Tools.rspack` 用于控制 [Rspack](https://rspack.rs/) 的选项。 [Rsbuild 文档](https://rsbuild.rs/zh/config/tools/rspack) |
| <a id="tools-swc"></a>`swc` | `ToolsSwcConfig` (来自 [@rsbuild/core](https://rsbuild.rs/config/)) |  | `Tools.swc` 用于控制 [builtin:swc-loader](https://rspack.rs/guide/features/builtin-swc-loader) 的选项。 [Rsbuild 文档](https://rsbuild.rs/zh/config/tools/swc) |
