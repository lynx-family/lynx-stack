Rslib 配置辅助工具，用于借助 `@rslib/core` 将 Lynx bundle 构建为库产物。

## 安装

import { PackageManagerTabs } from '@rspress/core/theme';

<PackageManagerTabs command="add @lynx-js/lynx-bundle-rslib-config -D" />

## 用法

```ts title="rslib.config.ts"
import { defineConfig } from '@rslib/core'
import { defineExternalBundleRslibConfig } from '@lynx-js/lynx-bundle-rslib-config'

export default defineConfig({
  ...defineExternalBundleRslibConfig({ /* ExternalBundleLibConfig */ }),
})
```

## 函数 \{#\}

### `defineExternalBundleRslibConfig()` \{#defineexternalbundlerslibconfig\}

```ts
defineExternalBundleRslibConfig(userLibConfig: ExternalBundleLibConfig, encodeOptions: EncodeOptions): RslibConfig
```

获取用于构建 Lynx external bundle 的 Rslib 配置。

如果要构建在 Lynx 后台线程中使用的 external bundle，可以使用以下代码：

```js
// rslib.config.js
import { defineExternalBundleRslibConfig } from '@lynx-js/lynx-bundle-rslib-config'

export default defineExternalBundleRslibConfig({
  id: 'utils-lib',
  source: {
    entry: {
      utils: {
        import: './src/utils.ts',
        layer: 'background',
      }
    }
  }
})
```

然后即可在后台线程中使用 `lynx.loadScript('utils', { bundleName: 'utils-lib-bundle-url' })`。

如果要构建在 Lynx 主线程中使用的 external bundle，可以使用以下代码：

```js
// rslib.config.js
import { defineExternalBundleRslibConfig } from '@lynx-js/lynx-bundle-rslib-config'

export default defineExternalBundleRslibConfig({
  id: 'utils-lib',
  source: {
    entry: {
      utils: {
        import: './src/utils.ts',
        layer: 'main-thread',
      }
    }
  }
})
```

然后即可在主线程中使用 `lynx.loadScript('utils', { bundleName: 'utils-lib-bundle-url' })`。

如果要构建同时在 Lynx 主线程和后台线程中使用的 external bundle，无需设置 layer。

```js
// rslib.config.js
import { defineExternalBundleRslibConfig } from '@lynx-js/lynx-bundle-rslib-config'

export default defineExternalBundleRslibConfig({
  id: 'utils-lib',
  source: {
    entry: {
      utils: './src/utils.ts',
    },
  }
})
```

然后即可在后台线程中使用 `lynx.loadScript('utils', { bundleName: 'utils-lib-bundle-url' })`，在主线程中使用 `lynx.loadScript('utils__main-thread', { bundleName: 'utils-lib-bundle-url' })`。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `userLibConfig` | `ExternalBundleLibConfig` |  |
| `encodeOptions` | `EncodeOptions` |  |

**返回值:** `RslibConfig`

### `ExternalObject` \{#externalobject\}

external 映射的对象形式。

当外部库由使用方应用异步（以 Promise 形式）挂载时，即
对应的 `pluginExternalBundle` external 配置了 `async: true` 时，
使用该形式替代普通的全局名称形式。

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| <a id="externalobject-async"></a>`async?` | `boolean` | 库是否以 Promise 的形式挂载，该 Promise resolve 为库的 命名空间。启用后，该 external 会作为 `promise` external 产出， 导入它的模块会 await 挂载的值，而不是同步 读取。 |
| <a id="externalobject-libraryname"></a>`libraryName` | `string \| string[]` | 外部库的全局名称（可包含子路径）。 |

### `ExternalsPresets` \{#externalspresets\}

```ts
type ExternalsPresets = { reactlynx?: ExternalsPresetValue } & Record<string, ExternalsPresetValue>
```

已启用的 externals 预设。

预设名称会从内置预设定义以及传给
[`defineExternalBundleRslibConfig`](#defineexternalbundlerslibconfig) 的自定义定义中解析。

### `ExternalsPresetValue` \{#externalspresetvalue\}

```ts
type ExternalsPresetValue = boolean | { async?: boolean }
```

externals 预设的启用方式。

`true` 会同步挂载该预设的库。`{ async: true }`
对象形式会异步（以 Promise 形式）挂载它们，适用于 web 目标，
该目标下 external bundle 通过 `fetchBundle().then` 加载，参见
[`ExternalObject.async`](#externalobject)。
