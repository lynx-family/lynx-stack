# pluginReactAlias

{/* @api PackageHeader package="react-alias-rsbuild-plugin" */}

将 `react` 和 `react-dom` 的导入通过别名指向 `@lynx-js/react`，使基于 React 编写的库解析到 ReactLynx 运行时。

## 安装

import { PackageManagerTabs } from '@rspress/core/theme';

<PackageManagerTabs command="add @lynx-js/react-alias-rsbuild-plugin -D" />

## 用法

```ts title="lynx.config.ts"
import { defineConfig } from '@lynx-js/rspeedy'
import { pluginReactAlias } from '@lynx-js/react-alias-rsbuild-plugin'

export default defineConfig({
  plugins: [pluginReactAlias()],
})
```
