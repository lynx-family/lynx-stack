# pluginReactLynx

{/* @api PackageHeader package="react-rsbuild-plugin" */}

<div className="api-pkg-header"><code>@lynx-js/react-rsbuild-plugin</code> <span className="api-pkg-version">v0.20.1</span> · <a href="https://www.npmjs.com/package/@lynx-js/react-rsbuild-plugin" target="_blank" rel="noopener">npm</a> · <a href="https://github.com/lynx-family/lynx-stack/tree/main/packages/rspeedy/plugin-react" target="_blank" rel="noopener">源码</a> · <a href="https://github.com/lynx-family/lynx-stack/tree/main/packages/rspeedy/plugin-react/CHANGELOG.md" target="_blank" rel="noopener">更新日志</a></div>

ReactLynx 的 DSL 插件。它将 JSX 编译为 ReactLynx 的双线程产物，接入运行时，并在开发环境下启用 Fast Refresh。构建引擎尚未注册时，它会自动注册 [`pluginLynx`](/zh/rspeedy/plugins/plugin-lynx)。

## 安装

import { PackageManagerTabs } from '@rspress/core/theme';

<PackageManagerTabs command="add @lynx-js/react-rsbuild-plugin -D" />

## 用法

```ts title="lynx.config.ts"
import { defineConfig } from '@lynx-js/rspeedy'
import { pluginReactLynx } from '@lynx-js/react-rsbuild-plugin'

export default defineConfig({
  plugins: [pluginReactLynx()],
})
```

## 选项

{/* @api ApiOptions package="react-rsbuild-plugin" type="PluginReactLynxOptions" */}

### `compat` \{#compat\}

- **类型:** `Partial<`[`CompatVisitorConfig`](#compatvisitorconfig)`> & { disableCreateSelectorQueryIncompatibleWarning?: boolean }`
- **默认值:** `undefined`

`compat` 选项用于控制与旧版 ReactLynx 的兼容性。

这些选项仅应在从 ReactLynx2.0 迁移或
面向旧版 ReactLynx3 运行时时使用。

### `customCSSInheritanceList` \{#customcssinheritancelist\}

- **类型:** `string[]`
- **默认值:** `undefined`

启用 [`PluginReactLynxOptions.enableCSSInheritance`](#enablecssinheritance) 后，可以通过 `customCSSInheritanceList` 控制哪些属性可继承，而不仅限于默认属性。

设置 `customCSSInheritanceList: ['direction', 'overflow']` 后，只有 `direction` 和 `overflow` 属性可继承。

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
 plugins: [
   pluginReactLynx({
     enableCSSInheritance: true,
     customCSSInheritanceList: ['direction', 'overflow']
   }),
 ],
}
```

### `debugInfoOutside` \{#debuginfooutside\}

- **类型:** `boolean`
- **默认值:** `true`

debugInfoOutside 控制调试信息是否放在模板之外。

推荐设置为 true 以减小模板体积。

### `enableCSSInheritance` \{#enablecssinheritance\}

- **类型:** `boolean`
- **默认值:** `false`

enableCSSInheritance 用于启用默认的继承属性。

以下属性默认可继承：

- `direction`

- `color`

- `font-family`

- `font-size`

- `font-style`

- `font-weight`

- `letter-spacing`

- `line-height`

- `line-spacing`

- `text-align`

- `text-decoration`

- `text-shadow`

推荐与 [`PluginReactLynxOptions.customCSSInheritanceList`](#customcssinheritancelist) 一起使用，以避免性能问题。

### `enableCSSInvalidation` \{#enablecssinvalidation\}

- **类型:** `boolean`
- **默认值:** `true`

CSS Invalidation 是指在 DOM 更新时，确定哪些元素需要重新计算样式的过程。

当使用组合器（combinator）确定各元素的样式（包括后代、相邻兄弟等）时，推荐启用此功能。否则只有初始设置的 class 能匹配对应的组合器，后续更新不会重新计算相关样式。

我们发现收集 invalidation 节点并进行更新是一个相对耗时的过程。
如果没有此类用法，且需要更好的样式匹配性能，可以选择性地关闭此功能。

```ts
If a descendant selector `.a .b` is defined in a CSS file, then when an element's class changes to `.a`, all nodes in its subtree with the className `.b` need to have their styles recalculated.
```

### `experimental_transformBuiltinAttributeNames` <span className="api-badge api-badge-beta">实验性</span> \{#experimental-transformbuiltinattributenames\}

- **类型:** `boolean | `[`TransformBuiltinAttributeNamesOptions`](#experimental-transformbuiltinattributenames)
- **默认值:** `false`

转换 Lynx 内置元素上的属性名。

`false` 表示禁用转换。`true` 表示应用默认规则：
`onClick` 变为 `bindtap`，`onCatchTap` 变为 `catchtap`，其他
`onXXX` 名称变为 `bindxxx`，其余 camelCase 名称变为
dash-case。传入对象时可提供可序列化的自定义规则。`rename` 中的精确条目
优先于 `preserve`，其次是由 `mode` 选择的
兜底行为。

显式的 JSX 属性会在编译时转换。通过 JSX spread 传入的
属性会在运行时按照相同的
规则转换。

| 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| <a id="experimental-transformbuiltinattributenames-mode"></a>`mode` | `"dash-case" \| "mapping-only"` | `'dash-case'` | 未在 `rename` 或 `preserve` 中列出的属性名的兜底行为。 `'dash-case'` 还会应用默认的 React 风格事件映射。 `'mapping-only'` 会保持其余名称不变。 |
| <a id="experimental-transformbuiltinattributenames-preserve"></a>`preserve` | `readonly string[]` |  | 应保持不变的属性名，除非同时存在精确的 `rename` 条目。 |
| <a id="experimental-transformbuiltinattributenames-rename"></a>`rename` | `Readonly<Record<string, string>>` (来自 typescript) |  | 从源属性名到转换后属性名的精确映射。 |

### `TemplateHooks` \{#templatehooks\}

为了让其他插件能够修改 Template，此插件会执行
[tapable](https://github.com/webpack/tapable) hooks。

```js
class MyPlugin {
  apply(compiler) {
    compiler.hooks.compilation.tap("MyPlugin", (compilation) => {
      console.log("The compiler is starting a new compilation...");

      LynxTemplatePlugin.getLynxTemplatePluginHooks(compilation).beforeEmit.tapAsync(
        "MyPlugin", // <-- Set a meaningful name here for stacktraces
        (data, cb) => {
          // Manipulate the content
          modifyTemplate(data.template)
          // Tell webpack to move on
          cb(null, data);
        },
      );
    });
  }
}
```
