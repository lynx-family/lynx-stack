# tools

直接操作底层工具的途径：当某个选项未由 Rspeedy 暴露时，可以直接修改 Rspack 配置、SWC 选项或 Rsbuild 配置。

## 选项

{/* @api ConfigOptions package="rspeedy" type="Config" path="tools" */}

### `tools.bundlerChain` \{#tools-bundlerchain\}

- **类型:** `ToolsBundlerChainConfig` (来自 [@rsbuild/core](https://rsbuild.rs/config/))
- **默认值:** `undefined`

[`Tools.bundlerChain`](#tools-bundlerchain) 通过 [rspack-chain](https://github.com/rspack-contrib/rspack-chain) 修改 [Rspack](https://rspack.rs) 的选项。

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    bundlerChain(chain) {
      chain.resolve.fullySpecified(true)
    },
  },
})
```

详见 [rspack-chain](https://github.com/rspack-contrib/rspack-chain)。

### `tools.cssExtract` \{#tools-cssextract\}

- **类型:** [`CssExtract`](#tools-cssextract)
- **默认值:** `undefined`

[`CssExtract`](#tools-cssextract) 用于控制 [CssExtractRspackPlugin](https://rspack.rs/plugins/rspack/css-extract-rspack-plugin) 的选项。

#### `tools.cssExtract.loaderOptions` \{#tools-cssextract-loaderoptions\}

- **类型:** [`CssExtractRspackLoaderOptions`](#tools-cssextract-loaderoptions)
- **默认值:** `undefined`

`@lynx-js/css-extract-webpack-plugin#LoaderOptions`

##### `tools.cssExtract.loaderOptions.esModule` \{#tools-cssextract-loaderoptions-esmodule\}

- **类型:** `boolean`
- **默认值:** `true`

与 [https://github.com/webpack-contrib/mini-css-extract-plugin#esModule](https://github.com/webpack-contrib/mini-css-extract-plugin#esModule) 相同。
默认情况下，`@lynx-js/css-extract-webpack-plugin` 会生成使用 ES modules 语法的 JS 模块。
在某些情况下使用 ES modules 会更有优势，
例如模块合并（module concatenation）和 tree shaking。

你可以通过以下方式启用 CommonJS 语法：

```js
import {CssExtractRspackPlugin} from "@lynx-js/css-extract-webpack-plugin";
export default {
  plugins: [new CssExtractRspackPlugin()],
  module: {
    rules: [
      {
        test: /\.css$/i,
        use: [
          {
            loader: CssExtractRspackPlugin.loader,
            options: {
              esModule: false,
            },
          },
          "css-loader",
        ],
      },
    ],
  },
};
```

### `tools.cssLoader` \{#tools-cssloader\}

- **类型:** [`CssLoader`](#tools-cssloader)
- **默认值:** 使用基于 `output.cssModules` 和 `output.sourceMap` 推导出的默认值，其中 CSS 文件的 `importLoaders` 设置为 `1`，Sass/Less 文件设置为 `2`。

[`CssLoader`](#tools-cssloader) 用于控制 [css-loader](https://github.com/webpack-contrib/css-loader) 的选项。

默认选项如下：

```js
const defaultOptions = {
  modules: {
    auto: true,
    namedExport: false,
    exportLocalsConvention: 'camelCase',
    localIdentName: output.cssModules.localIdentName,
  },
  sourceMap: output.sourceMap,
  // importLoaders is `1` when compiling css files, and is `2` when compiling sass/less files
  importLoaders: 1 || 2,
};
```

#### `tools.cssLoader.importLoaders` \{#tools-cssloader-importloaders\}

- **类型:** `0 | 1 | 2`
- **默认值:** 编译 CSS 文件时为 `1`，编译 Sass 或 Less 文件时为 `2`

`importLoaders` 选项用于配置在 `css-loader` 之前，有多少个 loader 应用于 `@imported` 资源和 CSS Modules 导入。

详见 [css-loader#import-loaders](https://github.com/webpack-contrib/css-loader?tab=readme-ov-file#importloaders)。

#### `tools.cssLoader.modules` \{#tools-cssloader-modules\}

- **类型:** `boolean | "local" | "global" | "pure" | "icss" | CssLoaderModules`
- **默认值:** 启用 CSS Modules，自动识别 `*.module.*` 文件，使用 camelCase 导出、`namedExport: false`，`localIdentName` 继承自 `output.cssModules.localIdentName`。

[`cssLoader.modules`](#cssloadermodules) 选项用于启用/禁用 CSS Modules 规范，并设置基本行为。

使用 `false` 值可以提升性能，因为这样会跳过对 CSS Modules 特性的解析，适用于使用原生 CSS 或其他技术的开发者。

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    cssLoader: {
      modules: false,
    },
  },
})
```

使用 `() => true` 值为所有文件启用 CSS Modules。

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    cssLoader: {
      modules: () => true,
    },
  },
})
```

使用对象值，基于 [`CssLoaderModules.auto`](#cssloadermodules-auto) 选项启用 CSS Modules，并对 CSS Modules 进行更多配置。

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    cssLoader: {
      modules: {
        namedExport: true,
      },
    },
  },
})
```

### `tools.rsdoctor` \{#tools-rsdoctor\}

- **类型:** [`RsdoctorRspackPluginOptions`](#tools-rsdoctor)
- **默认值:** `undefined`

[`Tools.rsdoctor`](#tools-rsdoctor) 用于控制 [Rsdoctor](https://rsdoctor.dev/) 的选项。

设置 `RSDOCTOR=true` 可启用 Rsdoctor。启用后，Rspeedy 会在配置规范化阶段合并额外的插件默认配置。

- 使用内置的 Rsdoctor。

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    rsdoctor: {
      disableClientServer: true,
    },
  },
})
```

详见 [Rsdoctor - Configuration](https://rsdoctor.dev/config/options/options)。

| 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| <a id="tools-rsdoctor-linter"></a>`linter` | `{ extends?: unknown[]; level?: "Ignore" \| "Warn" \| "Error"; rules?: Record<string, unknown> }` |  |  |

### `tools.rspack` \{#tools-rspack\}

- **类型:** `ToolsRspackConfig` (来自 [@rsbuild/core](https://rsbuild.rs/config/))
- **默认值:** `undefined`

[`Tools.rspack`](#tools-rspack) 用于控制 [Rspack](https://rspack.rs/) 的选项。

- 使用对象配置

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    rspack: {
      resolve: {
        fullySpecified: true,
      },
    },
  },
})
```

详见 [Rspack - Configuration](https://rspack.rs/config/index)。

- 使用函数形式并借助 `env` 工具函数

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    rspack(config, { env }) {
      if (env === 'development') {
        config.devtool = 'cheap-source-map'
      }
      return config
    },
  },
})
```

详见 [Rsbuild - tools.rspack](https://rsbuild.rs/config/tools/rspack#env)。

- 使用函数形式并借助 `mergeConfig` 工具函数

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    rspack(config, { mergeConfig }) {
      return mergeConfig(config, {
        resolve: {
          fullySpecified: true,
        },
      })
    },
  },
})
```

详见 [Rsbuild - tools.rspack](https://rsbuild.rs/config/tools/rspack#mergeconfig)。

- 使用函数形式并借助 `appendPlugins` 工具函数

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    rspack(config, { appendPlugins, rspack }) {
      appendPlugins(new rspack.BannerPlugin({ banner: 'Hello, World!' }))
      return config
    },
  },
})
```

详见 [Rsbuild - tools.rspack](https://rsbuild.rs/config/tools/rspack#appendplugins)。
