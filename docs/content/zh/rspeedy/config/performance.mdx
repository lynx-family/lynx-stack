# performance

在构建产物与运行时性能之间进行取舍的选项：chunk 拆分、移除 console、运行时性能分析以及 bundle 分析器。

## 选项

{/* @api ConfigOptions package="rspeedy" type="Config" path="performance" */}

### `performance.buildCache` <span className="api-badge api-badge-beta">Beta</span> \{#performance-buildcache\}

- **类型:** `boolean | BuildCache`
- **默认值:** ```ts
false

@beta This feature is experimental and may be changed in the future.
```

启用或配置持久化构建缓存。

启用持久化构建缓存。

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: {
    buildCache: true,
  },
})
```

自定义构建缓存。

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: {
    buildCache: {
      cacheDigest: [process.env.SOME_ENV],
      buildDependencies: ['postcss.config.js'],
    },
  },
})
```

### `performance.printFileSize` \{#performance-printfilesize\}

- **类型:** `boolean | PrintFileSizeOptions`
- **默认值:** true

[`Performance.printFileSize`](#performance-printfilesize)

详见 [Rsbuild - performance.printFileSize](https://rsbuild.rs/config/performance/print-file-size)。

是否在生产环境构建后打印文件大小。

如果不想打印任何信息，可以将 printFileSize 设置为 false 来禁用：

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: {
    printFileSize: false
  },
})
```

将 total 设置为 false 以禁用总大小的输出。

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: {
    printFileSize: {
      total: false,
    },
  },
})
```

将 detail 设置为 false 以禁用每个资源大小的输出。

如果不需要查看每个静态资源的大小，可以将 detail 设置为 false，此时只会输出总大小：

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: {
    printFileSize: {
      detail: false,
    },
  },
})
```

如果不需要查看 gzip 压缩后的大小，可以将 compressed 设置为 false，这可以为大型项目节省一些 gzip 计算时间：

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: {
    printFileSize: {
      compressed: false,
    },
  },
})
```

如果只需包含满足特定条件的静态资源，可以通过 include 传入过滤函数。

如果返回 false，该静态资源将被排除，不会计入总大小或详细大小。

仅输出大于 10kB 的静态资源：

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: {
    printFileSize: {
      include: (asset) => asset.size > 10 * 1000,
    }
  },
})
```

如果需要排除满足特定条件的静态资源，可以通过 exclude 传入过滤函数。如果同时设置了 include 和 exclude，exclude 的优先级更高。

Rspeedy 默认排除 source map、license 文件和 .d.ts 类型文件，因为这些文件不会影响页面加载性能。

在默认规则之外额外排除 .html 文件：

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: {
    printFileSize: {
      exclude: (asset) =>
        /\.(?:map|LICENSE\.txt)$/.test(asset.name) ||
        /\.html$/.test(asset.name),
    }
  },
})
```

### `performance.profile` \{#performance-profile\}

- **类型:** `boolean`
- **默认值:** 当 `DEBUG` 包含 `rspeedy` 时，Rspeedy 会将其设置为 `true`；否则不设置该选项。

是否在 ReactLynx 等 Lynx 运行时集成中采集耗时信息。

启用 profile。

- ReactLynx 等框架会通过 `console.profile` 输出运行时信息。
- Rspeedy 会在构建后输出 `dist/stats.json`，以兼容 bundle 分析工具。

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: { profile: true },
})
```

### `performance.removeConsole` \{#performance-removeconsole\}

- **类型:** `boolean | ConsoleType[]`
- **默认值:** `false`

是否在生产环境构建中移除 `console.[methodName]`。

- 移除所有 `console` 方法

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: {
    removeConsole: true,
  },
})
```

- 移除指定的 `console` 方法

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  performance: {
    removeConsole: ['log', 'warn']
  },
})
```
