## 类 \{#\}

### `MainThreadRef` \{#mainthreadref\}

`MainThreadRef` 是一种只能在主线程访问的 ref，
用于在主线程函数调用之间保存状态。
保存在 `MainThreadRef` 的 `current` 属性中的数据，
可以在多个主线程函数中读写。

### `DataProcessors` \{#dataprocessors\}

通过 [`Lynx.registerDataProcessors`](#lynx) 注册的数据处理器。

扩展 `dataProcessors` 接口

```ts
import type { DataProcessors as WellKnownDataProcessors } from '@lynx-js/react';

declare module '@lynx-js/react' {
  interface DataProcessors extends WellKnownDataProcessors {
    foo(bar: string): number;
  }
}
```

之后即可带类型地使用 `lynx.registerDataProcessors`。

```js
lynx.registerDataProcessors({
  dataProcessors: {
    foo(bar) {
      return 1;
    }
  }
})
```

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| <a id="dataprocessors-getscreenmetricsoverride"></a>`getScreenMetricsOverride?` | `getScreenMetricsOverride(metrics: { height: number; width: number }): { height: number; width: number }` | 可选的处理器，用于覆盖应用所使用的屏幕度量信息 |
