## 类 \{#classes\}

### `CssExtractRspackPlugin` \{#cssextractrspackplugin\}

CssExtractRspackPlugin 是 Lynx 的 CSS 提取插件。其用法与 Web 中的 [CssExtractRspackPlugin](https://rspack.rs/plugins/rspack/css-extract-rspack-plugin.html) 相同。

```js
import { CssExtractRspackPlugin } from '@lynx-js/css-extract-webpack-plugin'
export default {
  plugins: [new CssExtractRspackPlugin()],
  module: {
    rules: [
      {
        test: /\.css$/,
        use: [CssExtractRspackPlugin.loader, 'css-loader'],
      },
    ],
  },
}
```

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| <a id="cssextractrspackplugin-constructor"></a>`constructor` | `constructor(options?: CssExtractRspackPluginOptions): CssExtractRspackPlugin` |  |
| <a id="cssextractrspackplugin-defaultoptions"></a>`defaultOptions` | `Readonly<`[`CssExtractRspackPluginOptions`](#cssextractrspackpluginoptions)` & Pick<Required<`[`CssExtractRspackPluginOptions`](#cssextractrspackpluginoptions)`>, "cssPlugins">>` | `defaultOptions` 是 [`CssExtractRspackPlugin`](#cssextractrspackplugin) 使用的默认选项。 |

#### `CssExtractRspackPlugin.loader` \{#cssextractrspackplugin-loader\}

- **类型：** `string`

用于提取 CSS 的 loader。

应与 ['css-loader'](https://github.com/webpack-contrib/css-loader) 配合使用。

```js
import { CssExtractRspackPlugin } from '@lynx-js/css-extract-webpack-plugin'
export default {
  plugins: [new CssExtractRspackPlugin()],
  module: {
    rules: [
      {
        test: /\.css$/,
        use: [CssExtractRspackPlugin.loader, 'css-loader'],
      },
    ],
  },
}
```

#### `CssExtractRspackPluginOptions.chunkFilename?` \{#cssextractrspackpluginoptions-chunkfilename\}

- **类型：** `string`

非初始 CSS chunk 文件的名称

设置后，lazy bundle 的 CSS chunk 仍会输出到
`.lynx/lazy-bundle/<name>/<layer>.css`（chunk 没有 layer 时为 `.lynx/lazy-bundle/<name>.css`）；该模板仅作用于其他 chunk。

### `LoaderOptions` \{#loaderoptions\}

CSS 提取 loader 的选项。

| 成员 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| <a id="loaderoptions-emit"></a>`emit?` | `boolean` | `true` | 与 [mini-css-extract-plugin](https://github.com/webpack-contrib/mini-css-extract-plugin/tree/master?tab=readme-ov-file#emit) 相同。控制是否将 CSS 输出到文件系统。 - 若为 `true`（默认），则输出文件（将文件写入文件系统）。 - 若为 `false`，插件会提取 CSS，但不会输出文件。 对于服务端包，通常可以禁用该选项。 |
| <a id="loaderoptions-esmodule"></a>`esModule?` | `boolean` |  | [`CssExtractRspackLoaderOptions.esModule`](/zh/api/packages/rspeedy) |
