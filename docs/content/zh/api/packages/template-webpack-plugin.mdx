#### `LynxTemplatePlugin.convertCSSChunksToMap` \{#lynxtemplateplugin-convertcsschunkstomap\}

- **类型：** `convertCSSChunksToMap(cssChunks: (string | { content: string })[], plugins: Plugin[], enableCSSSelector: boolean): { cssMap: Record<string, LynxStyleNode[]>; cssSource: Record<string, string> }`

将 CSS chunk 转换为 CSS map。

该辅助函数目前直接转发至 `cssChunksToMap`。

返回的 `cssSource` 以 `cssId` 为键，并使用合成的文件名格式 `/cssId/<id>.css`。

```
)));
```

#### `LynxTemplatePluginOptions.customSectionNaming?` \{#lynxtemplatepluginoptions-customsectionnaming\}

- **类型：** `(compilation: Compilation) => `[`CustomSectionNaming`](#customsectionnaming)

将每个 chunk 组装为自定义 section，并按此策略命名。

以这种方式组装的 bundle 不包含 `lepusCode`，只有未被命名的 chunk 会保留在 manifest 中。
`FetchBundle` lazy bundle 默认以这种方式组装，使用其运行时所解析的三个 section 名称。

### `TemplateHooks` \{#templatehooks\}

为了让其他插件能够修改 template，此插件会执行
[tapable](https://github.com/webpack/tapable) 钩子。

```js
class MyPlugin {
  apply(compiler) {
    compiler.hooks.compilation.tap("MyPlugin", (compilation) => {
      console.log("The compiler is starting a new compilation...");

      LynxTemplatePlugin.getLynxTemplatePluginHooks(compilation).beforeEmit.tapAsync(
        "MyPlugin", // <-- Set a meaningful name here for stacktraces
        (data, cb) => {
          // Manipulate the content
          modifyTemplate(data.template)
          // Tell webpack to move on
          cb(null, data);
        },
      );
    });
  }
}
```
