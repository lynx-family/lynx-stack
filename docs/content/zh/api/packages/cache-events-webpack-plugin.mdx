## 类 \{#classes\}

### `LynxCacheEventsPlugin` \{#lynxcacheeventsplugin\}

一个 webpack 插件，用于缓存在入口完成启动之前到达的 Lynx 原生调用，并在启动完成后重放这些调用。

仅在 `output.chunkLoading` 为 `'lynx'` 时生效。

- 后台线程 chunk：始终缓存。涵盖 `lynx.getApp()` 的方法
  （`OnLifecycleEvent`、`publishEvent`、`publicComponentEvent`、
  `callDestroyLifetimeFun`、`updateGlobalProps`、`updateCardData`、
  `onAppReload`、`processCardConfig`）、`lynx.performance` 事件以及
  `globalThis.loadDynamicComponent`。

- 主线程 chunk：仅对启动过程为异步的入口进行缓存，例如依赖异步
  external ReactLynx 的入口。`renderPage` 会被缓存并重放，而 `processData`
  在真正的实现安装之前会被替换为直接透传的 shim。

#### `LynxCacheEventsPlugin.defaultOptions` \{#lynxcacheeventsplugin-defaultoptions\}

- **类型：** `Readonly<Required<`[`LynxCacheEventsPluginOptions`](#lynxcacheeventspluginoptions)`>>`

`defaultOptions` 是 [`LynxCacheEventsPlugin`](#lynxcacheeventsplugin) 使用的默认选项。

`defaultOptions` 可用于修改部分选项，同时让其余选项保持默认值。

```js
// webpack.config.js
import { LynxCacheEventsPlugin } from '@lynx-js/cache-events-webpack-plugin'
export default {
  plugins: [
    new LynxCacheEventsPlugin({
      ...LynxCacheEventsPlugin.defaultOptions,
      setupListTransformer: (setupList) => setupList,
    }),
  ],
}
```

## 类型 \{#types\}

### `LynxCacheEventsPluginOptions` \{#lynxcacheeventspluginoptions\}

[`LynxCacheEventsPlugin`](#lynxcacheeventsplugin) 的选项

#### `LynxCacheEventsPluginOptions.setupListTransformer?` \{#lynxcacheeventspluginoptions-setuplisttransformer\}

- **类型：** `(setupList: string[], context: { isMainThread: boolean }) => string[]`

用于修改 setup 列表的转换函数。

它会针对每个缓存 chunk 各运行一次（后台线程和
async-external 主线程分别运行），因此可以通过 `context.isMainThread` 判断当前转换的是哪个线程的列表。可借此只为其中一个线程添加缓存函数。

```js
// webpack.config.js
import { LynxCacheEventsPlugin } from '@lynx-js/cache-events-webpack-plugin'

const config = {
  plugins: [
    new LynxCacheEventsPlugin({
      setupListTransformer: (setupList, { isMainThread }) => {
        // only cache this event on the background thread
        if (!isMainThread) {
          setupList.push(
            `{
              name: 'customCacheEvent',
              setup: () => {
                console.log('customCacheEvent setup');
                return () => {
                  console.log('customCacheEvent teardown');
                }
              }
            }`
          )
        }
        return setupList;
      },
    }),
  ],
}
```
