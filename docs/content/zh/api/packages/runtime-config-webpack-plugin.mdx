## 类 \{#\}

### `RuntimeConfigWebpackPlugin` \{#runtimeconfigwebpackplugin\}

合并位于
`lynx.__runtime_configs__` 中的运行时配置，并对其进行浅冻结。

各 bundle 按执行顺序合并。
后执行的 bundle 中的值会覆盖先前相同 key 的值。

type RuntimeConfigWebpackPluginOptions = Record<string, unknown>
