为 Claude Code、Codex、Cursor、Copilot 等编程 agent 提供 Lynx 文档的 MCP 服务器，内容来自 [llms.txt](https://lynxjs.org/next/llms.txt)。

## 用法

在 MCP 客户端的配置中加入：

```json
{
  "mcpServers": {
    "lynx-docs": {
      "command": "npx",
      "args": ["-y", "@lynx-js/docs-mcp-server@latest"]
    }
  }
}
```

使用 Claude Code 时：

```bash
claude mcp add lynx-docs npx @lynx-js/docs-mcp-server@latest
```

需要 Node.js 18.17 或更高版本。其他客户端的配置见 [README](https://github.com/lynx-family/lynx-stack/tree/main/packages/mcp-servers/docs-mcp-server)。
