# `@lynx-js/genui/a2ui`

`@lynx-js/genui/a2ui` 是 [A2UI](https://a2ui.org/) v0.9 的 ReactLynx 客户端运行时。它接收应用收到的 A2UI 服务端到客户端消息，存入消息 store，并用受信任的 ReactLynx 组件渲染最新的 surface。它不调用模型，也不负责传输层：消息由应用推送进来。完整用法见 [A2UI 指南](https://lynxjs.org/zh/react/genui/a2ui)。

```ts
import { A2UI, createMessageStore } from '@lynx-js/genui/a2ui';
```

store、React 绑定、内置 catalog 和基础函数也可以分别从 `@lynx-js/genui/a2ui/store`、`/react`、`/catalog` 和 `/functions` 单独引入。

### `defineCatalog()` \{#definecatalog\}

```ts
function defineCatalog(inputs: readonly CatalogInput[]): Catalog
```

用组件、`[component, manifest]` 对和/或函数条目构建 catalog。同一类别中重复的名称会被拒绝。函数条目会立即把实现注册到 `functionRegistry`，因此 `defineCatalog` 之后的任何 `executeFunctionCall` 都能路由到它们。

```ts
import { Text, Button } from '@lynx-js/genui/a2ui';
import { defineCatalog, defineFunction } from '@lynx-js/genui/a2ui';
import { required } from '@lynx-js/genui/a2ui/functions';
import textManifest from '@lynx-js/genui/a2ui/catalog/Text/catalog.json'
  with { type: 'json' };

const catalog = defineCatalog([
  [Text, textManifest],
  Button,
  defineFunction(required),
]);
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `inputs` | `readonly `[`CatalogInput`](#cataloginput)`[]` |  |

**返回值：** [`Catalog`](#catalog)

## 类型 \{#types\}

### `A2UIProps` \{#a2uiprops\}

一体化 A2UI ReactLynx 渲染器的 props。

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| <a id="a2uiprops-catalogs"></a>`catalogs` | `readonly `[`CatalogInput`](#cataloginput)`[]` | 渲染器允许实例化的组件。每一项可以是一个裸组件（名称取自 `displayName ?? name`），也可以是元组 `[component, manifest]`，其中 manifest 是提取器在 `dist/catalog/<Name>/catalog.json` 输出的 JSON。 |
| <a id="a2uiprops-classname"></a>`className?` | `string` | 可选的 class 名，应用于当前活动 surface 的顶层 `surface-${surfaceId}` view。当主题切换通过 surface 级别的 class 表达时使用。 |

### `MessageStore` \{#messagestore\}

一个纯追加式的缓冲区，存放由开发者 IO 模块产生的原始协议消息。该 store 对 v0.9 协议一无所知——它不解析、不处理，也不解释消息，只负责：

 1. 按到达顺序存储消息。
 2. 有新消息到达时通知订阅者。
 3. 通过 `getSnapshot()` 返回当前快照（两次变更之间引用保持稳定——这是 `useSyncExternalStore` 所要求的）。

感知协议的处理——surface、signal、resource、action 分发——由 `<A2UI>`（渲染器组件）负责。不想了解协议的开发者应使用 `<A2UI>`；了解协议的开发者可以直接基于快照运行自己的 `MessageProcessor`。

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| <a id="messagestore-getsnapshot"></a>`getSnapshot` | `() => readonly `[`ServerToClientMessage`](#servertoclientmessage)`[]` | `useSyncExternalStore` 的 getSnapshot 约定——在两次 push 之间保持稳定。 |
| <a id="messagestore-subscribe"></a>`subscribe` | `(cb: () => void) => () => void` | `useSyncExternalStore` 的 subscribe 约定。 |
| <a id="messagestore-clear"></a>`clear` | `clear(): void` | 重置缓冲区，并通知订阅者。 |
| <a id="messagestore-push"></a>`push` | `push(message: ServerToClientMessage \| readonly ServerToClientMessage[]): void` | 向缓冲区追加一条或多条原始消息。每次调用只通知订阅者一次（传入单个数组参数时会合并为一次通知）。 |
