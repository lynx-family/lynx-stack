# `@lynx-js/genui/openui`

`@lynx-js/genui/openui` 是 [OpenUI Lang](https://www.openui.com/docs/openui-lang/specification-v05) v0.5 的 ReactLynx 客户端运行时。它解析 agent 生成的 OpenUI 文本，计算其中的状态和数据操作，并用你传入的组件库渲染结果。agent 只输出数据：它只能实例化这个组件库里的组件。完整用法见 [OpenUI 指南](https://lynxjs.org/zh/react/genui/openui)。

```ts
import { OpenUiRenderer, createOpenUiLibrary } from '@lynx-js/genui/openui';
```

如果不想打包用不到的内置组件，改从 [`@lynx-js/genui/openui/explicit`](./openui-explicit) 创建组件库。

### `useSetDefaultValue()` \{#usesetdefaultvalue\}
