# `@lynx-js/genui/a2ui-prompt`

`@lynx-js/genui/a2ui-prompt` 基于内置的 basic catalog 或你自己的 catalog 构建系统提示词，让模型以 A2UI 消息作答。它用在 CLI 或 agent 一侧，与应用里的 [`@lynx-js/genui/a2ui`](./a2ui) 渲染器配合使用。

```ts
import { buildA2UISystemPrompt } from '@lynx-js/genui/a2ui-prompt';
```
