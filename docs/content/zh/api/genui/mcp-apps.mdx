# `@lynx-js/genui/mcp-apps`

`@lynx-js/genui/mcp-apps` 是 MCP Apps 的 Lynx 宿主。它校验收到的 app 数据，找到你为它注册的渲染器，用 ReactLynx 渲染出来；没有已注册的渲染器匹配时，回退为流式 Markdown。用 `defineAppRenderer` 定义渲染器，用 `createAppRendererRegistry` 汇总成注册表，再把注册表传给 `McpApps`。

```ts
import {
  McpApps,
  createAppRendererRegistry,
  defineAppRenderer,
} from '@lynx-js/genui/mcp-apps';
```
