# `@lynx-js/genui/openui/prompt`

`@lynx-js/genui/openui/prompt` 用于构建系统提示词，让模型用你组件库里的组件以 OpenUI Lang 作答。它用在 agent 一侧，与应用里的 [`@lynx-js/genui/openui`](./openui) 渲染器配合使用。

```ts
import { buildOpenUiSystemPrompt } from '@lynx-js/genui/openui/prompt';
```

## 函数 \{#functions\}

### `buildOpenUiSystemPrompt()` \{#buildopenuisystemprompt\}

```ts
function buildOpenUiSystemPrompt(options: BuildOpenUiSystemPromptOptions): string
```

为给定的组件库和选项构建完整的 OpenUI 系统提示词。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `options` | [`BuildOpenUiSystemPromptOptions`](#buildopenuisystempromptoptions) |  |

**返回值：** `string`

### `createOpenUiPromptLibrary()` \{#createopenuipromptlibrary\}

```ts
function createOpenUiPromptLibrary(options: CreateOpenUiPromptLibraryOptions): OpenUiPromptLibrary
```

使用内置组件 schema 创建 headless OpenUI 库。

它与 ReactLynx 组件库保持一致以用于生成 prompt，同时不会在运行时依赖 ReactLynx 或 Lynx UI 组件。

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `options` | [`CreateOpenUiPromptLibraryOptions`](#createopenuipromptlibraryoptions) |  |

**返回值：** [`OpenUiPromptLibrary`](#openuipromptlibrary)
