# `@lynx-js/genui/a2ui-catalog-extractor`

`@lynx-js/genui/a2ui-catalog-extractor` 把组件的 TypeScript 接口及其 TypeDoc 注释转换成 agent 读取的 A2UI catalog JSON。它是 `genui a2ui generate catalog` 背后的实现；脚本中优先使用这条命令，需要在代码里做提取时再使用这个入口。

```ts
import { extractCatalogComponents } from '@lynx-js/genui/a2ui-catalog-extractor';
```
