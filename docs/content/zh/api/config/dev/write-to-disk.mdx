# dev.writeToDisk

{/* @api ConfigOption package="rspeedy" path="dev.writeToDisk" */}

- **类型：** `boolean | ((filename: string) => boolean)`

Lynx 修改了这个 Rsbuild 配置的默认值，其他用法与 Rsbuild 相同，详见 [Rsbuild 文档](https://rsbuild.rs/zh/config/dev/write-to-disk)。
