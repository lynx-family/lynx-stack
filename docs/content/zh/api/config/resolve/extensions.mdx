# resolve.extensions

{/* @api ConfigOption package="rspeedy" path="resolve.extensions" */}

- **类型：** `string[]`
- **默认值：** `['.ts', '.tsx', '.mjs', '.js', '.jsx', '.json', '.cjs']`

Lynx 修改了这个 Rsbuild 配置的默认值，其他用法与 Rsbuild 相同，详见 [Rsbuild 文档](https://rsbuild.rs/zh/config/resolve/extensions)。

{/* @api-end */}
