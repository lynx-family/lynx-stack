# splitChunks

{/* @api ConfigOption package="rspeedy" path="splitChunks" */}

- **类型：** `false | SplitChunksConfig`

Lynx 修改了这个 Rsbuild 配置的默认值，其他用法与 Rsbuild 相同，详见 [Rsbuild 文档](https://rsbuild.rs/zh/config/split-chunks)。

## 默认值 \{#default\}

- Lynx 构建默认将其设置为 `false`；如果进行了配置，则由 Rsbuild 的顶层 `splitChunks` 选项处理。
