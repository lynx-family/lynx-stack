# mode

{/* @api ConfigOption package="rspeedy" path="mode" */}

- **类型：** `"production" | "development" | "none"`

Lynx 修改了这个 Rsbuild 配置的默认值，其他用法与 Rsbuild 相同，详见 [Rsbuild 文档](https://rsbuild.rs/zh/config/mode)。

## 默认值 \{#default\}

取决于 `process.env.NODE_ENV`：

- `NODE_ENV` 为 `'production'` 时为 `'production'`
- `NODE_ENV` 为 `'development'` 时为 `'development'`
- 其他情况为 `'none'`

使用 Rspeedy CLI 时，`rspeedy dev` 和 `rspeedy preview` 默认为 `'development'`，`rspeedy build` 默认为 `'production'`。
