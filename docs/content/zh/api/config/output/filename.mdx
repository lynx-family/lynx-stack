# output.filename

{/* @api ConfigOption package="rspeedy" path="output.filename" */}

- **类型：** `string | Filename`
- **默认值：** `{ bundle: '[name].[platform].bundle', template: '[name].[platform].bundle' }`

Lynx 修改了这个 Rsbuild 配置的默认值，其他用法与 Rsbuild 相同，详见 [Rsbuild 文档](https://rsbuild.rs/zh/config/output/filename)。

{/* @api-end */}
