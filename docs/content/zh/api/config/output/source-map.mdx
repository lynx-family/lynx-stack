# output.sourceMap

{/* @api ConfigOption package="rspeedy" path="output.sourceMap" */}

- **类型：** `boolean | SourceMap`

Lynx 修改了这个 Rsbuild 配置的默认值，其他用法与 Rsbuild 相同，详见 [Rsbuild 文档](https://rsbuild.rs/zh/config/output/source-map)。

## 默认值 \{#default\}

- 在 Lynx 构建中未设置该选项时，JavaScript source map 在开发环境使用 `'cheap-module-source-map'`，在生产环境使用 `'source-map'`；同时也会生成 CSS source map。
- 所有 `.map` 资源都会在输出前被移除。
