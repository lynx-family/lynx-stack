# output.dataUriLimit

{/* @api ConfigOption package="rspeedy" path="output.dataUriLimit" */}

- **类型：** `number | DataUriLimit`
- **默认值：** `2048`

Lynx 修改了这个 Rsbuild 配置的默认值，其他用法与 Rsbuild 相同，详见 [Rsbuild 文档](https://rsbuild.rs/zh/config/output/data-uri-limit)。
