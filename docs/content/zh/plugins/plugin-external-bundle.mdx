# pluginExternalBundle

<div className="api-pkg-header"><code>@lynx-js/external-bundle-rsbuild-plugin</code> <span className="api-pkg-version">v0.4.2</span> · <a href="https://www.npmjs.com/package/@lynx-js/external-bundle-rsbuild-plugin" target="_blank" rel="noopener">npm</a> · <a href="https://github.com/lynx-family/lynx-stack/tree/main/packages/rspeedy/plugin-external-bundle" target="_blank" rel="noopener">源码</a> · <a href="https://github.com/lynx-family/lynx-stack/tree/main/packages/rspeedy/plugin-external-bundle/CHANGELOG.md" target="_blank" rel="noopener">更新日志</a></div>

构建 external bundle：一种 Lynx bundle，其模块在运行时由宿主 bundle 按需加载，而不是被内联。

## 安装

import { PackageManagerTabs } from '@rspress/core/theme';

<PackageManagerTabs command="add @lynx-js/external-bundle-rsbuild-plugin -D" />

## 用法

```ts title="lynx.config.ts"
import { defineConfig } from '@lynx-js/rspeedy'
import { pluginExternalBundle } from '@lynx-js/external-bundle-rsbuild-plugin'

export default defineConfig({
  plugins: [pluginExternalBundle()],
})
```

### `externalsPresets` \{#externalspresets\}

- **类型:** [`ExternalsPresets`](#externalspresets)

外部库的预设。

与 https://rspack.rs/config/externals#externalspresets 相同，但适用于 Lynx。

#### `externalsPresets.reactlynx` \{#externalspresets-reactlynx\}

- **类型:** `boolean | `[`ReactLynxExternalsPresetOptions`](#externalspresets-reactlynx)

加载 ReactLynx 运行时 bundle，并配置其标准模块全局变量。

##### `externalsPresets.reactlynx.url` <span className="api-badge api-badge-deprecated">已废弃</span> \{#externalspresets-reactlynx-url\}

- **类型:** `string`

:::warning 已废弃
已废弃。
:::

直接覆盖运行时 bundle 的 URL。

仅当 ReactLynx 运行时托管在当前
构建产物之外（例如 CDN 上）时才使用该选项。与 `bundlePath` 不同，该选项不会向当前编译
产出任何额外资源。

 建议优先使用 `bundlePath`，它通过运行时 public
path 解析，并支持自动产出资源。

##### 其他选项 \{#externalspresets-reactlynx-other-options\}

| 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| <a id="externalspresets-reactlynx-async"></a>`async` | `boolean` | `false` | 针对 web 目标，异步加载 ReactLynx 运行时 bundle。 web 运行时（`@lynx-js/web-core`）只能异步获取 external bundle （`fetchBundle().then`），因此 ReactLynx 必须以 promise 的形式挂载， 使用它的模块需要先 await 该 promise 再读取子路径（否则 `React.memo` 等会从一个 pending 状态的 promise 上读取，结果为 `undefined`）。 启用后还会解析 web 编码的 `@lynx-js/react-umd/{dev,prod}-web` bundle，并将 `bundlePath` 默认设为 `react.web.bundle`。 |
| <a id="externalspresets-reactlynx-bundlepath"></a>`bundlePath` | `string` | `'react.lynx.bundle'` | 将 ReactLynx 运行时 bundle 产出到当前构建产物中，并通过 生成的运行时 public path 加载。 对于常规 Rspeedy 项目，优先使用该选项而非 `url`。除了让 运行时基于 `publicPath` 解析最终 URL 之外，插件还会将 对应的 `@lynx-js/react-umd` bundle 复制到产出的资源中， 因此应用 bundle 可以直接引用它，发布时无需额外的手动 复制步骤。 |
| <a id="externalspresets-reactlynx-reactumdpackagename"></a>`reactUmdPackageName` | `string` | `'@lynx-js/react-umd'` | 提供 ReactLynx 运行时 bundle 的包名。 为其他发行版封装该插件时（例如 `@byted-lynx/react-umd`），可覆盖该选项。 |

### `pluginExternalBundle()` \{#pluginexternalbundle\}

```ts
pluginExternalBundle(options: PluginExternalBundleOptions): RsbuildPlugin
```

创建一个用于加载 external bundle 的 Rsbuild 插件。

该插件封装了 externals-loading-webpack-plugin，并通过 api.useExposed
自动从 react-rsbuild-plugin 获取 layer 名称。

```ts
// lynx.config.ts
import { pluginExternalBundle } from '@lynx-js/external-bundle-rsbuild-plugin'
import { pluginReactLynx } from '@lynx-js/react-rsbuild-plugin'

export default {
  plugins: [
    pluginReactLynx(),
    pluginExternalBundle({
      externals: {
        lodash: {
          bundlePath: 'lodash.lynx.bundle',
          background: { sectionPath: 'background' },
          mainThread: { sectionPath: 'mainThread' },
        },
      },
    }),
  ],
}
```

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `options` | [`PluginExternalBundleOptions`](#pluginexternalbundleoptions) |  |

**返回值:** `RsbuildPlugin`

### `PluginExternalConfig` \{#pluginexternalconfig\}

```ts
type PluginExternalConfig = PluginExternalValue | string
```

`pluginExternalBundle` 接受的 external bundle 简写形式。

传入字符串时，它会被视为 `bundlePath`，插件会
推断：
- `libraryName`：external 请求的 key
- `background.sectionPath`：external 请求的 key
- `mainThread.sectionPath`：`${request}__main-thread`
