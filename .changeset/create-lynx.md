Add `@lynx-js/create-lynx`, which scaffolds a Lynx app for either build tool:

```bash
npm create @lynx-js/lynx@latest
```

`rsbuild-ts` / `rsbuild-js` build with Rsbuild and `pluginLynx`, `rspeedy-ts` / `rspeedy-js` build with Rspeedy. It supersedes `create-rspeedy`, which now carries a deprecation notice and no longer receives updates.
