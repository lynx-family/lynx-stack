# OpenUI examples

Keep editable OpenUI Lang in `.openui` files. Rsbuild imports these as raw text
and copies this directory to `demos/openui/` for static previews.

The Travel Camera Guide adapts the user-provided photography recommendation
screenshot. Its ten JPEGs in `travel-camera/` are cropped image regions from that
reference, including the four environment portraits, three camera images, and
three wide scenes. They are illustrative material, not camera sample photographs.
The example uses local assets and local state; it does not need an online agent.
