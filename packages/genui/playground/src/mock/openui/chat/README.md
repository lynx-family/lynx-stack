# OpenUI Chat examples

These 18 fictional UI fixtures cover the positional Chat contracts used by the reference examples, including shared checkbox bindings, reactive slider calculations, forms, tables and composed content. `ProductFeature` is a document extension rather than an upstream Chat component. The source data is illustrative.

Only the UI examples are included. Images are authored local schematic illustrations, and source links point to the local explanation page. The parser and renderer both use `createOpenUiChatLibrary`'s contracts; the default Stack catalog remains separate. The `.openui` sources are copied unchanged into `demos/openui/chat/` for short preview links.
