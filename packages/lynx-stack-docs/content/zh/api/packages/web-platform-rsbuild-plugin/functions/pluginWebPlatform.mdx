# 函数: pluginWebPlatform()

```ts
function pluginWebPlatform(userOptions?: PluginWebPlatformOptions): RsbuildPlugin;
```

为 Lynx Web Platform 创建一个 Rsbuild 插件。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `userOptions?` | `PluginWebPlatformOptions` |

## 返回

`RsbuildPlugin`

## 示例

```ts
// rsbuild.config.ts
import { pluginWebPlatform } from '@lynx-js/web-platform-rsbuild-plugin'
import { defineConfig } from '@rsbuild/core';

export default defineConfig({
  plugins: [pluginWebPlatform({
    // replace with your actual native-modules file path
    nativeModulesPath: path.resolve(__dirname, './index.native-modules.ts'),
  })],
})
```
