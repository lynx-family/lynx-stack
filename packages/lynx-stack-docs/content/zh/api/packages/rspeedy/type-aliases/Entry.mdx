# 类型别名: Entry

```ts
type Entry = 
  | string
  | string[]
  | Record<string, 
  | string
  | string[]
| EntryDescription>;
```

Entry 选项用于设置入口模块。

## 示例

- 使用单个入口：

```js
import { defineConfig } from '@lynx-js/rspeedy'
export default defineConfig({
  source: {
    entry: './src/pages/main/index.js',
  }
})
```

- 使用包含多个入口模块的单个入口：

```js
import { defineConfig } from '@lynx-js/rspeedy'
export default defineConfig({
  source: {
    entry: ['./src/prefetch.js', './src/pages/main/index.js'],
  }
})
```

- 使用多个入口（每个入口包含多个入口模块）：

```js
import { defineConfig } from '@lynx-js/rspeedy'
export default defineConfig({
  source: {
    entry: {
      foo: './src/pages/foo/index.js',
      bar: ['./src/pages/bar/index.js', './src/post.js'], // multiple entry modules is allowed
    }
  }
})
```

- 使用 [EntryDescription](../interfaces/EntryDescription.mdx) 配置多个入口：

```js
import { defineConfig } from '@lynx-js/rspeedy'
export default defineConfig({
  source: {
    entry: {
      foo: './src/pages/foo/index.js',
      bar: {
        import: ['./src/prefetch.js', './src/pages/bar'],
      }
    }
  }
})
```
