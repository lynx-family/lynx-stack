# 函数: defineConfig()

## 调用签名

```ts
function defineConfig(config: Config): Config;
```

`defineConfig` 方法是一个辅助函数，用于获取 TypeScript 智能提示。

### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `config` | [`Config`](../interfaces/Config.mdx) | Rspeedy 的配置。 |

### 返回

[`Config`](../interfaces/Config.mdx)

与输入配置完全相同的配置。

### 示例

在 `lynx.config.ts` 中使用 `defineConfig`：

```ts
import { defineConfig } from '@lynx-js/rspeedy'
export default defineConfig({
  // autocompletion works here!
})
```

## 调用签名

```ts
function defineConfig(config: (params: ConfigParams) => Config): (params: ConfigParams) => Config;
```

`defineConfig` 方法是一个辅助函数，用于获取 TypeScript 智能提示。

### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `config` | (`params`: [`ConfigParams`](../interfaces/ConfigParams.mdx)) => [`Config`](../interfaces/Config.mdx) | 返回 Rspeedy 配置的函数。 |

### 返回

与输入完全相同的函数。

(`params`: [`ConfigParams`](../interfaces/ConfigParams.mdx)) => [`Config`](../interfaces/Config.mdx)

### 示例

在 `lynx.config.ts` 中使用 `defineConfig`：

```ts
import { defineConfig } from '@lynx-js/rspeedy'
export default defineConfig(() => {
  return {
    // autocompletion works here!
  }
})
```

在 `lynx.config.ts` 中带参数使用 `defineConfig`：

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig(({ env }) => {
  const isTest = env === 'test'
  return {
    output: {
      minify: isTest ? false : true,
    },
  }
})
```

## 调用签名

```ts
function defineConfig(config: Promise<Config>): Promise<Config>;
```

`defineConfig` 方法是一个辅助函数，用于获取 TypeScript 智能提示。

### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `config` | `Promise`\<[`Config`](../interfaces/Config.mdx)\> | 解析为 Rspeedy 配置的 Promise。 |

### 返回

`Promise`\<[`Config`](../interfaces/Config.mdx)\>

与输入完全相同的 Promise。

### 示例

在 `lynx.config.ts` 中使用 `defineConfig`：

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig(
  import('@lynx-js/react-rsbuild-plugin').then(({ pluginReactLynx }) => ({
    plugins: [pluginReactLynx()],
  })),
);
```

## 调用签名

```ts
function defineConfig(config: (params: ConfigParams) => Promise<Config>): (params: ConfigParams) => Promise<Config>;
```

`defineConfig` 方法是一个辅助函数，用于获取 TypeScript 智能提示。

### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `config` | (`params`: [`ConfigParams`](../interfaces/ConfigParams.mdx)) => `Promise`\<[`Config`](../interfaces/Config.mdx)\> | 返回一个解析为 Rspeedy 配置的 Promise 的函数。 |

### 返回

与输入完全相同的函数。

(`params`: [`ConfigParams`](../interfaces/ConfigParams.mdx)) => `Promise`\<[`Config`](../interfaces/Config.mdx)\>

### 示例

在 `lynx.config.ts` 中使用 `defineConfig`：

```ts
import { defineConfig } from '@lynx-js/rspeedy'
export default defineConfig(async () => {
  const foo = await bar()
  return {
    // autocompletion works here!
  }
})
```

在 `lynx.config.ts` 中带参数使用 `defineConfig`：

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig(async ({ env }) => {
  const foo = await bar()
  const isTest = env === 'test'
  return {
    output: {
      minify: isTest ? false : true,
    },
  }
})
```
