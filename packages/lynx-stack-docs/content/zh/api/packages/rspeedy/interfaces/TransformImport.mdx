# 接口: TransformImport

TransformImport 选项用于转换导入路径，以便从第三方包的子路径中按需导入模块，功能类似于 [babel-plugin-import](https://npmjs.com/package/babel-plugin-import)。

## 属性

### camelToDashComponentName?

```ts
optional camelToDashComponentName?: boolean;
```

是否将驼峰命名（camelCase）的导入转换为短横线命名（kebab-case）。

#### 默认值

Rsbuild 默认将该选项设置为 `true`。

#### 示例

- Input:

```js
import { ButtonGroup } from 'foo'
```

- Output:

设置为 `true` 时：
```js
import ButtonGroup from 'foo/button-group'
```

设置为 `false` 时：
```js
import ButtonGroup from 'foo/ButtonGroup'
```

***

### customName?

```ts
optional customName?: string;
```

自定义转换后的路径。

#### 默认值

```ts
undefined
```

#### 备注

你可以指定转换后路径的格式。例如，将其设置为 `my-lib/{{ camelCase member }}`，即可将 member 转换为驼峰格式。

支持以下格式：

- `kebabCase`：字母小写，单词之间使用连字符连接。例如：`my-variable-name`。

- `snakeCase`：字母小写，单词之间使用下划线连接。例如：`my_variable_name`。

- `camelCase`：首字母小写，其后每个单词的首字母大写。例如：`myVariableName`。

- `upperCase`：字母大写，其他字符不变。例如：`MY-VARIABLE-NAME`。

- `lowerCase`：字母小写，其他字符不变。例如：`my-variable-name`。

***

### libraryDirectory?

```ts
optional libraryDirectory?: string;
```

用于拼接转换后的路径，拼接规则为 `${libraryName}/${libraryDirectory}/${member}`，其中 member 为导入的成员。

#### 默认值

`'lib'`

#### 示例

- Input:

```js
import { Button } from 'foo'
```

- Output:

```js
import Button from 'foo/lib/button'
```

***

### libraryName

```ts
libraryName: string;
```

需要转换的原始导入路径。

#### 备注

该选项为必填项。

***

### transformToDefaultImport?

```ts
optional transformToDefaultImport?: boolean;
```

是否将导入语句转换为默认导入。

#### 默认值

Rsbuild 默认将该选项设置为 `true`。

#### 示例

- Input:

```js
import { Button } from 'foo'
```

- Output:

设置为 `true` 时：
```js
import Button from 'foo/button'
```

设置为 `false` 时：
```js
import { Button } from 'foo/button'
```
