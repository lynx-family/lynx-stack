# 接口: Minify

Minify 用于配置是否在生产环境构建中启用代码压缩，或配置压缩器选项。

## 属性

### backgroundOptions?

```ts
optional backgroundOptions?: SwcJsMinimizerRspackPluginOptions;
```

为后台线程 bundle 覆盖 Rsbuild 的 `output.minify.jsOptions`。

#### 备注

该选项会被深度合并到 `output.minify.jsOptions` 中。它主要与 ReactLynx 的双线程产物配合使用，使主线程和后台线程的 bundle 可以使用不同的压缩规则。

#### 默认值

```ts
undefined
```

***

### css?

```ts
optional css?: boolean;
```

是否启用 CSS 压缩。

#### 默认值

当启用 `output.minify` 且未设置 `css` 时，默认为 `true`。

#### 备注

在生产环境构建时，会使用 [@rsbuild/plugin-css-minimizer](https://github.com/rspack-contrib/rsbuild-plugin-css-minimizer) 压缩 CSS 资源，以提升传输效率。

#### 示例

- 禁用 CSS 压缩。

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  output: {
    minify: {
      css: false,
    },
  },
})
```

***

### js?

```ts
optional js?: boolean;
```

是否启用 JavaScript 压缩。

#### 默认值

当启用 `output.minify` 且未设置 `js` 时，默认为 `true`。

#### 示例

- 禁用 JavaScript 压缩。

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  output: {
    minify: {
      js: false,
    },
  },
})
```

***

### jsOptions?

```ts
optional jsOptions?: SwcJsMinimizerRspackPluginOptions;
```

[Minify.jsOptions](#jsoptions) 用于配置 SWC 的压缩选项。

#### 默认值

当启用 JavaScript 压缩且未设置 `jsOptions` 时，默认为 `{}`。

#### 备注

详细配置请参考 [SwcJsMinimizerRspackPlugin](https://rspack.rs/plugins/rspack/swc-js-minimizer-rspack-plugin)。

#### 示例

- 禁用 mangle 功能。

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  output: {
    minify: {
      jsOptions: {
        minimizerOptions: {
          mangle: false,
        },
      },
    },
  },
})
```

***

### mainThreadOptions?

```ts
optional mainThreadOptions?: SwcJsMinimizerRspackPluginOptions;
```

为主线程 bundle 覆盖 Rsbuild 的 `output.minify.jsOptions`。

#### 备注

该选项会被深度合并到 `output.minify.jsOptions` 中。它主要与 ReactLynx 的双线程产物配合使用，使主线程和后台线程的 bundle 可以使用不同的压缩规则。

#### 默认值

```ts
undefined
```

#### 示例

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  output: {
    minify: {
      jsOptions: {
        minimizerOptions: {
          compress: {
            pure_funcs: ['console.log'],
          },
        },
      },
      mainThreadOptions: {
        minimizerOptions: {
          compress: {
            pure_funcs: ['NativeModules.call', 'lynx.getJSModule'],
          },
        },
      },
    },
  },
})
```
