# 接口: CssExtract

CssExtract 用于控制 [CssExtractRspackPlugin](https://rspack.rs/plugins/rspack/css-extract-rspack-plugin) 的选项。

## 属性

### loaderOptions?

```ts
optional loaderOptions?: CssExtractRspackLoaderOptions;
```

CSS extract loader 的选项。

#### 默认值

```ts
undefined
```

***

### pluginOptions?

```ts
optional pluginOptions?: CssExtractRspackPluginOptions;
```

[@lynx-js/css-extract-webpack-plugin!CssExtractRspackPlugin](../../css-extract-webpack-plugin/classes/CssExtractRspackPlugin.mdx) 的选项

#### 默认值

```ts
undefined
```
