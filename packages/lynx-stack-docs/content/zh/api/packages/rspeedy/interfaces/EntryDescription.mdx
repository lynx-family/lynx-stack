# 接口: EntryDescription

`EntryDescription` 用于描述一个入口。当项目中存在多个配置不同的入口时非常有用。

## 备注

与 Rspack 的 [Entry Description Object](https://rspack.rs/config/entry#entry-description-object) 类似，但只允许使用 Lynx 支持的少数属性。

## 属性

### dependOn?

```ts
optional dependOn?: string | string[];
```

当前入口所依赖的入口，它们必须在当前入口加载之前加载。

***

### import?

```ts
optional import?: string | string[];
```

入口模块的路径。

#### 默认值

`'./src/index.js'`

***

### publicPath?

```ts
optional publicPath?: string;
```

在使用按需加载或加载图片、文件等外部资源时，这是一个重要的选项。如果指定了错误的值，加载这些资源时会出现 404 错误。

#### 默认值

```ts
undefined
```

#### 参阅

https://webpack.js.org/configuration/output/#outputpublicpath
