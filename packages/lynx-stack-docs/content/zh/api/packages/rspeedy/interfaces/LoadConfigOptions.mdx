# 接口: LoadConfigOptions

loadConfig 的选项。

## 属性

### configPath?

```ts
optional configPath?: string;
```

要加载的配置文件路径。

#### 默认值

自动从 `cwd` 中解析 `lynx.config.ts`、`lynx.config.js`、`lynx.config.mts` 或 `lynx.config.mjs`

***

### cwd?

```ts
optional cwd?: string;
```

用于解析配置文件路径的工作目录。

#### 默认值

`process.cwd()`
