# 接口: Tools

Tools 选项用于修改各类构建工具的行为。

## 属性

### bundlerChain?

```ts
optional bundlerChain?: ToolsBundlerChainConfig;
```

[Tools.bundlerChain](#bundlerchain) 通过 [Rspack](https://rspack.rs) 修改 [rspack-chain](https://github.com/rspack-contrib/rspack-chain) 的选项。

#### 默认值

```ts
undefined
```

#### 示例

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    bundlerChain(chain) {
      chain.resolve.fullySpecified(true)
    },
  },
})
```

详见 [rspack-chain](https://github.com/rspack-contrib/rspack-chain)。

### cssLoader?

```ts
optional cssLoader?: CssLoader;
```

[CssLoader](CssLoader.mdx) 用于控制 [css-loader](https://github.com/webpack-contrib/css-loader) 的选项。

#### 默认值

使用基于 `output.cssModules` 和 `output.sourceMap` 推导出的默认值，其中 CSS 文件的 `importLoaders` 设置为 `1`，Sass/Less 文件设置为 `2`。

#### 备注

默认选项如下：

```js
const defaultOptions = {
  modules: {
    auto: true,
    namedExport: false,
    exportLocalsConvention: 'camelCase',
    localIdentName: output.cssModules.localIdentName,
  },
  sourceMap: output.sourceMap,
  // importLoaders is `1` when compiling css files, and is `2` when compiling sass/less files
  importLoaders: 1 || 2,
};
```

### rsdoctor?

```ts
optional rsdoctor?: RsdoctorRspackPluginOptions;
```

[Tools.rsdoctor](#rsdoctor) 用于控制 [Rsdoctor](https://rsdoctor.dev/) 的选项。

#### 默认值

```ts
undefined
```

#### 备注

设置 `RSDOCTOR=true` 可启用 Rsdoctor。启用后，Rspeedy 会在配置规范化阶段合并额外的插件默认配置。

#### 示例

- 使用内置的 Rsdoctor。

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    rsdoctor: {
      disableClientServer: true,
    },
  },
})
```

详见 [Rsdoctor - Configuration](https://rsdoctor.dev/config/options/options)。

### rspack?

```ts
optional rspack?: ToolsRspackConfig;
```

[Tools.rspack](#rspack) 用于控制 [Rspack](https://rspack.rs/) 的选项。

#### 默认值

```ts
undefined
```

#### 示例

- 使用对象配置

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    rspack: {
      resolve: {
        fullySpecified: true,
      },
    },
  },
})
```

详见 [Rspack - Configuration](https://rspack.rs/config/index)。

- 使用函数形式并借助 `env` 工具函数

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    rspack(config, { env }) {
      if (env === 'development') {
        config.devtool = 'cheap-source-map'
      }
      return config
    },
  },
})
```

详见 [Rsbuild - tools.rspack](https://rsbuild.rs/config/tools/rspack#env)。

- 使用函数形式并借助 `mergeConfig` 工具函数

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    rspack(config, { mergeConfig }) {
      return mergeConfig(config, {
        resolve: {
          fullySpecified: true,
        },
      })
    },
  },
})
```

详见 [Rsbuild - tools.rspack](https://rsbuild.rs/config/tools/rspack#mergeconfig)。

- 使用函数形式并借助 `appendPlugins` 工具函数

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    rspack(config, { appendPlugins, rspack }) {
      appendPlugins(new rspack.BannerPlugin({ banner: 'Hello, World!' }))
      return config
    },
  },
})
```

详见 [Rsbuild - tools.rspack](https://rsbuild.rs/config/tools/rspack#appendplugins)。
