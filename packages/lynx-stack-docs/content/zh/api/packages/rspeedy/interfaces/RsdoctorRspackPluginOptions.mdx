# 接口: RsdoctorRspackPluginOptions

`tools.rsdoctor` 的简化选项类型。

该类型应避免使用深层嵌套或交叉的工具类型，以确保
typia 能够基于 `Config` 生成校验器。

## 继承

- `Omit`\<`RawRsdoctorRspackPluginOptions`\<\[\]\>, `"linter"`\>

## 属性

### linter?

```ts
optional linter?: object;
```

#### extends?

```ts
optional extends?: unknown[];
```

#### level?

```ts
optional level?: "Ignore" | "Warn" | "Error";
```

#### rules?

```ts
optional rules?: Record<string, unknown>;
```
