# 接口: Filename

Filename 决定输出到 [Output.distPath](Output.mdx#distpath) 下的 Lynx bundle 文件的名称。

## 备注

如果传入字符串，它将被用作 [Filename.bundle](#bundle)。

## 属性

### assets?

```ts
optional assets?: Filename;
```

其他静态资源的名称，不包括上述类型（image、svg、font、html、wasm...）

#### 默认值

`'[name].[contenthash:8][ext]'`

***

### bundle?

```ts
optional bundle?: BundleFilename;
```

bundle 文件的名称。

#### 备注

支持以下占位符：

- `[name]`：入口名称。
- `[platform]`：Rsbuild environment 的名称。
- `[contenthash]`：bundle 内容的 hash。

#### 默认值

`'[name].[platform].bundle'`

#### 示例

- 在 bundle 文件名中使用 content hash：

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  output: {
    filename: {
      bundle: '[name].[contenthash].bundle',
    },
  },
})
```

- 在 bundle 文件名中使用指定长度的 content hash：

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  output: {
    filename: {
      bundle: '[name].[contenthash:8].bundle',
    },
  },
})
```

- 使用函数分别控制主 bundle 和 lazy bundle
  （例如将 lazy bundle 输出到另一个目录，并附加 git
  commit hash）：

```js
import { execSync } from 'node:child_process'

import { defineConfig } from '@lynx-js/rspeedy'

const gitHash = execSync('git rev-parse --short HEAD').toString().trim()

export default defineConfig({
  output: {
    filename: {
      bundle: ({ lazyBundle, platform }) =>
        lazyBundle
          ? `my-lazy-bundles/[name].[fullhash]-${gitHash}.bundle`
          : `[name].${platform}.bundle`,
    },
  },
})
```

### css?

```ts
optional css?: Filename;
```

**`Lynx Default Changed`**

CSS 文件的名称。

#### 默认值

`'[name]/[name].css'`

#### 示例

- 使用函数根据文件信息动态设置文件名：

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  output: {
    filename: {
      css: (pathData, assetInfo) => {
        console.log(pathData); // You can check the contents of pathData here

        if (pathData.chunk?.name === 'index') {
          return isProd ? '[name].[contenthash:8].css' : '[name].css';
        }
        return '/some-path/[name].css';
      },
    },
  },
})
```

### js?

```ts
optional js?: Filename;
```

JavaScript 文件的名称。

#### 默认值

开发环境下为 `'[name].js'`，生产环境 web 构建为 `'[name].[contenthash:8].js'`，生产环境 node 构建为 `'[name].js'`

#### 示例

- 使用函数根据文件信息动态设置文件名：

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  output: {
    filename: {
      js: (pathData, assetInfo) => {
        console.log(pathData); // You can check the contents of pathData here

        if (pathData.chunk?.name === 'index') {
          return isProd ? '[name].[contenthash:8].js' : '[name].js';
        }
        return '/some-path/[name].js';
      },
    },
  },
})
```
