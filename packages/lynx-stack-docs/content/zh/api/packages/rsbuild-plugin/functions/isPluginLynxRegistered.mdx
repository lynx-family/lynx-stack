# 函数: isPluginLynxRegistered()

```ts
function isPluginLynxRegistered(host: object, environments: string[]): boolean;
```

Lynx 构建引擎是否已注册。

## 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `host` | \{ `isPluginExists`: `boolean`; \} | 用于查找的 Rsbuild 实例或插件 API。 |
| `host.isPluginExists` | - |
| `environments` | `string`[] | 已配置的环境名称。 |

## 返回

`boolean`

## 备注

该引擎是全局的。不传 environment 调用 `isPluginExists` 时只会报告全局插件，因此无法检测到调用方（例如 `rslib`）注册在某个 environment 上的引擎。
