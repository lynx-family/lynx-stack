# 接口: ReactLynxExternalsPresetOptions

内置 `reactlynx` externals 预设的选项。

## 属性

### async?

```ts
optional async?: boolean;
```

针对 web 目标，异步加载 ReactLynx 运行时 bundle。

web 运行时（`@lynx-js/web-core`）只能异步获取 external bundle
（`fetchBundle().then`），因此 ReactLynx 必须以 promise 的形式挂载，使用它的模块需要先 await 该 promise 再读取子路径（否则
`React.memo` 等会从一个 pending 状态的 promise 上读取，结果为 `undefined`）。该选项仅控制运行时的挂载方式；在 `lynx` / `lynx-*` 以外的 environment 中会选用 web bundle。

#### 默认值

`false`

***

### bundlePath?

```ts
optional bundlePath?: string;
```

将 ReactLynx 运行时 bundle 产出到当前构建产物中，并通过生成的运行时 public path 加载。

对于普通的 Rspeedy 项目，优先使用它而不是 `url`。除了让
运行时从 `publicPath` 解析出最终 URL 之外，该插件还会
将对应的 `@lynx-js/react-umd` bundle 复制到产物中，
这样应用 bundle 就可以引用它，而无需在发布时额外手动复制。

#### 默认值

`'react.lynx.bundle'`；在 `lynx` / `lynx-*` 以外的 environment 中为
`'react.web.bundle'`

***

### reactUmdPackageName?

```ts
optional reactUmdPackageName?: string;
```

提供 ReactLynx 运行时 bundle 的包名。

为其他发行版封装该插件时（例如
`@byted-lynx/react-umd`），可覆盖该选项。

#### 默认值

`'@lynx-js/react-umd'`

***

### ~~url?~~

```ts
optional url?: string;
```

直接覆盖运行时 bundle 的 URL。

仅当 ReactLynx 运行时托管在当前构建产物之外（例如 CDN 上）时才使用该选项。与 `bundlePath` 不同，该选项不会向当前编译产出任何额外资源。

#### 已被弃用

建议优先使用 `bundlePath`，它通过运行时 public
path 解析，并支持自动产出资源。
