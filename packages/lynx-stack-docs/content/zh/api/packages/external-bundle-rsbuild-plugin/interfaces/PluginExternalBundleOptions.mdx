# 接口: PluginExternalBundleOptions

external-bundle-rsbuild-plugin 的选项。

## 继承

- `Pick`\<`ExternalsLoadingPluginOptions`, `"globalObject"` \| `"timeout"` \| `"retries"`\>

## 属性

### externalBundleRoot?

```ts
optional externalBundleRoot?: string;
```

存放项目自有 external bundle 的根目录，这些 bundle 由
`bundlePath` 引用。

`pluginExternalBundle` 在开发环境提供服务
以及构建时生成资源时都会使用此目录。当
外部 bundle 构建到独立的输出文件夹（例如
`dist-external-bundle`）时，建议显式设置此项。

***

### externals?

```ts
optional externals?: Record<string, PluginExternalConfig>;
```

额外需要加载的显式 externals。

***

### externalsPresetDefinitions?

```ts
optional externalsPresetDefinitions?: ExternalsPresetDefinitions;
```

由 `externalsPresets` 启用的自定义 externals 预设的定义。

可用于添加业务专属的预设（例如 `lynxUi`），或通过 `extends`
扩展内置预设。

***

### externalsPresets?

```ts
optional externalsPresets?: ExternalsPresets;
```

外部库的预设。

与 https://rspack.rs/config/externals#externalspresets 相同，但适用于 Lynx。

***

### globalObject?

```ts
optional globalObject?: "lynx" | "globalThis";
```

该选项指定用于挂载库的全局对象。

在 Lynx 中，库默认挂载到 `lynx[Symbol.for("__LYNX_EXTERNAL_GLOBAL__")]` 上。

如果启用了 share js context，并希望通过挂载到全局对象来复用该库，可以将该选项设置为 `'globalThis'`。

#### 默认值

```ts
'lynx'
```

#### 继承自

```ts
Pick.globalObject
```

***

### retries?

```ts
optional retries?: number;
```

获取外部 bundle 超时（`response.code === -2`）时的额外重试次数。

#### 默认值

```ts
0
```

#### 继承自

```ts
Pick.retries
```

***

### timeout?

```ts
optional timeout?: number;
```

加载 externals 的超时时间，单位为毫秒。

#### 默认值

```ts
2000
```

#### 继承自

```ts
Pick.timeout
```
