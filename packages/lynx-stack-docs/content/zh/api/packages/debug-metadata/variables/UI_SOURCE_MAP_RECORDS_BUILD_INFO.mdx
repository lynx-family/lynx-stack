# 变量: UI\_SOURCE\_MAP\_RECORDS\_BUILD\_INFO

```ts
const UI_SOURCE_MAP_RECORDS_BUILD_INFO: "lynxUiSourceMapRecords" = 'lynxUiSourceMapRecords';
```

`module.buildInfo[UI_SOURCE_MAP_RECORDS_BUILD_INFO]` 是
主线程 loader 存放其从模块中提取出的 [UiSourceMapRecord](../interfaces/UiSourceMapRecord.mdx) 数组的地方，
供 `LynxDebugMetadataPlugin` 收集。

位于这个零依赖的 schema 包中，以便生产者
（`@lynx-js/react-webpack-plugin` 的 loader）和消费者
（`@lynx-js/debug-metadata-rsbuild-plugin`）都能读取同一个
常量，而无需彼此产生运行时依赖。
