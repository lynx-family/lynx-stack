# 模块: @lynx-js/debug-metadata

[npm](https://www.npmjs.com/package/@lynx-js/debug-metadata) · [Source](https://github.com/lynx-family/lynx-stack/tree/main/packages/tools/debug-metadata) · [Changelog](https://github.com/lynx-family/lynx-stack/blob/main/packages/tools/debug-metadata/CHANGELOG.md)

Lynx `debug-metadata.json` 格式的 schema 类型。

零运行时依赖。可以安全地在任意 Node.js 上下文中使用——
rsbuild 插件、dev-server 中间件、反向符号化服务、
CLI 工具等。使用 `JSON.parse` 读取 JSON，并转换为
[DebugMetadataAsset](interfaces/DebugMetadataAsset.mdx)；对于按字段查询（`?field=…`
风格的查询），使用 `FIELDS` 注册表和 `resolveField`
分发器。
