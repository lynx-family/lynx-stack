# 类型别名: DebugMetadataLoader

```ts
type DebugMetadataLoader = (debugMetadataUrl: string) => Promise<DebugMetadataAsset>;
```

加载节点的 `debugMetadataUrl` 所指向的 [DebugMetadataAsset](../interfaces/DebugMetadataAsset.mdx)。
由调用方提供，以使核心逻辑不涉及 I/O（CLI 负责接入
`fetch` / `fs`）；对每个不同的 URL 只调用一次。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `debugMetadataUrl` | `string` |

## 返回

`Promise`\<[`DebugMetadataAsset`](../interfaces/DebugMetadataAsset.mdx)\>
