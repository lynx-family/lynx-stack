# 接口: QueryParams

每个 resolver 都会收到的参数。resolver 会挑选自己需要的键。

## 属性

### filename?

```ts
optional filename?: string;
```

资源的 basename（例如 `main-thread.js`）。

***

### key?

```ts
optional key?: string;
```

Chunk hash / 发布标识符。

***

### path?

```ts
optional path?: string;
```

相对于 bundler 的资源路径（例如 `.lynx/main/main-thread.js.map`）。
