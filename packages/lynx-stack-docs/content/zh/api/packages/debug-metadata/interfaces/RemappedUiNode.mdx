# 接口: RemappedUiNode

经过反向解析后的 [UiNode](UiNode.mdx)。当节点的 `nodeIndex`
在其 `debugMetadataUrl` 对应的 UI source map 中已知时，会获得
[UiSourceLocation](UiSourceLocation.mdx) 字段；其余节点则原样返回。

## 继承

- [`UiNode`](UiNode.mdx)

## 可索引

```ts
[field: string]: unknown
```
