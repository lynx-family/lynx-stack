# 接口: LepusNGFunctionInfo

某个 lepusNG 函数的调试数据：将字节码 PC 偏移量映射回原始源码中的
`(line, column)`，并附带可选的调用方信息。

## 属性

### column\_number

```ts
column_number: number;
```

函数定义起始位置的源码列号（从 0 开始）。

***

### file\_name

```ts
file_name: string;
```

***

### function\_id

```ts
function_id: number;
```

***

### function\_name

```ts
function_name: string;
```

***

### line\_col

```ts
line_col: object[];
```

解码后的 line/column 对，编译器输出的每个源码位置对应一个。
`line_col.length` 与 `pc2line_buf` 中编码的映射数量一致。

#### column

```ts
column: number;
```

#### line

```ts
line: number;
```

***

### line\_number

```ts
line_number: number;
```

函数定义起始位置的源码行号（从 1 开始）。

***

### pc2caller\_info

```ts
pc2caller_info: Record<string, string>;
```

可选的 PC 偏移量 → 调用方源码片段映射。键为字符串化的
PC 偏移量；值为字节码内联自的原始函数体。
可用于对堆栈跟踪进行反内联（de-inline）。

***

### pc2line\_buf

```ts
pc2line_buf: number[];
```

PC-to-line 表的变长编码。解码规则
记录在 lepusNG 字节码调试信息规范中。

***

### pc2line\_len

```ts
pc2line_len: number;
```

`pc2line_buf` 的长度（字节）。
