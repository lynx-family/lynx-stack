# 接口: ResolveResult

[resolveField](../functions/resolveField.mdx) 的结果。

## 属性

### found

```ts
found: boolean;
```

当 resolver 匹配成功时为 `true`；当字段已知
但没有匹配到值时为 `false`（HTTP 层 → 404）。

***

### payload?

```ts
optional payload?: unknown;
```

仅在 `found` 时才存在。这是要 JSON 序列化并返回给
客户端的值（已通过 `FieldResolver.payload` 解包）。
