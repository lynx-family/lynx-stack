### rootDir

```ts
rootDir: string | null;
```

git worktree 根目录的绝对路径
（`git rev-parse --show-toplevel`）。消费方在反向符号化（reverse symbolication）过程中，
使用它把 source map 中相对源码的路径
解析回文件系统位置。
