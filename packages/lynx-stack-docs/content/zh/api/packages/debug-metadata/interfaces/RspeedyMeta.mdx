# 接口: RspeedyMeta

Rspeedy 为单个模板 / 入口生成的构建上下文。

## 属性

### bundlePath

```ts
bundlePath: string;
```

此元数据对应的模板文件名模式（例如
`main/template.js`）。使多入口项目无需依赖 storage-key 约定即可识别每个元数据文件属于哪个页面。

***

### entryFiles

```ts
entryFiles: string[];
```

该 debug-metadata 所对应的 webpack 入口（或多个入口）的源文件，以相对于 git rootDir
的路径表示（如果不在 git 仓库中，
则回退到 compiler context）。

通常是单个文件，但 webpack 允许数组形式的入口，并且
Lynx 内部会将每个用户入口拆分为多个 webpack 入口——两种情况都会在这里产生多个路径。
