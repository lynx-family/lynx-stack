# 接口: LepusNGDebugInfo

lepusNG 编码字节码的调试载荷，与
encoder 写入 `debug-info.json` 的 JSON 相同。顶层的 `lepusNG_debug_info`
key 被保留下来，以便消费方（Lynx runtime、反向符号化
服务）可以将 `?field=bytecode-debug-info` 响应和
旧版的 `debug-info.json` 文件视为同一种结构。

## 属性

### lepusNG\_debug\_info

```ts
lepusNG_debug_info: LepusNGDebugInfoBody;
```
