# 函数: normalizeRepo()

```ts
function normalizeRepo(remoteUrl: string | null | undefined): string | null;
```

将 git 远程 URL（SSH 或 HTTP 形式）规范化为
`owner/repo` 标识符，并去掉末尾的 `.git`。对于空
输入返回 `null`，对于不匹配任何已知形式的字符串则返回原字符串。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `remoteUrl` | `string` \| `null` \| `undefined` |

## 返回

`string` \| `null`
