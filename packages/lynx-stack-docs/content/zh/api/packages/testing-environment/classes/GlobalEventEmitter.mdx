# 类: GlobalEventEmitter

Lynx 的 `GlobalEventEmitter` 模块，可通过 `lynx.getJSModule('GlobalEventEmitter')` 访问。

框架测试库可以用它触发和监听跨线程事件。

## 构造函数

### 构造函数

```ts
new GlobalEventEmitter(): GlobalEventEmitter;
```

#### 返回

`GlobalEventEmitter`

## 属性

listeners: Record<string, Function[]> = {};
