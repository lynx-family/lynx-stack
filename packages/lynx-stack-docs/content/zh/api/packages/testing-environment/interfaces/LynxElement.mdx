# 接口: LynxElement

任意 Lynx 元素，例如 `view`、`text`、`image` 等。

[Lynx Spec Reference](https://lynxjs.org/living-spec/index.html?ts=1743416098203#element%E2%91%A0)

## 继承

- `HTMLElement`

## 属性

### cssId?

```ts
optional cssId?: string;
```

元素的 cssId

***

### eventMap?

```ts
optional eventMap?: object;
```

绑定到该元素的事件映射表。

#### 索引签名

```ts
[key: string]: any
```

***

### firstChild

```ts
firstChild: LynxElement;
```

返回第一个子节点。

[MDN Reference](https://developer.mozilla.org/docs/Web/API/Node/firstChild)

#### 重写了

```ts
HTMLElement.firstChild
```

### gesture?

[key: string]: any
