# 函数: pluginReactLynx()

```ts
function pluginReactLynx(userOptions?: PluginReactLynxOptions): RsbuildPlugin[];
```

创建用于 ReactLynx 的 Rsbuild 插件。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `userOptions?` | [`PluginReactLynxOptions`](../interfaces/PluginReactLynxOptions.mdx) |

## 返回

`RsbuildPlugin`[]

## 示例

```ts
// rsbuild.config.ts
import { pluginReactLynx } from '@lynx-js/react-rsbuild-plugin'
export default {
  plugins: [pluginReactLynx()]
}
```
