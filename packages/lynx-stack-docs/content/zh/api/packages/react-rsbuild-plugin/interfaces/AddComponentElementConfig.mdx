# 接口: AddComponentElementConfig

控制是否为组件添加包裹元素

## 属性

### compilerOnly

```ts
compilerOnly: boolean;
```

是否仅在编译期添加组件元素

#### 示例

注意，这仅对从 [CompatVisitorConfig.oldRuntimePkg](CompatVisitorConfig.mdx#oldruntimepkg) 导入的 `Component` 生效。

```js
import { defineConfig } from '@lynx-js/rspeedy'
import { pluginReactLynx } from '@lynx-js/react-rsbuild-plugin'

export default defineConfig({
  plugins: [
    pluginReactLynx({
      compat: {
        addComponentElement: { compilerOnly: true }
      },
    })
  ],
})
```
