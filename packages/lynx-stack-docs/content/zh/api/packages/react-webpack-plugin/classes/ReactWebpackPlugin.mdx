# 类: ReactWebpackPlugin

ReactWebpackPlugin 使 ReactLynx 可以与 webpack 一起使用

## 示例

```js
// webpack.config.js
import { ReactWebpackPlugin } from '@lynx-js/react-webpack-plugin'
export default {
  plugins: [new ReactWebpackPlugin()],
}
```

## 构造函数

### 构造函数

```ts
new ReactWebpackPlugin(options?: ReactWebpackPluginOptions): ReactWebpackPlugin;
```

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `options?` | [`ReactWebpackPluginOptions`](../interfaces/ReactWebpackPluginOptions.mdx) |

#### 返回

`ReactWebpackPlugin`

## 属性

### defaultOptions

```ts
static defaultOptions: Readonly<Required<ReactWebpackPluginOptions>>;
```

`defaultOptions` 是 ReactWebpackPlugin 使用的默认选项。

***

### loaders

```ts
static loaders: Record<keyof typeof LAYERS | "TESTING", string>;
```

ReactLynx 所用的 loader。

#### 备注

请注意，该 loader 会把 JSX/TSX 转换为合法的 JavaScript。
对于 `.ts` 和 `.tsx` 文件，TypeScript 类型也会被去除。

#### 示例

```js
// webpack.config.js
import { ReactWebpackPlugin, LAYERS } from '@lynx-js/react-webpack-plugin'
export default {
  module: {
    rules: [
      {
        test: /\.tsx?$/,
        layer: LAYERS.MAIN_THREAD,
        use: ['swc-loader', ReactWebpackPlugin.loaders.MAIN_THREAD]
      },
      {
        test: /\.tsx?$/,
        layer: LAYERS.BACKGROUND,
        use: ['swc-loader', ReactWebpackPlugin.loaders.BACKGROUND]
      },
    ],
  },
  plugins: [new ReactWebpackPlugin()],
}
```

## 方法

### apply()

```ts
apply(compiler: Compiler): void;
```

webpack 插件的入口点。

#### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `compiler` | `Compiler` | webpack 编译器 |

#### 返回

`void`
