# 类: Rpc

用于处理 MessagePort 远程过程调用（Remote Process Call）的实例

## 构造函数

### 构造函数

```ts
new Rpc(port: MessagePort | undefined, name: string): Rpc;
```

#### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `port` | `MessagePort` \| `undefined` | message channel 的一种大小 |
| `name` | `string` | 实例名称 |

#### 返回

`Rpc`

## 访问器

get nextRetId(): string;
