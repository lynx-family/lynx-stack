# 类: CDPChannel

一个无状态的 CDP（Chrome DevTools Protocol）通道，
用于向指定的 Lynx session 发送命令。

每次调用 `send()` 都是通过 `Connector` 进行的一次短生命周期请求/响应。
Channel 会按 session ID 使用 `WeakRef` 缓存，以便复用。

## 构造函数

### 构造函数

```ts
new CDPChannel(
   _connector: Connector, 
   _clientId: string, 
   _sessionId: number
): CDPChannel;
```

构造一个严格绑定到单个 Lynx session 的新 CDP Channel。

**给 Agent 的提示：**
请优先使用 `CDPChannel.from()`，而不是手动 new 出一个 channel，因为 `from()`
会处理 WeakRef 缓存以降低内存占用。

#### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `_connector` | `Connector` | 底层 ADB 传输控制器。 |
| `_clientId` | `string` | 已绑定的 devtool target 标识字符串。 |
| `_sessionId` | `number` | 范围较窄的 Lynx view session ID。 |

#### 返回

`CDPChannel`

## 方法

### send()

```ts
send<T extends keyof Protocol>(method: T, params: Protocol[T]["params"]): Promise<Protocol[T]["return"]>;
```

派发一个强类型的 Chrome DevTools Protocol（CDP）方法命令，并等待其返回结果。

**Agent 用法：**
这是 `kitten-lynx` 中所有交互的核心。它不会维护一个长连接的 socket，
而是每次 `send(...)` 调用都会构造一个自包含的 ADB 请求，并等待独立的响应。

**类型：**
请注意，泛型严格绑定到本文件顶部定义的 `Protocol` 接口。
如果你需要调用一个被 TypeScript 拒绝的 CDP 命令，必须先更新 `Protocol` 接口！

#### 类型参数

| 类型参数 | 描述 |
| ------ | ------ |
| `T` *extends* keyof `Protocol` | CDP 方法名的字符串字面量（例如 `'DOM.getDocument'`、`'Page.navigate'`）。 |

#### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `method` | `T` | 要发送给 Lynx devtool 服务器的命令。 |
| `params` | `Protocol`\[`T`\]\[`"params"`\] | CDP 方法所需的强类型 payload 对象。 |

#### 返回

`Promise`\<`Protocol`\[`T`\]\[`"return"`\]\>

一个 promise，解析为与 `method` 预期返回结构相匹配的强类型响应对象。

***

### from()

```ts
static from(
   sessionId: number, 
   clientId: string, 
   connector: Connector
): CDPChannel;
```

获取或实例化指定 Lynx session 对应的无状态 `CDPChannel`。

**设计模式（面向 Agent）：**
这个测试库采用**无状态**的 CDP 架构，以避免在不稳定的 ADB 链路上
出现挂起的 WebSocket 连接。Channel 会按 `sessionId` 通过 `WeakRef` 进行缓存，以减少分配。

#### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `sessionId` | `number` | Lynx runtime 分配的数字型 Lynx devtool session ID。 |
| `clientId` | `string` | 客户端应用的唯一设备端口标识符（例如 `"emulator-5554:40121"`）。 |
| `connector` | `Connector` | 为 ADB 传输提供支持的活跃 `Connector` 实例。 |

#### 返回

`CDPChannel`

绑定到所请求会话的 `CDPChannel` 引用。
