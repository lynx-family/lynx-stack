# 类: LynxCacheEventsPlugin

一个 webpack 插件，用于缓存在入口
启动完成之前到达的 Lynx native 调用，并在启动稳定后重放这些调用。

## 备注

仅当 `output.chunkLoading` 为 `'lynx'` 时才生效。

- Background chunk：始终会被缓存。覆盖 `lynx.getApp()` 的方法
  （`OnLifecycleEvent`、`publishEvent`、`publicComponentEvent`、
  `callDestroyLifetimeFun`、`updateGlobalProps`、`updateCardData`、
  `onAppReload`、`processCardConfig`）、`lynx.performance` 事件，以及
  `globalThis.loadDynamicComponent`。

- Main-thread chunk：仅在入口的启动是异步时才会被缓存，
  例如依赖异步外部 ReactLynx 的入口。`renderPage`
  会被缓存并重放，`processData` 会被 shim 为一个直通实现，直到真正的
  实现被安装为止。

## 构造函数

### 构造函数

```ts
new LynxCacheEventsPlugin(options?: LynxCacheEventsPluginOptions): LynxCacheEventsPlugin;
```

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `options?` | [`LynxCacheEventsPluginOptions`](../interfaces/LynxCacheEventsPluginOptions.mdx) |

#### 返回

`LynxCacheEventsPlugin`

## 属性

### defaultOptions

```ts
static defaultOptions: Readonly<Required<LynxCacheEventsPluginOptions>>;
```

`defaultOptions` 是 LynxCacheEventsPlugin 使用的默认选项。

#### 示例

`defaultOptions` 可用于修改部分选项，同时保留其余选项为默认值。

```js
// webpack.config.js
import { LynxCacheEventsPlugin } from '@lynx-js/cache-events-webpack-plugin'
export default {
  plugins: [
    new LynxCacheEventsPlugin({
      ...LynxCacheEventsPlugin.defaultOptions,
      setupListTransformer: (setupList) => setupList,
    }),
  ],
}
```
