# 接口: LynxCacheEventsPluginOptions

[LynxCacheEventsPlugin](../classes/LynxCacheEventsPlugin.mdx) 的选项

## 属性

### setupListTransformer?

```ts
optional setupListTransformer?: (setupList: string[], context: object) => string[];
```

用于修改 setup 列表的转换函数。

它针对每个可缓存的 chunk 各运行一次——后台线程和
async-external 主线程分别运行——因此 `context.isMainThread` 会告诉你
当前正在转换的是哪个线程的列表。可以用它来只为某一个线程添加缓存函数。

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `setupList` | `string`[] |
| `context` | \{ `isMainThread`: `boolean`; \} |
| `context.isMainThread` | `boolean` |

#### 返回

`string`[]

#### 示例

```js
// webpack.config.js
import { LynxCacheEventsPlugin } from '@lynx-js/cache-events-webpack-plugin'

const config = {
  plugins: [
    new LynxCacheEventsPlugin({
      setupListTransformer: (setupList, { isMainThread }) => {
        // only cache this event on the background thread
        if (!isMainThread) {
          setupList.push(
            `{
              name: 'customCacheEvent',
              setup: () => {
                console.log('customCacheEvent setup');
                return () => {
                  console.log('customCacheEvent teardown');
                }
              }
            }`
          )
        }
        return setupList;
      },
    }),
  ],
}
```
