# 函数: computed()

```ts
function computed<T>(fn: () => T, options?: SignalOptions<T>): ReadonlySignal<T>;
```

创建一个基于其他 signal 的值计算得出的新 signal。

返回的 computed signal 是只读的，当回调函数中访问的任意 signal 发生变化时，其值会自动更新。

## 类型参数

| 类型参数 |
| ------ |
| `T` |

## 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `fn` | () => `T` | effect 回调。 |
| `options?` | [`SignalOptions`](../interfaces/SignalOptions.mdx)\<`T`\> | - |

## 返回

[`ReadonlySignal`](../interfaces/ReadonlySignal.mdx)\<`T`\>

一个新的只读 signal。
