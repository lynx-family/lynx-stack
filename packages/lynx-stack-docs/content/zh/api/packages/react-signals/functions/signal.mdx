# 函数: signal()

## 调用签名

```ts
function signal<T>(value: T, options?: SignalOptions<T>): Signal<T>;
```

创建一个新的普通 signal。

### 类型参数

| 类型参数 |
| ------ |
| `T` |

### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `value` | `T` | signal 的初始值。 |
| `options?` | [`SignalOptions`](../interfaces/SignalOptions.mdx)\<`T`\> | - |

### 返回

[`Signal`](../classes/Signal.mdx)\<`T`\>

一个新的 signal。

function signal<T = undefined>(): Signal<T | undefined>;

| 类型参数 | 默认类型 |

### 返回
