# 函数: batch()

```ts
function batch<T>(fn: () => T): T;
```

将多次值更新合并为一次 "commit"，在给定回调结束时统一提交。

batch 可以嵌套，变更只会在最外层的 batch 回调
完成后才会被刷新（flush）。

在 batch 内访问已被修改的 signal，会得到其更新后的
值。

## 类型参数

| 类型参数 |
| ------ |
| `T` |

## 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `fn` | () => `T` | 回调函数。 |

## 返回

`T`

回调返回的值。
