# 函数: untracked()

```ts
function untracked<T>(fn: () => T): T;
```

运行一个回调函数，该函数可以访问 signal 的值，但不会订阅 signal 的更新。

在 `createModel` 工厂函数内部调用时，这也会抑制
model 拥有的 effect 捕获。回调内部创建的 effect 不会
被外层 model 所拥有，必须手动释放。回调内部嵌套的
`createModel` 调用仍会捕获自己的 effect。

## 类型参数

| 类型参数 |
| ------ |
| `T` |

## 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `fn` | () => `T` | 回调函数。 |

## 返回

`T`

回调返回的值。
