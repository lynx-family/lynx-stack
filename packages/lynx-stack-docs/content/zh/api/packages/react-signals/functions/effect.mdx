# 函数: effect()

```ts
function effect(fn: EffectFn, options?: EffectOptions): DisposeFn;
```

创建一个 effect，用于在 signal 变化时运行任意代码。

effect 会跟踪在给定回调
函数 `fn` 中访问了哪些 signal，并在这些 signal 变化时重新运行该回调。

该回调可以返回一个清理函数。清理函数只会运行一次，
会在回调下一次被调用时或该 effect 被销毁时运行，
以两者中先发生的为准。

## 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `fn` | `EffectFn` | effect 回调。 |
| `options?` | [`EffectOptions`](../interfaces/EffectOptions.mdx) | - |

## 返回

`DisposeFn`

用于销毁该 effect 的函数。
