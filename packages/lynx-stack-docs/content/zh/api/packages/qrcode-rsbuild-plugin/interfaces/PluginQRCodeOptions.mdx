# 接口: PluginQRCodeOptions

[pluginQRCode](../functions/pluginQRCode.mdx) 的选项。

## 属性

### fullscreen?

```ts
optional fullscreen?: boolean;
```

启用 Lynx bundle URL 的全屏变体（追加
`?fullscreen=true`，在 LynxExplorer 中打开 bundle 时会隐藏应用内导航栏）。

启用后，插件会：
- 在 schema 轮换列表中追加一个 `fullscreen` 项：二维码仍然
  打开默认 schema，在开发控制台中按 `a` 可切换
  到 `fullscreen` 变体。
- 在开发服务器打印的每个 Lynx bundle URL
  下方追加一行 `∟ Fullscreen` URL。

#### 默认值

`false`

***

### schema?

```ts
optional schema?: CustomizedSchemaFn;
```

自定义生成的 schema。

#### 示例

```js
import { pluginQRCode } from '@lynx-js/qrcode-rsbuild-plugin'
import { pluginReactLynx } from '@lynx-js/react-rsbuild-plugin'
import { defineConfig } from '@rsbuild/core'

export default defineConfig({
  plugins: [
    pluginReactLynx(),
    pluginQRCode({
      schema(url) {
        return `lynx://${url}?dev=1`
      },
    }),
  ],
})
```

- 使用多个 schema：

可以在终端中按 `a` 切换 schema。

```js
import { pluginQRCode } from '@lynx-js/qrcode-rsbuild-plugin'
import { pluginReactLynx } from '@lynx-js/react-rsbuild-plugin'
import { defineConfig } from '@rsbuild/core'

export default defineConfig({
  plugins: [
    pluginReactLynx(),
    pluginQRCode({
      schema(url) {
        return {
          http: url,
          foo: `foo://lynx?url=${encodeURIComponent(url)}&dev=1`,
          bar: `bar://lynx?url=${encodeURIComponent(url)}`,
        }
      },
    }),
  ],
})
```
