### chunkFilename?

```ts
optional chunkFilename?: string;
```

非初始 CSS chunk 文件的名称

#### 备注

设置后，lazy bundle 的 CSS chunk 仍会输出到
`.lynx/lazy-bundle/<name>/<layer>.css`（如果该 chunk 没有 layer，
则输出到 `.lynx/lazy-bundle/<name>.css`）；此模板适用于其他 chunk。

#### 重写了

```ts

```
