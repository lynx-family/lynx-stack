# 模块: @lynx-js/externals-loading-webpack-plugin

[npm](https://www.npmjs.com/package/@lynx-js/externals-loading-webpack-plugin) · [Source](https://github.com/lynx-family/lynx-stack/tree/main/packages/webpack/externals-loading-webpack-plugin) · [Changelog](https://github.com/lynx-family/lynx-stack/blob/main/packages/webpack/externals-loading-webpack-plugin/CHANGELOG.md)

一个用于在 Lynx 中加载外部依赖（externals）的 webpack 插件。使用 `lynx.fetchBundle()` 和 `lynx.loadScript()` API 来加载和解析这些外部依赖。

## 备注

需要 Lynx 3.5 及以上版本。
