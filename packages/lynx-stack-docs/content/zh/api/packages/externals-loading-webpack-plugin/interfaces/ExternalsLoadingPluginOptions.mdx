# 接口: ExternalsLoadingPluginOptions

`ExternalsLoadingPlugin` 的选项。

## 属性

### backgroundLayer

```ts
backgroundLayer: string;
```

background layer 的名称。

***

### externals

```ts
externals: Record<string, ExternalValue>;
```

指定要加载的 externals。externals 应为 Lynx Bundle。

#### 示例

在后台层和 `main-thread` 层中都加载 `lodash` 库。

```js
module.exports = {
 plugins: [
   new ExternalsLoadingPlugin({
     mainThreadLayer: 'main-thread',
     backgroundLayer: 'background',
     externals: {
       lodash: {
         url: 'http://lodash.lynx.bundle',
         background: { sectionPath: 'background' },
         mainThread: { sectionPath: 'mainThread' },
       },
     },
   }),
 ],
};
```

只在后台层加载 `lodash` 库。

```js
module.exports = {
 plugins: [
   new ExternalsLoadingPlugin({
     mainThreadLayer: 'main-thread',
     backgroundLayer: 'background',
     externals: {
       lodash: {
         url: 'http://lodash.lynx.bundle',
         background: { sectionPath: 'background' }
       },
     },
   }),
 ],
};
```

***

### globalObject?

```ts
optional globalObject?: "lynx" | "globalThis";
```

该选项指定用于挂载库的全局对象。

在 Lynx 中，库默认挂载到 `lynx[Symbol.for("__LYNX_EXTERNAL_GLOBAL__")]` 上。

如果启用了 share js context，并希望通过挂载到全局对象来复用该库，可以将该选项设置为 `'globalThis'`。

#### 默认值

```ts
'lynx'
```

***

### mainThreadLayer

```ts
mainThreadLayer: string;
```

主线程 layer 的名称。

***

### retries?

```ts
optional retries?: number;
```

获取外部 bundle 超时（`response.code === -2`）时的额外重试次数。

#### 默认值

```ts
0
```

***

### timeout?

```ts
optional timeout?: number;
```

加载 externals 的超时时间，单位为毫秒。

#### 默认值

```ts
2000
```
