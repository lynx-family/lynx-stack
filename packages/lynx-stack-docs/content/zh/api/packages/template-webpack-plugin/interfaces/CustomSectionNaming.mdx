# 接口: CustomSectionNaming

指定 chunk 以哪个名称作为自定义 section 发出。

## 备注

返回 `undefined` 可以让某个 chunk 不进入自定义 sections。被排除的后台
chunk 仍会留在 manifest 中，而运行时正是从 manifest 中查找它的。

## 方法

### background()

```ts
background(manifestKey: string, index: number): string | undefined;
```

#### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `manifestKey` | `string` | 该 chunk 在 manifest 中的键。lazy bundle 以路径为键（`/.rspeedy/lazy-bundle/…/background.js`），external bundle 以产物名为键。 |
| `index` | `number` | - |

#### 返回

`string` \| `undefined`
