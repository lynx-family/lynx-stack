# 接口: ResolvedTasmCSSDiagnostic

带有格式化消息和可选 source map
位置信息的 TASM CSS 诊断。

## 继承

- [`TasmCSSDiagnostic`](TasmCSSDiagnostic.mdx)

## 属性

### column

```ts
column: number;
```

TASM 报告的生成 CSS 列号。

#### 继承自

[`TasmCSSDiagnostic`](TasmCSSDiagnostic.mdx).[`column`](TasmCSSDiagnostic.mdx#column)

***

### line

```ts
line: number;
```

TASM 报告的生成 CSS 行号。

#### 继承自

[`TasmCSSDiagnostic`](TasmCSSDiagnostic.mdx).[`line`](TasmCSSDiagnostic.mdx#line)

***

### message

```ts
message: string;
```

适用于 webpack 诊断的警告信息。

***

### name?

```ts
optional name?: string;
```

当 TASM 报告时，表示不支持的 CSS 语法名称。

#### 继承自

[`TasmCSSDiagnostic`](TasmCSSDiagnostic.mdx).[`name`](TasmCSSDiagnostic.mdx#name)

***

### sourceColumn?

```ts
optional sourceColumn?: number;
```

从 CSS source map 解析出的原始源码列号。

***

### sourceFile?

```ts
optional sourceFile?: string;
```

从 CSS source map 解析出的原始源码文件。

***

### sourceLine?

```ts
optional sourceLine?: number;
```

从 CSS source map 解析出的原始源码行号。

***

### type?

```ts
optional type?: string;
```

诊断类别，例如 `property`。

#### 继承自

[`TasmCSSDiagnostic`](TasmCSSDiagnostic.mdx).[`type`](TasmCSSDiagnostic.mdx#type)
