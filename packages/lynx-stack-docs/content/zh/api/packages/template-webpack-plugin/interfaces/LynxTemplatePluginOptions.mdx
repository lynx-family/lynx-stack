# 接口: LynxTemplatePluginOptions

LynxTemplatePlugin 的选项

## 属性

### appType?

```ts
optional appType?: "card" | "DynamicComponent";
```

要编码的 bundle 类型。

#### 默认值

对于 lazy bundle 为 `'DynamicComponent'`，否则为 `'card'`。

***

### chunks?

```ts
optional chunks?: "all" | string[];
```

列出所有应被注入的条目

#### 默认值

`'all'`

***

### cssPlugins

```ts
cssPlugins: Plugin[];
```

传递给 parser 的插件

***

### customCSSInheritanceList

```ts
customCSSInheritanceList: string[] | undefined;
```

启用 [PluginReactLynxOptions.enableCSSInheritance](../../react-rsbuild-plugin/interfaces/PluginReactLynxOptions.mdx#enablecssinheritance) 后，可以通过 `customCSSInheritanceList` 控制哪些属性可继承，而不仅限于默认属性。

#### 示例

设置 `customCSSInheritanceList: ['direction', 'overflow']` 后，只有 `direction` 和 `overflow` 属性可继承。

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
 plugins: [
   pluginReactLynx({
     enableCSSInheritance: true,
     customCSSInheritanceList: ['direction', 'overflow']
   }),
 ],
})
```

***

### customSectionNaming?

```ts
optional customSectionNaming?: (compilation: Compilation) => CustomSectionNaming;
```

将每个 chunk 组装进一个自定义 section 中，其命名由该策略决定。

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `compilation` | `Compilation` |

#### 返回

[`CustomSectionNaming`](CustomSectionNaming.mdx)

#### 备注

以这种方式组装出的 bundle 不包含 `lepusCode`，只有未命名的
chunk 会保留在 manifest 中。`FetchBundle` 类型的 lazy bundle
默认就是以这种方式组装的，使用其运行时所解析的三个 section 名称。

***

### debugInfoOutside

```ts
debugInfoOutside: boolean;
```

debugInfoOutside 控制调试信息是否放在模板之外。

#### 备注

推荐设置为 true 以减小模板体积。

***

### defaultDisplayLinear

```ts
defaultDisplayLinear: boolean;
```

defaultDisplayLinear 控制 CSS 中 `display` 的默认值是否为 `linear`。

如果 `defaultDisplayLinear === false`，`display` 的默认值将为 `flex` 而非 `linear`。

***

### defaultOverflowVisible?

```ts
optional defaultOverflowVisible?: boolean;
```

启用后，view 和组件默认的 overflow CSS 属性将是 `'visible'`。否则将是 `'hidden'`。

#### 默认值

`true`

***

### dsl?

```ts
optional dsl?: "tt" | "react" | "react_nodiff";
```

向编码器声明当前的 dsl。

***

### enableA11y

```ts
enableA11y: boolean;
```

使用 Android View 层级的 API 和系统实现。

***

### enableAccessibilityElement

```ts
enableAccessibilityElement: boolean;
```

enableAccessibilityElement 用于设置所有 `<view />` 元素的 `accessibility-element` 默认值。

***

### enableCSSInheritance

```ts
enableCSSInheritance: boolean;
```

enableCSSInheritance 用于启用默认的继承属性。

#### 备注

以下属性默认可继承：

- `direction`

- `color`

- `font-family`

- `font-size`

- `font-style`

- `font-weight`

- `letter-spacing`

- `line-height`

- `line-spacing`

- `text-align`

- `text-decoration`

- `text-shadow`

推荐与 [PluginReactLynxOptions.customCSSInheritanceList](../../react-rsbuild-plugin/interfaces/PluginReactLynxOptions.mdx#customcssinheritancelist) 一起使用，以避免性能问题。

***

### enableCSSInvalidation

```ts
enableCSSInvalidation: boolean;
```

CSS Invalidation 是指在 DOM 更新时，确定哪些元素需要重新计算样式的过程。

#### 备注

当使用组合器（combinator）确定各元素的样式（包括后代、相邻兄弟等）时，推荐启用此功能。否则只有初始设置的 class 能匹配对应的组合器，后续更新不会重新计算相关样式。

我们发现收集 invalidation 节点并进行更新是一个相对耗时的过程。如果没有此类用法，且需要更好的样式匹配性能，可以选择性地关闭此功能。

***

### enableCSSSelector

```ts
enableCSSSelector: boolean;
```

enableCSSSelector 控制是否启用新的 CSS 实现。

### enableNewGesture

```ts
enableNewGesture: boolean;
```

enableNewGesture 用于启用新的手势系统。

***

### enableRemoveCSSScope

```ts
enableRemoveCSSScope: boolean;
```

enableRemoveCSSScope 控制是否将 CSS 限制在组件作用域内使用。

`true`：所有 CSS 文件都被视为全局 CSS。

`false`：所有 CSS 文件都被视为作用域 CSS，仅在显式导入它的组件中生效。

`undefined`：仅对 CSS Modules 使用作用域 CSS，其他 CSS 文件视为全局 CSS。作用域 CSS 比全局 CSS 更快，因此如果遇到性能问题，可以使用 CSS Modules 来加速 CSS。

***

### filename?

```ts
optional filename?: string | ((entryName: string) => string);
```

要写入模板的文件。
支持子目录，例如：`assets/template.js`。
[name] 会被替换为入口名称。

#### 默认值

`'[name].bundle'`
