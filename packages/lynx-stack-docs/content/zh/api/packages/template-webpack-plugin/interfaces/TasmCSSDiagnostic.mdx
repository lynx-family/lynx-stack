# 接口: TasmCSSDiagnostic

TASM 在模板编码过程中发出的 CSS 诊断信息。

## 继承于

- [`ResolvedTasmCSSDiagnostic`](ResolvedTasmCSSDiagnostic.mdx)

## 属性

### column

```ts
column: number;
```

TASM 报告的生成 CSS 列号。

***

### line

```ts
line: number;
```

TASM 报告的生成 CSS 行号。

***

### name?

```ts
optional name?: string;
```

当 TASM 报告时，表示不支持的 CSS 语法名称。

***

### type?

```ts
optional type?: string;
```

诊断类别，例如 `property`。
