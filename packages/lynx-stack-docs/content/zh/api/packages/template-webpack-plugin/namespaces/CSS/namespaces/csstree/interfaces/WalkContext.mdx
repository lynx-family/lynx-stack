### break

```ts
break: symbol;
```

停止遍历。一旦某个 visitor 函数返回该值，
就不会再调用其他 visitor 函数。

### skip

```ts
skip: symbol;
```

阻止当前节点被继续遍历。不会为它的属性或子节点
调用任何访问函数；请注意该值只对 enter visitor 有效，
因为 leave visitor 是在遍历完节点的所有属性和子节点
之后才被调用的。
