# 接口: MotionValue\<V = `any`\>

`MotionValue` 用于追踪动效值的状态和速度。

## 类型参数

| 类型参数 | 默认类型 |
| ------ | ------ |
| `V` | `any` |

## 属性

### accelerate?

```ts
optional accelerate?: AccelerateConfig;
```

滚动时间线加速元数据。设置后，VisualElement
可以创建绑定到滚动时间线的原生 WAAPI 动画，
而不是通过 JS 驱动更新。

***

### ~~onChange()~~

```ts
onChange(subscription: Subscriber<V>): () => void;
```

添加一个函数，当 `MotionValue` 更新时会收到通知。

它返回一个函数，调用该函数会取消订阅。

在 React 组件内部调用 `onChange` 时，应将其包裹在
`useEffect` Hook 中。由于它会返回一个取消订阅的函数，应将其从
`useEffect` 函数中返回，以确保不会添加重复的订阅者。.

```jsx
export const MyComponent = () => {
  const x = useMotionValue(0)
  const y = useMotionValue(0)
  const opacity = useMotionValue(1)

  useEffect(() => {
    function updateOpacity() {
      const maxXY = Math.max(x.get(), y.get())
      const newOpacity = transform(maxXY, [0, 100], [1, 0])
      opacity.set(newOpacity)
    }

    const unsubscribeX = x.on("change", updateOpacity)
    const unsubscribeY = y.on("change", updateOpacity)

    return () => {
      unsubscribeX()
      unsubscribeY()
    }
  }, [])

  return <motion.div style={{ x }} />
}
```

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `subscription` | `Subscriber`\<`V`\> |

#### 返回

调用后会取消该订阅的函数。

() => `void`

#### 已被弃用
