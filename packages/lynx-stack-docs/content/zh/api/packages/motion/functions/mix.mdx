# 函数: mix()

## 调用签名

```ts
function mix<T>(from: T, to: T): Mixer<T>;
```

### 类型参数

| 类型参数 |
| ------ |
| `T` |

### 参数

| 参数 | 类型 |
| ------ | ------ |
| `from` | `T` |
| `to` | `T` |

### 返回

`Mixer`\<`T`\>
