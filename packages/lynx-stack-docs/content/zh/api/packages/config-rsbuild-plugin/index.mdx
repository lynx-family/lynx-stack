# 模块: @lynx-js/config-rsbuild-plugin

[npm](https://www.npmjs.com/package/@lynx-js/config-rsbuild-plugin) · [Source](https://github.com/lynx-family/lynx-stack/tree/main/packages/rspeedy/plugin-config) · [Changelog](https://github.com/lynx-family/lynx-stack/blob/main/packages/rspeedy/plugin-config/CHANGELOG.md)

用于配置由 `@lynx-js/type-config` 定义的 Lynx Config 的 Rsbuild 插件。

## 示例

```ts
import { pluginLynxConfig } from '@lynx-js/config-rsbuild-plugin'
import { pluginReactLynx } from '@lynx-js/react-rsbuild-plugin'
import { defineConfig } from '@rsbuild/core'

export default defineConfig({
  plugins: [
    pluginReactLynx(),
    pluginLynxConfig({
      alignMouseEventWithW3C: true,
    }),
  ],
})
```
