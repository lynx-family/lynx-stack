# 函数: pluginLynxConfig()

```ts
function pluginLynxConfig(config: Config, options?: Options): RsbuildPlugin;
```

用于配置由 `@lynx-js/type-config` 定义的 Lynx Config 的 Rsbuild 插件。

## 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `config` | [`Config`](../interfaces/Config.mdx) | 要设置的 Lynx 配置。 |
| `options?` | [`Options`](../interfaces/Options.mdx) | - |

## 返回

`RsbuildPlugin`

## 示例

```ts
import { pluginLynxConfig } from '@lynx-js/config-rsbuild-plugin'
import { pluginReactLynx } from '@lynx-js/react-rsbuild-plugin'
import { defineConfig } from '@rsbuild/core'

export default defineConfig({
  plugins: [
    pluginReactLynx(),
    pluginLynxConfig({
      alignMouseEventWithW3C: true,
    }),
  ],
})
```
