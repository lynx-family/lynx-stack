# 类: WebSocket

Lynx 的 [WebSocket](https://developer.mozilla.org/en-US/docs/Web/API/WebSocket) 实现。

## 备注

这仅在具有 `NativeModules.LynxWebSocketModule` 的环境中有效。

## 构造函数

### 构造函数

```ts
new WebSocket(
   url: string, 
   protocols?: string | string[], 
   options?: object
): WebSocket;
```

#### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `url` | `string` | 要连接的 URL；应为 WebSocket 服务器将响应的 URL。 |
| `protocols?` | `string` \| `string`[] | 可以是单个协议字符串，也可以是协议字符串数组。如果省略，默认使用空数组，即 `[]`。 |
| `options?` | \{ `headers?`: `Record`\<`string`, `string`\>; \} | 仅供 Lynx 使用的额外选项。 |
| `options.headers?` | `Record`\<`string`, `string`\> | - |

#### 返回

`WebSocket`

## 属性

### CLOSED

```ts
static CLOSED: ReadyState = ReadyState.CLOSED;
```

连接已关闭或无法打开。

***

### CLOSING

```ts
static CLOSING: ReadyState = ReadyState.CLOSING;
```

连接正在关闭过程中。

***

### CONNECTING

```ts
static CONNECTING: ReadyState = ReadyState.CONNECTING;
```

Socket 已创建。连接尚未打开。

***

### OPEN

```ts
static OPEN: ReadyState = ReadyState.OPEN;
```

连接已打开，可以进行通信。

## 方法

### addEventListener()

```ts
addEventListener<T extends keyof EventMap>(type: T, callback?: (event: EventMap[T]) => void): void;
```

`EventTarget` 接口的 `addEventListener()` 方法用于设置一个函数，每当指定事件被传递到目标对象时就会调用该函数。

#### 类型参数

| 类型参数 |
| ------ |
| `T` *extends* keyof [`EventMap`](../type-aliases/EventMap.mdx) |

#### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `type` | `T` | 表示要监听的事件类型的区分大小写的字符串。 |
| `callback?` | (`event`: [`EventMap`](../type-aliases/EventMap.mdx)\[`T`\]) => `void` | 接收通知的函数。事件详情见 [@lynx-js/websocket!EventMap](../type-aliases/EventMap.mdx)。 |

#### 返回

`void`

***

### close()

```ts
close(code?: number, reason?: string): void;
```

`close()` 方法用于关闭 WebSocket 连接或正在进行的连接尝试（如果有）。

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `code?` | `number` |
| `reason?` | `string` |

#### 返回

`void`

#### 备注

如果连接已经处于 [CLOSED](#closed) 状态，该方法不做任何事。

***

### ping()

```ts
ping(): void;
```

`ping` 方法通过 WebSocket 连接向服务器发送一条空消息。

#### 返回

`void`

#### 备注

如果在连接处于 [CONNECTING](#connecting) 状态时调用 `ping()`，会抛出异常。如果在连接处于 [CLOSING](#closing) 或 [CLOSED](#closed) 状态时调用 `ping()`，会静默丢弃数据。

***

removeEventListener<T extends keyof EventMap>(type: T, callback: (event: EventMap[T]) => void): void;

`EventTarget` 接口的 `removeEventListener()` 方法从 WebSocket 上移除一个事件监听器。
