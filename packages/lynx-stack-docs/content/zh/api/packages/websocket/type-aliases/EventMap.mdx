# 类型别名: EventMap

```ts
type EventMap = object;
```

`EventMap` 描述了 [@lynx-js/websocket!WebSocket](../classes/WebSocket.mdx) 可能触发的事件。

## 属性

### close

```ts
close: Event<"close"> & object;
```

当与 [@lynx-js/websocket!WebSocket](../classes/WebSocket.mdx) 的连接关闭时，会触发 `close` 事件。

#### 类型声明

##### code

```ts
readonly code: number;
```

##### reason

```ts
readonly reason: string;
```

***

### error

```ts
error: Event<"error"> & object;
```

当与 [@lynx-js/websocket!WebSocket](../classes/WebSocket.mdx) 的连接因错误而关闭时（例如某些数据无法发送），会触发 `error` 事件。

#### 类型声明

##### message

```ts
readonly message: string;
```

***

### message

```ts
message: Event<"message"> & object;
```

当通过 [@lynx-js/websocket!WebSocket](../classes/WebSocket.mdx) 接收到数据时，会触发 `message` 事件。

#### 类型声明

##### data

```ts
readonly data: string;
```

***

### open

```ts
open: Event<"open">;
```

当与 [@lynx-js/websocket!WebSocket](../classes/WebSocket.mdx) 的连接建立时，会触发 `open` 事件。
