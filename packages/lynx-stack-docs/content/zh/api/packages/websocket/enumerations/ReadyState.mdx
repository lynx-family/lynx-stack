# 枚举: ReadyState

`ReadyState` 描述了 `WebSocket` 连接的状态。

## 参阅

https://developer.mozilla.org/en-US/docs/Web/API/WebSocket/readyState

## 枚举成员

### CLOSED

```ts
CLOSED: 3;
```

连接已关闭或无法打开。

***

### CLOSING

```ts
CLOSING: 2;
```

连接正在关闭过程中。

***

### CONNECTING

```ts
CONNECTING: 0;
```

Socket 已创建。连接尚未打开。

***

### OPEN

```ts
OPEN: 1;
```

连接已打开，可以进行通信。
