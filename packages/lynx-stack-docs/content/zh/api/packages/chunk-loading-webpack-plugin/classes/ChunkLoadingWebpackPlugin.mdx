# 类: ChunkLoadingWebpackPlugin

ChunkLoadingWebpackPlugin 为 Lynx 中的 Rspack 启用 chunk 加载。
仅当 `output.chunkLoading` 为 `'lynx'` 时才会生效。

## 示例

```js
// rspack.config.js
import { ChunkLoadingWebpackPlugin } from '@lynx-js/chunk-loading-webpack-plugin'
export default {
  output: {
    chunkLoading: 'lynx',
    chunkFormat: 'commonjs',
  },
  plugins: [new ChunkLoadingWebpackPlugin()],
}
```

## 构造函数

### 构造函数

```ts
new ChunkLoadingWebpackPlugin(options?: Partial<ChunkLoadingWebpackPluginOptions>): ChunkLoadingWebpackPlugin;
```

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `options` | `Partial`\<[`ChunkLoadingWebpackPluginOptions`](../interfaces/ChunkLoadingWebpackPluginOptions.mdx)\> |

`ChunkLoadingWebpackPlugin`
