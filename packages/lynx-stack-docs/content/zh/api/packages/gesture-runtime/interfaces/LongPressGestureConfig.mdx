# 接口: LongPressGestureConfig

LongPressGesture 的配置接口。
Long press gesture 用于识别长按手势。

## 继承

- [`BaseGestureConfig`](BaseGestureConfig.mdx)

## 可索引

```ts
[key: string]: unknown
```

## 属性

### enabled?

```ts
optional enabled?: boolean;
```

该手势是否启用。默认为 true。

#### 继承自

[`BaseGestureConfig`](BaseGestureConfig.mdx).[`enabled`](BaseGestureConfig.mdx#enabled)

***

### maxDistance?

```ts
optional maxDistance?: number;
```

触摸点仍被视为长按时可移动的最大距离（单位：point）。默认为 10。

***

### minDuration?

```ts
optional minDuration?: number;
```

长按的最小持续时间（单位：毫秒）。默认为 500ms。
