# 接口: TapGestureConfig

TapGesture 的配置接口。
Tap gesture 用于识别点击（tap）手势。

## 继承

- [`BaseGestureConfig`](BaseGestureConfig.mdx)

## 可索引

```ts
[key: string]: unknown
```

## 属性

### enabled?

```ts
optional enabled?: boolean;
```

该手势是否启用。默认为 true。

#### 继承自

[`BaseGestureConfig`](BaseGestureConfig.mdx).[`enabled`](BaseGestureConfig.mdx#enabled)

***

### maxDistance?

```ts
optional maxDistance?: number;
```

触摸点仍被视为点击时可移动的最大距离（单位：point）。默认为 10。

***

### maxDuration?

```ts
optional maxDuration?: number;
```

点击的最大持续时间（单位：毫秒）。默认为 500ms。

***

### numberOfTaps?

```ts
optional numberOfTaps?: number;
```

所需的点击次数。默认为 1。
