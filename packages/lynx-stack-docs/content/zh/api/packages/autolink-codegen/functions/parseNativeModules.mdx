# 函数: parseNativeModules()

```ts
function parseNativeModules(source: string, filename?: string): NativeModuleSpec[];
```

从 TypeScript 声明源码中解析标有 `@lynxmodule` 的原生模块声明。

## 参数

| 参数 | 类型 | 默认值 |
| ------ | ------ | ------ |
| `source` | `string` | `undefined` |
| `filename` | `string` | `'<inline>'` |

## 返回

[`NativeModuleSpec`](../interfaces/NativeModuleSpec.mdx)[]
