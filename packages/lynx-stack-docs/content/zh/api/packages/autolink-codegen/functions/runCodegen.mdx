# 函数: runCodegen()

```ts
function runCodegen(options?: CodegenOptions): GeneratedFile[];
```

将生成的文件写入磁盘，跳过标记为 `overwrite: false` 的已存在文件，
并返回生成的文件描述符。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `options` | [`CodegenOptions`](../interfaces/CodegenOptions.mdx) |

## 返回

[`GeneratedFile`](../interfaces/GeneratedFile.mdx)[]
