# 接口: ExternalBundleLibConfig

`defineExternalBundleRslibConfig` 接受的 Rslib 配置结构。

## 继承

- `LibConfig`

## 属性

### autoExtension?

```ts
optional autoExtension?: boolean;
```

是否根据 [format](#format) 选项自动设置 JavaScript 输出文件的扩展名。

#### 默认值

`true`

#### 参阅

[https://rslib.rs/config/lib/auto-extension](https://rslib.rs/config/lib/auto-extension)

#### 继承自

```ts
LibConfig.autoExtension
```

***

### ~~autoExternal?~~

```ts
optional autoExternal?: AutoExternal;
```

是否自动将不同依赖类型的依赖外部化，而不将它们打包进 bundle。

#### 已被弃用

请改用 `output.autoExternal`。

#### 默认值

当 [format](#format) 为 `cjs` 或 `esm` 时为 `true`，当 [format](#format) 为 `umd` 或 `mf` 时为 `false`。

#### 参阅

[https://rslib.rs/config/lib/auto-external](https://rslib.rs/config/lib/auto-external)

#### 继承自

```ts
LibConfig.autoExternal
```

### shims?

```ts
optional shims?: Shims;
```

配置 CommonJS 和 ESM 输出的 shim。

#### 默认值

```js
const defaultShims = {
  cjs: {
    'import.meta.url': true,
    'import.meta.dirname': true,
    'import.meta.filename': true,
  },
  esm: {
    __filename: false,
    __dirname: false,
    require: false,
  },
};
```

#### 参阅

[https://rslib.rs/config/lib/shims](https://rslib.rs/config/lib/shims)

#### 继承自

```ts
LibConfig.shims
```

### wasm?

```ts
optional wasm?: Wasm;
```

配置 Rslib 如何处理 `.wasm` 模块。

该选项只有在 `format` 为 `'esm'` 时才能配置。

#### 默认值

当 `bundle` 为 `true` 时为 `{ mode: 'compile' }`；当 `bundle` 为 `false` 时为 `{ mode: 'preserve' }`。

#### 参阅

[https://rslib.rs/config/lib/wasm](https://rslib.rs/config/lib/wasm)

#### 继承自

```ts
LibConfig.wasm
```
