# 类型别名: OutputConfig

```ts
type OutputConfig = Required<LibConfig>["output"] & object;
```

Lynx external bundle 构建接受的输出配置。

## 类型声明

### externals?

```ts
optional externals?: Externals;
```

### externalsPresetDefinitions?

```ts
optional externalsPresetDefinitions?: ExternalsPresetDefinitions;
```

由 `externalsPresets` 启用的自定义 externals 预设的定义。

用于添加业务相关的预设（例如 `@lynx-js/lynx-ui`），或通过 `extends` 扩展内置预设。

### externalsPresets?

```ts
optional externalsPresets?: ExternalsPresets;
```

外部库的预设。

与 https://rspack.rs/config/externals#externalspresets 相同，但适用于 Lynx。

### globalObject?

```ts
optional globalObject?: "lynx" | "globalThis";
```

该选项指定用于挂载库的全局对象。

在 Lynx 中，库默认挂载到 `lynx[Symbol.for("__LYNX_EXTERNAL_GLOBAL__")]` 上。

如果启用了 share js context，并希望通过挂载到全局对象来复用该库，可以将该选项设置为 `'globalThis'`。

#### 默认值

`'lynx'`
