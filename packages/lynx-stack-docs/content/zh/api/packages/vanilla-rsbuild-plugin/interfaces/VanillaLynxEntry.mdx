# 接口: VanillaLynxEntry

一个逻辑 Vanilla Lynx 入口的两个线程源文件。

## 属性

### background?

```ts
optional background?: string | false;
```

在后台 JavaScript 线程中执行的源码。

#### 备注

省略时，如果存在同级的 `background.ts` 文件，则会使用它。将此
设置为 `false` 可显式创建仅包含主线程的 bundle。

***

### css?

```ts
optional css?: string | false;
```

编码进 Lynx 模板中的 CSS 源码。

#### 备注

省略时，如果存在同级的 `style.css` 文件，则会使用它。将此设置为
`false` 可禁用该约定。

***

### mainThread

```ts
mainThread: string;
```

在 Lynx 主线程上、带有 Element PAPI 全局对象执行的模块请求。

#### 备注

该请求由 Rspeedy 或 Rsbuild 解析。当它指向一个已存在的本地文件时，会按照约定发现可选的同级 `background.ts` 和 `style.css` 文件。
