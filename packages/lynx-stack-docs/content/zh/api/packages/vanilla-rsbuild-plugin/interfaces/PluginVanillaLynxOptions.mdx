# 接口: PluginVanillaLynxOptions

[pluginVanillaLynx](../functions/pluginVanillaLynx.mdx) 的选项。

## 属性

### bundleFilename?

```ts
optional bundleFilename?: VanillaBundleFilename;
```

覆盖最终的 `.bundle` 文件名。

#### 备注

省略时，使用 `pluginLynx` 的 `output.filename.bundle`（默认为
`'[name].[platform].bundle'`）。

***

### engineVersion?

```ts
optional engineVersion?: string;
```

生成的 bundle 所需的最低 Lynx Engine 版本。

#### 默认值

`'3.5'`

***

### entries?

```ts
optional entries?: Record<string, VanillaLynxEntry>;
```

显式的双线程入口。

#### 备注

省略时，每个 Rsbuild `source.entry` 都会被当作主线程
入口，并按照约定发现可选的同级 `background.ts` 和 `style.css`
文件。

***

### ~~targetSdkVersion?~~

```ts
optional targetSdkVersion?: string;
```

[PluginVanillaLynxOptions.engineVersion](#engineversion) 的别名。

#### 已被弃用

请改用 `engineVersion`。
