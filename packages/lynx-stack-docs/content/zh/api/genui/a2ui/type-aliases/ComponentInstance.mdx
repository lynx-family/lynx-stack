# 类型别名: ComponentInstance

```ts
type ComponentInstance = v0_9.AnyComponent & object;
```

## 类型声明

### \_\_template?

```ts
optional __template?: object;
```

模板化容器的内部元数据，用于在数据模型更新时重新展开。

#### \_\_template.componentId

```ts
componentId: v0_9.ComponentId;
```

#### \_\_template.path

```ts
path: string;
```

### dataContextPath?

```ts
optional dataContextPath?: string;
```

通过模板创建该组件时的绝对数据上下文路径，用于解析组件树内部的相对绑定。
