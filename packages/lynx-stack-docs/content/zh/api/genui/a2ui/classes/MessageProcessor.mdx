# 类: MessageProcessor

有状态的 A2UI 协议处理器，将原始 v0.9 消息转换为可渲染的 surface、resource、数据模型 signal 以及用户操作事件。

## 构造函数

### 构造函数

```ts
new MessageProcessor(): MessageProcessor;
```

#### 返回

`MessageProcessor`

### resolvePath()

```ts

```

结合当前数据上下文解析 JSON Pointer。

- 绝对路径（以 '/' 开头）原样返回。
- 相对路径基于传入的 dataContextPath 解析。

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `path` | `string` |
| `dataContextPath?` | `string` |
