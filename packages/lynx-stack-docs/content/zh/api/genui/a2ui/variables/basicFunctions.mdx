# 变量: basicFunctions

```ts
const basicFunctions: readonly CatalogFunctionEntry[];
```

打包为 `CatalogFunctionEntry` 的 A2UI 0.9 basic catalog 函数实现，可直接展开到 `<A2UI catalogs={[...]}>` 中。这些实现本身来自 `@a2ui/web_core`，因此无需额外工作即可与上游规范保持一致。

## 示例

```ts
<A2UI catalogs={[Text, Button, ...basicFunctions]} ... />
```
