# 函数: useChecks()

```ts
function useChecks(options: object): CheckOutcome & object;
```

以响应式方式对某个输入组件的 `checks` 数组求值。返回当前结果
以及第一条失败信息（便于内联渲染错误）。当外部存在
`<FormContext.Provider>` 时，该输入也会向其注册，以便同一表单中的
Button 能够响应 `isValid`。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `options` | \{ `checks`: [`CheckLike`](../interfaces/CheckLike.mdx)[] \| `undefined`; `componentId`: `string`; `dataContextPath?`: `string`; `surface`: [`Surface`](../interfaces/Surface.mdx) \| `undefined`; \} |
| `options.checks` | [`CheckLike`](../interfaces/CheckLike.mdx)[] \| `undefined` |
| `options.componentId` | `string` |
| `options.dataContextPath?` | `string` |
| `options.surface` | [`Surface`](../interfaces/Surface.mdx) \| `undefined` |

## 返回

`CheckOutcome` & `object`
