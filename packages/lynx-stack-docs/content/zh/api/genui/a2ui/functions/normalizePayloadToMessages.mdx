# 函数: normalizePayloadToMessages()

```ts
function normalizePayloadToMessages(payload: unknown): ServerToClientMessage[];
```

将任意数据（字符串、数组、对象）规范化为扁平的 `ServerToClientMessage` 记录列表。已结构化的消息会直接透传；纯文本则回退为包裹在 Text/Card surface 中。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `payload` | `unknown` |

## 返回

[`ServerToClientMessage`](../type-aliases/ServerToClientMessage.mdx)[]
