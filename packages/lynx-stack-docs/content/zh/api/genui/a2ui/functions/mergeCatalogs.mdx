# 函数: mergeCatalogs()

```ts
function mergeCatalogs(...catalogs: Catalog[]): Catalog;
```

合并多个 catalog。名称重复时后写入的覆盖先写入的，适合页面级 catalog 覆盖品牌级 catalog、品牌级再覆盖内置 catalog 的场景。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| ...`catalogs` | [`Catalog`](../interfaces/Catalog.mdx)[] |

## 返回

[`Catalog`](../interfaces/Catalog.mdx)
