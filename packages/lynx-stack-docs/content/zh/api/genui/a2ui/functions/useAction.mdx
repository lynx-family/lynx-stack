# 函数: useAction()

```ts
function useAction(props: ActionProps): object;
```

创建一个 `sendAction` 回调，它会解析动态的 action 数据值，并通过当前处理器分发用户事件或函数调用。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `props` | [`ActionProps`](../interfaces/ActionProps.mdx) |

## 返回

`object`
