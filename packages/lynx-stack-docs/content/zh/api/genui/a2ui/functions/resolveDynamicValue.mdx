# 函数: resolveDynamicValue()

```ts
function resolveDynamicValue(
   processor: MessageProcessor, 
   value: unknown, 
   surfaceId: string, 
   dataContextPath?: string, 
   options?: ResolveDynamicValueOptions
): unknown;
```

将字面量、数据绑定和函数调用解析为具体的运行时值，用于组件 props 或 action 数据。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `processor` | [`MessageProcessor`](../classes/MessageProcessor.mdx) |
| `value` | `unknown` |
| `surfaceId` | `string` |
| `dataContextPath?` | `string` |
| `options?` | `ResolveDynamicValueOptions` |

## 返回

`unknown`
