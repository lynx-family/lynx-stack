# 函数: useResolvedProps()

```ts
function useResolvedProps(
   properties: Record<string, unknown>, 
   surface: Surface | undefined, 
   dataContextPath?: string, 
   processor?: MessageProcessor, 
   functions?: readonly CatalogFunctionEntry[]
): readonly [Record<string, unknown>, (key: string, value: unknown) => void];
```

解析组件的动态 props，并在基于 signal 的数据模型变化时保持结果同步。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `properties` | `Record`\<`string`, `unknown`\> |
| `surface` | [`Surface`](../interfaces/Surface.mdx) \| `undefined` |
| `dataContextPath?` | `string` |
| `processor?` | [`MessageProcessor`](../classes/MessageProcessor.mdx) |
| `functions?` | readonly [`CatalogFunctionEntry`](../interfaces/CatalogFunctionEntry.mdx)[] |

## 返回

readonly \[`Record`\<`string`, `unknown`\>, (`key`: `string`, `value`: `unknown`) => `void`\]
