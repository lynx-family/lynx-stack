# 函数: useDataBinding()

```ts
function useDataBinding<T = unknown>(
   dynamicValue: unknown, 
   surface: Surface | undefined, 
   dataContextPath?: string, 
   fallbackValue?: T
): [T | undefined, (newValue: T) => void, string | undefined];
```

订阅数据模型绑定，并返回该路径上的当前值。

## 类型参数

| 类型参数 | 默认类型 |
| ------ | ------ |
| `T` | `unknown` |

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `dynamicValue` | `unknown` |
| `surface` | [`Surface`](../interfaces/Surface.mdx) \| `undefined` |
| `dataContextPath?` | `string` |
| `fallbackValue?` | `T` |

## 返回

\[`T` \| `undefined`, (`newValue`: `T`) => `void`, `string` \| `undefined`\]
