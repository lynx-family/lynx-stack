# 函数: prepareMessagesForProcessing()

```ts
function prepareMessagesForProcessing(
   rawMessages: ServerToClientMessage[], 
   messageId: string, 
   activeSurfaceIds: Set<string>
): object;
```

为消息打上给定的 messageId 标记，并报告其中是否有消息携带了
非空的 `updateComponents`。同时会根据当前活跃的 surface 集合对 `createSurface`
消息去重。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `rawMessages` | [`ServerToClientMessage`](../type-aliases/ServerToClientMessage.mdx)[] |
| `messageId` | `string` |
| `activeSurfaceIds` | `Set`\<`string`\> |

## 返回

`object`

### hasComponentUpdate

```ts
hasComponentUpdate: boolean;
```

### messages

```ts
messages: ServerToClientMessage[];
```
