# 函数: executeFunctionCall()

```ts
function executeFunctionCall(
   processor: MessageProcessor, 
   fn: object, 
   surfaceId: string, 
   dataContextPath?: string, 
   options?: ResolveFunctionOptions
): unknown;
```

解析参数，在注册表中查找对应的函数并调用它。
当没有注册实现时，只记录一次日志并返回 `undefined`，以便调用方
（检查、动态属性绑定）可以优雅降级。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `processor` | [`MessageProcessor`](../classes/MessageProcessor.mdx) |
| `fn` | \{ `args`: `Record`\<`string`, `any`\>; `call`: `string`; `returnType`: `"string"` \| `"number"` \| `"boolean"` \| `"object"` \| `"array"` \| `"void"` \| `"any"`; \} |
| `fn.args` | `Record`\<`string`, `any`\> |
| `fn.call` | `string` |
| `fn.returnType?` | `"string"` \| `"number"` \| `"boolean"` \| `"object"` \| `"array"` \| `"void"` \| `"any"` |
| `surfaceId?` | `string` |
| `dataContextPath?` | `string` |
| `options?` | [`ResolveFunctionOptions`](../interfaces/ResolveFunctionOptions.mdx) |

## 返回

`unknown`
