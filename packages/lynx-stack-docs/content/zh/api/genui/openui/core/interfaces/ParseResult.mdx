# 接口: ParseResult

单次调用 `parser.parse(text)` 的输出。

流式传输过程中，每个分块都会在重新解析累积文本后产生新的 ParseResult。`root` 会逐步从 null 变为部分树，再变为完整的树。

## 属性

### meta

```ts
meta: object;
```

#### errors

```ts
errors: ValidationError[];
```

属性校验错误。缺少必填属性的组件会被移除（替换为 null），并列在这里。

#### incomplete

```ts
incomplete: boolean;
```

解析器检测到输入被截断或不完整时为 true。

#### orphaned

```ts
orphaned: string[];
```

#### statementCount

```ts
statementCount: number;
```

#### unresolved

```ts
unresolved: string[];
```

***

### mutationStatements

```ts
mutationStatements: MutationStatementInfo[];
```

提取出的 Mutation() 调用，其位置参数为 AST 节点。

***

### queryStatements

```ts
queryStatements: QueryStatementInfo[];
```

提取出的 Query() 调用，其位置参数为 AST 节点。

***

### root

```ts
root: ElementNode | null;
```

根 ElementNode（通常是 Root 组件）；解析还没有产出时为 null。

***

### stateDeclarations

```ts
stateDeclarations: Record<string, unknown>;
```

$variable 声明，把 "$varName" 映射到它实际生成的默认值。
