# 函数: validate()

```ts
function validate(
   value: unknown, 
   rules: ParsedRule[], 
   customValidators?: Record<string, ValidatorFn>
): string | undefined;
```

对一个值运行所有规则，遇到第一个错误即停止。先检查自定义校验器，再检查内置校验器。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `value` | `unknown` |
| `rules` | [`ParsedRule`](../interfaces/ParsedRule.mdx)[] |
| `customValidators?` | `Record`\<`string`, [`ValidatorFn`](../type-aliases/ValidatorFn.mdx)\> |

## 返回

`string` \| `undefined`
