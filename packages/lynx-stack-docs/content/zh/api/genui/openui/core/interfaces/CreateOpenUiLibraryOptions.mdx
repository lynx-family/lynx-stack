# 接口: CreateOpenUiLibraryOptions

创建 ReactLynx OpenUI 组件库的选项。

## 属性

### componentGroups?

```ts
optional componentGroups?: ComponentGroup[];
```

额外的组件分组；禁用默认组件时则为完整的分组集合。

***

### components?

```ts
optional components?: DefinedComponent<any>[];
```

额外的组件；禁用默认组件时则为完整的组件集合。

***

### includeDefaultComponents?

```ts
optional includeDefaultComponents?: boolean;
```

是否包含内置组件和组件分组。默认为 `true`。

***

### root?

```ts
optional root?: string;
```

覆盖根组件名称。默认为 `'Stack'`。
