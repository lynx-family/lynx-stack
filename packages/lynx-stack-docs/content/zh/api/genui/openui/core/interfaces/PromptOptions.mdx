# 接口: PromptOptions

## 属性

### additionalRules?

```ts
optional additionalRules?: string[];
```

***

### bindings?

```ts
optional bindings?: boolean;
```

启用 $variables、@Set、@Reset 和交互式筛选。默认：启用 toolCalls 时为 true。

***

### editMode?

```ts
optional editMode?: boolean;
```

在提示词中加入编辑模式的说明。

***

### examples?

```ts
optional examples?: string[];
```

没有工具时展示的示例（静态 / 布局类模式）。

***

### inlineMode?

```ts
optional inlineMode?: boolean;
```

启用内联模式：LLM 可以用文本作答，并可附带 openui-lang 代码块。

***

### preamble?

```ts
optional preamble?: string;
```

***

### toolCalls?

```ts
optional toolCalls?: boolean;
```

启用 Query()、Mutation()、@Run 和工具工作流。默认：提供了工具时为 true。

***

### toolExamples?

```ts
optional toolExamples?: string[];
```

有工具时展示的示例（Query/Mutation 模式），优先于 `examples`。

***

### tools?

```ts
optional tools?: ToolDescriptor[];
```

Query() 可用的工具，可以是字符串名称或丰富的 ToolSpec 描述，会注入到提示词中。
