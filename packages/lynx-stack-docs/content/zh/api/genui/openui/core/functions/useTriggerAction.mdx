# 函数: useTriggerAction()

```ts
function useTriggerAction(): (userMessage: string, formName?: string, action?: 
  | ActionPlan
  | {
  context?: string;
  params?: Record<string, any>;
  type?: string;
  url?: string;
}) => void | Promise<void>;
```

获取用于触发结构化 action 事件的 triggerAction 函数。

## 返回

(`userMessage`: `string`, `formName?`: `string`, `action?`: 
  \| [`ActionPlan`](../interfaces/ActionPlan.mdx)
  \| \{
  `context?`: `string`;
  `params?`: `Record`\<`string`, `any`\>;
  `type?`: `string`;
  `url?`: `string`;
\}) => `void` \| `Promise`\<`void`\>

## 示例

```tsx
const triggerAction = useTriggerAction();
<button onClick={() => triggerAction("Submit", "myForm")}>
```
