# 函数: parseStructuredRules()

```ts
function parseStructuredRules(rules: unknown): ParsedRule[];
```

将一个结构化的 rules 对象解析为 ParsedRule[]。
支持：\{ required: true, minLength: 5, email: true, max: 100 \}
会跳过值为 false/undefined 的键。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `rules` | `unknown` |

## 返回

[`ParsedRule`](../interfaces/ParsedRule.mdx)[]
