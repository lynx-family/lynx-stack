# 函数: createStreamingParser()

```ts
function createStreamingParser(schema: LibraryJSONSchema, rootName?: string): StreamParser;
```

根据组件库的 JSON Schema 文档创建流式解析器。传入 `library.toJSONSchema()` 获取 schema。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `schema` | [`LibraryJSONSchema`](../interfaces/LibraryJSONSchema.mdx) |
| `rootName?` | `string` |

## 返回

[`StreamParser`](../interfaces/StreamParser.mdx)
