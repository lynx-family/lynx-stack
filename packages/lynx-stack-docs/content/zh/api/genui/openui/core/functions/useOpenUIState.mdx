# 函数: useOpenUIState()

```ts
function useOpenUIState(__namedParameters: UseOpenUIStateOptions, renderDeep: (value: unknown) => ReactNode): OpenUIState;
```

核心状态 hook——将所有表单状态、action 处理、解析器管理和上下文组装从 Renderer 组件中抽离出来。

Store 保存所有内容：$bindings 作为顶层键，表单字段则以普通值的形式嵌套在 formName 下。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `__namedParameters` | [`UseOpenUIStateOptions`](../interfaces/UseOpenUIStateOptions.mdx) |
| `renderDeep` | (`value`: `unknown`) => `ReactNode` |

## 返回

[`OpenUIState`](../interfaces/OpenUIState.mdx)
