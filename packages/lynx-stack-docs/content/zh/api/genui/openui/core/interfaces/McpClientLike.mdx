# 接口: McpClientLike

MCP Client 的最小结构，与 @modelcontextprotocol/sdk 的 Client 一致，但不需要强制引入它。任何实现了这些方法的对象都可以传入。

## 方法

### callTool()

```ts
callTool(params: object, options?: unknown): Promise<{
  content: object[];
  isError?: boolean;
  structuredContent?: unknown;
}>;
```

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `params` | \{ `arguments?`: `Record`\<`string`, `unknown`\>; `name`: `string`; \} |
| `params.arguments?` | `Record`\<`string`, `unknown`\> |
| `params.name?` | `string` |
| `options?` | `unknown` |

#### 返回

`Promise`\<\{
  `content`: `object`[];
  `isError?`: `boolean`;
  `structuredContent?`: `unknown`;
\}\>

***
