# 函数: mergeStatements()

```ts
function mergeStatements(
   existing: string, 
   patch: string, 
   rootId?: string
): string;
```

把已有程序与补丁合并（部分更新）。补丁中的语句按名称覆盖已有语句，不再可达的语句会被自动回收。以字符串形式返回合并后的程序。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `existing` | `string` |
| `patch` | `string` |
| `rootId?` | `string` |

## 返回

`string`
