# 接口: UseOpenUIStateOptions

用于解析 OpenUI 文本并构建渲染器状态的输入。

## 属性

### initialQueryResults?

```ts
optional initialQueryResults?: Readonly<Record<string, unknown>>;
```

预取的 Query 结果，以 Query 赋值名称（statement ID）为键。它们在首次渲染时即可使用，并在可选的 tool provider 于 commit 后重新校验期间作为兜底值。
