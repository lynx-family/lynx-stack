# 接口: OpenUIState

由 `useOpenUIState` 返回的派生 OpenUI 渲染器状态。

## 属性

### contextValue

```ts
contextValue: OpenUIContextValue;
```

***

### isQueryLoading

```ts
isQueryLoading: boolean;
```

是否有 Query 正在获取数据。

***

### parseResult

```ts
parseResult: ParseResult | null;
```

原始解析结果（props 中为 AST 节点）。供 onParseResult 回调使用。

***

### result

```ts
result: ParseResult | null;
```

求值后的结果（props 已解析为具体值）。供 Renderer 使用。
