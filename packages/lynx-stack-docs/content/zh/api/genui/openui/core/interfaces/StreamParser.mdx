# 接口: StreamParser

## 方法

### getResult()

```ts
getResult(): ParseResult;
```

获取最新的 ParseResult，不消费新数据。

#### 返回

[`ParseResult`](ParseResult.mdx)

***

### push()

```ts
push(chunk: string): ParseResult;
```

传入下一个 SSE/流分片，并获取最新的 ParseResult。

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `chunk` | `string` |

#### 返回

[`ParseResult`](ParseResult.mdx)

***

### set()

```ts
set(fullText: string): ParseResult;
```

设置完整文本：与内部缓冲区做 diff，只推送增量。如果文本被替换（而不是追加），会自动重置。

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `fullText` | `string` |

#### 返回

[`ParseResult`](ParseResult.mdx)
