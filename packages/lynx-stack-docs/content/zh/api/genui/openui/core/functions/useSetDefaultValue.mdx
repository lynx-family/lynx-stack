# 函数: useSetDefaultValue()

```ts
function useSetDefaultValue(shouldTriggerSaveCallback: object): void;
```

在流式输出结束后，将组件的默认值/初始值写入表单状态——但仅当用户尚未设置值时才会写入。

在任何带有 `defaultValue` 或 `defaultChecked` prop 的表单组件中调用它。它在流式输出期间不执行任何操作，以免 LLM 对 prop 的修改与不完整的状态相互冲突。

## 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `shouldTriggerSaveCallback` | \{ `componentType?`: `string`; `defaultValue`: `unknown`; `existingValue`: `unknown`; `formName?`: `string`; `name`: `string`; `shouldTriggerSaveCallback?`: `boolean`; \} | 默认为 `false`（仅更新本地状态，不持久化消息）。 |
| `shouldTriggerSaveCallback.componentType?` | `string` | - |
| `shouldTriggerSaveCallback.defaultValue` | `unknown` | - |
| `shouldTriggerSaveCallback.existingValue` | `unknown` | - |
| `shouldTriggerSaveCallback.formName?` | `string` | - |
| `shouldTriggerSaveCallback.name` | `string` | - |
| `shouldTriggerSaveCallback.shouldTriggerSaveCallback?` | `boolean` | - |

## 返回

`void`
