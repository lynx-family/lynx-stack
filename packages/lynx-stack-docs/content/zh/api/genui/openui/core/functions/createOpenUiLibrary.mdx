# 函数: createOpenUiLibrary()

```ts
function createOpenUiLibrary(options?: CreateOpenUiLibraryOptions): Library;
```

创建 ReactLynx OpenUI 组件库，包含调用方提供的组件，以及（除非禁用）内置组件。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `options?` | [`CreateOpenUiLibraryOptions`](../interfaces/CreateOpenUiLibraryOptions.mdx) |

## 返回

[`Library`](../type-aliases/Library.mdx)
