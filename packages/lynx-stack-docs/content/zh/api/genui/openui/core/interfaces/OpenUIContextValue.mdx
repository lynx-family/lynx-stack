# 接口: OpenUIContextValue

由 OpenUI 渲染器、hooks、action 和表单字段共享的运行时上下文。

## 属性

### evaluationContext

```ts
evaluationContext: EvaluationContext;
```

运行时表达式求值所使用的 AST 求值上下文。

***

### getFieldValue

```ts
getFieldValue: (formName: string | undefined, name: string) => any;
```

获取字段值。$bindings 位于顶层，表单字段则嵌套在 formName 下。

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `formName` | `string` \| `undefined` |
| `name` | `string` |

#### 返回

`any`

***

### setFieldValue

```ts
setFieldValue: (formName: string | undefined, componentType: string | undefined, name: string, value: unknown, shouldTriggerSaveCallback?: boolean) => void;
```

设置表单字段值。

#### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `formName` | `string` \| `undefined` | 表单的 name 属性。 |
| `componentType` | `string` \| `undefined` | 组件类型（例如 "Input"、"Select"）。 |
| `name` | `string` | 字段的 name 属性。 |
| `value` | `unknown` | 新的值。 |
| `shouldTriggerSaveCallback?` | `boolean` | 为 true 时，通过 onStateUpdate 持久化状态。文本输入应在 change 时传 `false`、在 blur 时传 `true`；离散输入（Select、RadioGroup 等）应始终传 `true`。 |

#### 返回

`void`

### triggerAction

```ts
triggerAction: (userMessage: string, formName?: string, action?: 
  | ActionPlan
  | {
  context?: string;
  params?: Record<string, any>;
  type?: string;
  url?: string;
}) => void | Promise<void>;
```

触发一个 action。可接受以下几种：
- ActionPlan（v0.5）：按顺序执行各个步骤（Run、Set、ToAssistant、OpenUrl）
- 旧版 action 配置（v0.1）：带有可选 type 和 params 的对象。
- 不传：触发带有该 label 的 ContinueConversation

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `userMessage` | `string` |
| `formName?` | `string` |
| `action?` | \| [`ActionPlan`](ActionPlan.mdx) \| \{ `context?`: `string`; `params?`: `Record`\<`string`, `any`\>; `type?`: `string`; `url?`: `string`; \} |

#### 返回

`void` \| `Promise`\<`void`\>
