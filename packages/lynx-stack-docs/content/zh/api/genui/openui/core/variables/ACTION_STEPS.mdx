# 变量: ACTION\_STEPS

```ts
const ACTION_STEPS: object;
```

把解析器层面的 action 步骤名映射为运行时的步骤类型值，是唯一的数据源。

## 类型声明

### OpenUrl

```ts
readonly OpenUrl: "open_url";
```

### Reset

```ts
readonly Reset: "reset";
```

### Run

```ts
readonly Run: "run";
```

### Set

```ts
readonly Set: "set";
```

### ToAssistant

```ts
readonly ToAssistant: "continue_conversation";
```
