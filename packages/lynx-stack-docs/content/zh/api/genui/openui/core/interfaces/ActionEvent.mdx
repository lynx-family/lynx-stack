# 接口: ActionEvent

交互组件触发的结构化 action 事件。

## 属性

### formName?

```ts
optional formName?: string;
```

触发这个 action 的表单名称（如果有）。

***

### formState?

```ts
optional formState?: Record<string, unknown>;
```

action 发生时的原始表单状态，即所有字段的值。

***

### humanFriendlyMessage

```ts
humanFriendlyMessage: string;
```

这个 action 的可读标签（在对话中显示为用户消息）。

***

### params

```ts
params: Record<string, unknown>;
```

特定于 action 的参数（例如 OpenUrl 对应 \{ url \}，Custom 对应自定义参数）。

***

### type

```ts
type: 
  | BuiltinActionType
  | string & object;
```

action 类型。内置类型见 `BuiltinActionType`。
