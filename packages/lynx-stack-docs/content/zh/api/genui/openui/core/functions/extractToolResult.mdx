# 函数: extractToolResult()

```ts
function extractToolResult(result: object): unknown;
```

从 MCP callTool 的结果中提取实际数据。优先使用 structuredContent（机器可读的 JSON），否则回退为解析文本内容。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `result` | \{ `content`: `object`[]; `isError?`: `boolean`; `structuredContent?`: `unknown`; \} |
| `result.content` | `object`[] |
| `result.isError?` | `boolean` |
| `result.structuredContent?` | `unknown` |

## 返回

`unknown`
