# 接口: BuildOpenUiSystemPromptOptions

用于自定义生成的 OpenUI 系统提示词的选项。

## 继承

- [`CreateOpenUiPromptLibraryOptions`](CreateOpenUiPromptLibraryOptions.mdx)

## 属性

### appendix?

```ts
optional appendix?: string;
```

***

### componentGroups?

```ts
optional componentGroups?: ComponentGroup[];
```

替换或扩展内置的组件分组。

#### 继承自

[`CreateOpenUiPromptLibraryOptions`](CreateOpenUiPromptLibraryOptions.mdx).[`componentGroups`](CreateOpenUiPromptLibraryOptions.mdx#componentgroups)

### componentNames?

```ts

```

将内置项限制为这些名称。自定义的 `components` 仍会被追加。

#### 继承自

[`CreateOpenUiPromptLibraryOptions`](CreateOpenUiPromptLibraryOptions.mdx).[`componentNames`](CreateOpenUiPromptLibraryOptions.mdx#componentnames)

***

#### 继承自

[`CreateOpenUiPromptLibraryOptions`](CreateOpenUiPromptLibraryOptions.mdx).[`components`](CreateOpenUiPromptLibraryOptions.mdx#components)
