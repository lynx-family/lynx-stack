# 函数: createOpenUiPromptLibrary()

```ts
function createOpenUiPromptLibrary(options?: CreateOpenUiPromptLibraryOptions): OpenUiPromptLibrary;
```

使用内置组件 schema 创建 headless OpenUI 库。

它与 ReactLynx 组件库保持一致以用于生成 prompt，同时不会在运行时依赖 ReactLynx 或 Lynx UI 组件。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `options` | [`CreateOpenUiPromptLibraryOptions`](../interfaces/CreateOpenUiPromptLibraryOptions.mdx) |

## 返回

[`OpenUiPromptLibrary`](../type-aliases/OpenUiPromptLibrary.mdx)
