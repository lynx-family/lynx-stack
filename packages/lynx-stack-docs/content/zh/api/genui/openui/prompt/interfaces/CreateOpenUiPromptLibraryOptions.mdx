# 接口: CreateOpenUiPromptLibraryOptions

创建 headless OpenUI prompt 库的选项。

## 继承于

- [`BuildOpenUiSystemPromptOptions`](BuildOpenUiSystemPromptOptions.mdx)

## 属性

### componentGroups?

```ts
optional componentGroups?: ComponentGroup[];
```

替换或扩展内置的组件分组。

***

### componentNames?

```ts
optional componentNames?: readonly string[];
```

将内置项限制为这些名称。自定义的 `components` 仍会被追加。

***

### components?

```ts
optional components?: OpenUiPromptComponent[];
```

替换或扩展内置的组件集合。

***

### root?

```ts
optional root?: string;
```

覆盖根组件名称。默认为 `'Stack'`。
