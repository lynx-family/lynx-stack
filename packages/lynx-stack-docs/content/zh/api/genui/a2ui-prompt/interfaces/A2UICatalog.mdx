# 接口: A2UICatalog

可直接用于 prompt 的 A2UI catalog，包含组件、规则、示例以及可选的客户端函数。

## 属性

### components

```ts
components: A2UIComponentSpec[];
```

***

### examples?

```ts
optional examples?: A2UIExample[];
```

***

### extraRules?

```ts
optional extraRules?: string[];
```

***

### functions?

```ts
optional functions?: A2UIFunctionSpec[];
```

***

### id

```ts
id: string;
```

***

### label

```ts
label: string;
```

***

### version?

```ts
optional version?: string;
```
