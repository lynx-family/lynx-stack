# 函数: createA2UICatalogFromManifests()

```ts
function createA2UICatalogFromManifests(options: object): A2UICatalog;
```

| `options.catalogId` | `string` |
| `options.componentManifests` | `Record`\<`string`, [`JsonSchema`](../interfaces/JsonSchema.mdx)\>[] |
| `options.examples?` | [`A2UIExample`](../interfaces/A2UIExample.mdx)[] |
| `options.extraRules?` | `string`[] |
| `options.functions?` | [`A2UIFunctionSpec`](../interfaces/A2UIFunctionSpec.mdx)[] |
| `options.label?` | `string` |
| `options.version?` | `string` |

## 返回

[`A2UICatalog`](../interfaces/A2UICatalog.mdx)
