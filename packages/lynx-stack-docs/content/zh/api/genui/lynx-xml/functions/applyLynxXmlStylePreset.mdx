# 函数: applyLynxXmlStylePreset()

```ts
function applyLynxXmlStylePreset(source: string, stylePreset?: "default"): string;
```

在不修改脚本的情况下，向直接使用 Element PAPI 的文档注入预设 CSS。

## 参数

| 参数 | 类型 | 默认值 |
| ------ | ------ | ------ |
| `source` | `string` | `undefined` |
| `stylePreset` | `"default"` | `'default'` |

## 返回

`string`
