# @lynx-js/react

[npm](https://www.npmjs.com/package/@lynx-js/react) · [Source](https://github.com/lynx-family/lynx-stack/tree/main/packages/react) · [Changelog](https://github.com/lynx-family/lynx-stack/blob/main/packages/react/CHANGELOG.md)

`@lynx-js/react` 是适用于 Lynx 的 React。它保留了 React 17 的 API 界面，
重新导出标准的 Hook 和 API，并添加了双线程
模型所需的内容：主线程函数、页面从 native 接收到的数据，
以及一些编译期指令和宏。

## 备注

下面这些 React API 的行为与 [React 官方参考文档](https://react.dev/reference/react)
一致，除非页面另有说明。它们与 React 17 和
[Preact](https://preactjs.com/guide/v10/switching-to-preact/) 兼容。

React 从 [React 18](https://react.dev/blog/2022/03/29/react-v18) 开始进入“并发”时代。
以 `useTransition`、`useDeferredValue` 为代表的并发特性，对宿主如何调度任务有严格要求
——它们依赖浏览器的 Web API，或者依赖 React Native 的新架构。Lynx 有自己的架构演进方向，
因此 ReactLynx 选择以 React 17 为基础，同时保留 React 的编程模型。
[React 19](https://react.dev/blog/2024/04/25/react-19) 和
[React Compiler](https://react.dev/learn/react-compiler) 中不依赖并发架构的部分，
我们仍会持续关注并尝试引入。

ReactLynx 的入门介绍参见 [ReactLynx 指南](https://lynxjs.org/react/)。
