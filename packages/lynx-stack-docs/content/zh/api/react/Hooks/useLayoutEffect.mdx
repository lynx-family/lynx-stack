# ~~函数: useLayoutEffect()~~

```ts
function useLayoutEffect(effect: EffectCallback, deps?: DependencyList): void;
```

`useLayoutEffect` 现在是 `useEffect` 的别名，请改用 `useEffect`。

接收一个包含命令式、可能带有副作用代码的函数。副作用会在主线程 DOM 更新后执行，且不会阻塞更新。

## 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `effect` | `EffectCallback` | 命令式函数，可以返回一个清理函数 |
| `deps?` | `DependencyList` | 如果提供，只有列表中的值发生变化（使用 === 比较）时 effect 才会执行。 |

## 返回

`void`

## 已被弃用

后台线程中的 `useLayoutEffect` 无法提供读取布局信息并同步重新渲染的精确时机，这一点与 React 不同。
