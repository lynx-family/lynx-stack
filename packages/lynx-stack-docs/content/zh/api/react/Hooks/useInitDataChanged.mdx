# 函数: useInitDataChanged()

```ts
function useInitDataChanged(callback: (data: InitData) => void): void;
```

用于在 `initData` 变化时获得通知的 React Hook。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `callback` | (`data`: [`InitData`](../Types/InitData.mdx)) => `void` |

## 返回

`void`

## 示例

```ts
function App() {
  useInitDataChanged((data) => {
    data.someProperty // can use it
  })
}
```
