# 函数: useMainThreadRef()

## 调用签名

```ts
function useMainThreadRef<T>(initValue: T): MainThreadRef<T>;
```

Create A `MainThreadRef`.

`MainThreadRef` 是一种只能在主线程访问的 ref，用于在主线程函数调用之间保存状态。保存在 `MainThreadRef` 的 `current` 属性中的数据，可以在多个主线程函数中读写。

它是一个 Hook，只应在组件的顶层调用。

### 类型参数

| 类型参数 |
| ------ |
| `T` |

### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `initValue` | `T` | `MainThreadRef` 的初始值。 |

### 返回

[`MainThreadRef`](../Types/MainThreadRef.mdx)\<`T`\>

### 示例

```ts
import { useMainThreadRef } from '@lynx-js/react'
import type { MainThread } from '@lynx-js/types'

export function App() {
  const ref = useMainThreadRef<MainThread.Element>(null)

  const handleTap = () => {
    'main thread'
    ref.current?.setStyleProperty('background-color', 'blue')
  }

  return (
    <view
      main-thread:ref={ref}
      main-thread:bindtap={handleTap}
      style={{ width: '300px', height: '300px' }}
    />
  )
}
```
