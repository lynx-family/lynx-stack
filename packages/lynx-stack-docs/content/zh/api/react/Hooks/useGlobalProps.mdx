# 函数: useGlobalProps()

```ts
function useGlobalProps(): GlobalProps;
```

用于获取 `lynx.__globalProps` 的 React Hook。在 `globalPropsMode: 'event'` 下，`lynx.__globalProps` 变化时组件会重新渲染；在默认的 `'reactive'` 模式下，更新通过整体重新渲染生效。

## 返回

[`GlobalProps`](../Types/GlobalProps.mdx)

## 示例

```ts
function App() {
  const globalProps = useGlobalProps();

  globalProps.someProperty // use it
}
```
