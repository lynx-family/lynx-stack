# 函数: useCallback()

```ts
function useCallback<T extends Function>(callback: T, deps: DependencyList): T;
```

`useCallback` 会返回该回调函数的一个 memoized 版本，只有当某个 `inputs`
发生变化时，该版本才会改变。

## 类型参数

| 类型参数 |
| ------ |
| `T` *extends* `Function` |

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `callback` | `T` |
| `deps` | `DependencyList` |

## 返回

`T`

## Version

16.8.0
