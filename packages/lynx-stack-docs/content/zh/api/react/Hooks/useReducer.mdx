# 函数: useReducer()

## 调用签名

```ts
function useReducer<S, A extends AnyActionArg>(reducer: (prevState: S, ...args: A) => S, initialState: S): [S, ActionDispatch<A>];
```

`useState` 的一种替代方案。

当你有涉及多个子值的复杂 state 逻辑时，通常
`useReducer` 比 `useState` 更合适。它还能让你为触发深层
更新的组件优化性能，因为你可以向下传递 `dispatch`，而不是传递回调函数。

### 类型参数

| 类型参数 |
| ------ |
| `S` |
| `A` *extends* `AnyActionArg` |

### 参数

| 参数 | 类型 |
| ------ | ------ |
| `reducer` | (`prevState`: `S`, ...`args`: `A`) => `S` |
| `initialState` | `S` |

### 返回

\[`S`, `ActionDispatch`\<`A`\>\]

### Version

16.8.0

### 参阅

[https://react.dev/reference/react/useReducer](https://react.dev/reference/react/useReducer)
