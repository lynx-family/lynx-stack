# 函数: useState()

## 调用签名

```ts
function useState<S>(initialState: S | (() => S)): [S, Dispatch<SetStateAction<S>>];
```

返回一个有状态的值，以及更新它的函数。

### 类型参数

| 类型参数 |
| ------ |
| `S` |

### 参数

| 参数 | 类型 |
| ------ | ------ |
| `initialState` | `S` \| (() => `S`) |

### 返回

\[`S`, `Dispatch`\<`SetStateAction`\<`S`\>\>\]

### Version

16.8.0

### 参阅

[https://react.dev/reference/react/useState](https://react.dev/reference/react/useState)
