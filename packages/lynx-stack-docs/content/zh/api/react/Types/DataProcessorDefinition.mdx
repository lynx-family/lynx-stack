# 接口: DataProcessorDefinition

DataProcessor 的定义

## 属性

### dataProcessors?

```ts
optional dataProcessors?: DataProcessors;
```

需与 `lynx.registerDataProcessors` 配合使用。更多示例参见 [Lynx.registerDataProcessors](Lynx.mdx#registerdataprocessors)。

***

### defaultDataProcessor?

```ts
optional defaultDataProcessor?: (rawInitData: InitDataRaw) => InitData;
```

可以通过扩展 [InitDataRaw](InitDataRaw.mdx) 和 [InitData](InitData.mdx) 来自定义 `defaultDataProcessor` 的输入和输出类型

需与 `lynx.registerDataProcessors` 配合使用。更多示例参见 [Lynx.registerDataProcessors](Lynx.mdx#registerdataprocessors)。

#### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `rawInitData` | [`InitDataRaw`](InitDataRaw.mdx) | 由原生代码传入的 initData |

#### 返回

[`InitData`](InitData.mdx)
