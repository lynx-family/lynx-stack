# 接口: Root

`@lynx-js/react` 默认导出的 root，用于渲染 JSX

## 属性

### ~~registerDataProcessors~~

```ts
registerDataProcessors: (dataProcessorDefinition: DataProcessorDefinition) => void;
```

注册 DataProcessor。必须在 `root.render()` 之前调用。

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `dataProcessorDefinition` | [`DataProcessorDefinition`](DataProcessorDefinition.mdx) |

#### 返回

`void`

#### 已被弃用

请改用 [lynx.registerDataProcessors](Lynx.mdx#registerdataprocessors)

***

### render

```ts
render: (jsx: ReactNode) => void;
```

使用此 API 传入要渲染的 JSX

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `jsx` | `ReactNode` |

#### 返回

`void`

#### 示例

```ts
import { root } from "@lynx-js/react"

function App() {
  // Your app
  return <view>...</view>
}

root.render(<App/>);
```

```tsx
import { root } from "@lynx-js/react"

function App() {
  // Your app
  return <view>...</view>
}

if (__MAIN_THREAD__) {
  root.render(
    <DataProvider data={DEFAULT_DATA}>
       <App/>
    </DataProvider>
  );
} else if (__BACKGROUND__) {
  fetchData().then((data) => {
    root.render(
      <DataProvider data={data}>
         <App/>
      </DataProvider>
    ); // You can render later after your data is ready
  })
}
```
