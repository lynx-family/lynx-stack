# 函数: forwardRef()

```ts
function forwardRef<T, P = {
}>(render: ForwardRefRenderFunction<T, PropsWithoutRef<P>>): ForwardRefExoticComponent<PropsWithoutRef<P> & RefAttributes<T>>;
```

让你的组件通过 ref 向父组件
暴露一个 DOM 节点。

## 类型参数

| 类型参数 | 默认类型 | 描述 |
| ------ | ------ | ------ |
| `T` | - | DOM 节点的类型。 |
| `P` | `object` | 组件接受的 props（如果有的话）。 |

## 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `render` | `ForwardRefRenderFunction`\<`T`, `PropsWithoutRef`\<`P`\>\> | 参见 [ForwardRefRenderFunction](https://react.dev/reference/react/forwardRef#render-function)。 |

## 返回

`ForwardRefExoticComponent`\<`PropsWithoutRef`\<`P`\> & `RefAttributes`\<`T`\>\>

## 参阅

 - [React Docs](https://react.dev/reference/react/forwardRef)
 - [React TypeScript Cheatsheet](https://react-typescript-cheatsheet.netlify.app/docs/basic/getting-started/forward_and_create_ref/)

## 示例

```tsx
interface Props {
  children?: ReactNode;
  type: "submit" | "button";
}

export const FancyButton = forwardRef<HTMLButtonElement, Props>((props, ref) => (
  <button ref={ref} className="MyClassName" type={props.type}>
    {props.children}
  </button>
));
```
