# 函数: memo()

## 调用签名

```ts
function memo<P extends object>(Component: FunctionComponent<P>, propsAreEqual?: (prevProps: Readonly<P>, nextProps: Readonly<P>) => boolean): NamedExoticComponent<P>;
```

让你在组件的 props 未变化时跳过重新渲染。

### 类型参数

| 类型参数 |
| ------ |
| `P` *extends* `object` |

### 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `Component` | `FunctionComponent`\<`P`\> | 要进行 memoize 的组件。 |
| `propsAreEqual?` | (`prevProps`: `Readonly`\<`P`\>, `nextProps`: `Readonly`\<`P`\>) => `boolean` | 用于判断 props 是否发生变化的函数。 |

### 返回

`NamedExoticComponent`\<`P`\>

### 参阅

[React Docs](https://react.dev/reference/react/memo)

### 示例

```tsx
import { memo } from 'react';

const SomeComponent = memo(function SomeComponent(props: { foo: string }) {
  // ...
});
```

| ------ |

### 参数

| ------ | ------ | ------ |
| `Component` | `T` | 要进行 memoize 的组件。 |
| `propsAreEqual?` | (`prevProps`: `Readonly`\<`ComponentProps`\<`T`\>\>, `nextProps`: `Readonly`\<`ComponentProps`\<`T`\>\>) => `boolean` | 用于判断 props 是否发生变化的函数。 |

### 返回

`MemoExoticComponent`\<`T`\>

### 参阅

[React Docs](https://react.dev/reference/react/memo)
