# 函数: createContext()

```ts
function createContext<T>(defaultValue: T): Context<T>;
```

让你创建一个组件可以提供或读取的 [Context](https://react.dev/reference/react/createContext#context-provider)。

## 类型参数

| 类型参数 |
| ------ |
| `T` |

## 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `defaultValue` | `T` | 当读取 context 的组件在其上层树中找不到匹配的 [Provider](https://react.dev/reference/react/createContext#provider) 时，你希望 context 具有的值。它作为“最后兜底”使用。 |

## 返回

`Context`\<`T`\>

## 参阅

 - [React Docs](https://react.dev/reference/react/createContext#reference)
 - [React TypeScript Cheatsheet](https://react-typescript-cheatsheet.netlify.app/docs/basic/getting-started/context/)

## 示例

```tsx
import { createContext } from 'react';

const ThemeContext = createContext('light');
function App() {
  return (
    <ThemeContext value="dark">
      <Toolbar />
    </ThemeContext>
  );
}
```
