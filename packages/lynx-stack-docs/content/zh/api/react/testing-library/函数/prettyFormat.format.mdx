# 函数: format()

```ts
function format(val: unknown, options?: PrettyFormatOptions): string;
```

返回 `val` 对象的展示字符串

## 参数

| 参数 | 类型 | 描述 |
| ------ | ------ | ------ |
| `val` | `unknown` | 任意 JavaScript 对象 |
| `options?` | [`PrettyFormatOptions`](../接口/prettyFormat.PrettyFormatOptions.mdx) | 自定义配置 |

## 返回

`string`
