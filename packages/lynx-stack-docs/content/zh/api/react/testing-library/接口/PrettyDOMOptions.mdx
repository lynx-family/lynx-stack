### filterNode?

```ts
optional filterNode?: (node: Node) => boolean;
```

传入一个 `Node`，返回 `false` 表示在输出中忽略该节点。
默认忽略 `<style />`、`<script />` 和注释节点。

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `node` | `Node` |

#### 返回

`boolean`
