# 接口: RenderHookOptions\<Props\>

[renderHook](../函数/renderHook.mdx) 的选项

## 类型参数

| 类型参数 |
| ------ |
| `Props` |

## 属性

### initialProps?

```ts
optional initialProps?: Props;
```

传给 renderHook 回调的参数。如果打算用 rerender 工具改变传给 hook 的值，会很有用。

***

### wrapper?

```ts
optional wrapper?: any;
```

把 React 组件作为 wrapper 选项传入，它会被渲染在内部元素外层。这在为常用的数据 Provider 创建可复用的自定义 render 函数时最有用，示例见 setup。

#### 示例

```ts
import { renderHook } from '@lynx-js/react/testing-library'
import { ThemeProvider } from 'my-ui-lib'
import { TranslationProvider } from 'my-i18n-lib'
import defaultStrings from 'i18n/en-x-default'

const AllTheProviders = ({children}) => {
  return (
    <ThemeProvider theme="light">
      <TranslationProvider messages={defaultStrings}>
        {children}
      </TranslationProvider>
    </ThemeProvider>
  )
}

const customRenderHook = (ui, options) =>
  renderHook(ui, { wrapper: AllTheProviders, ...options })

// re-export everything
export * from '@lynx-js/react/testing-library'

// override renderHook method
export { customRenderHook as renderHook }
```
