## 属性

### rerender

```ts
rerender: (props?: Props) => void;
```

触发一次重新渲染。props 会被传递给你的 renderHook 回调。

#### 参数

| 参数 | 类型 |
| ------ | ------ |
| `props?` | `Props` |

#### 返回

`void`

***

### result

```ts
result: object;
```

#### current

```ts
current: Result;
```

### unmount

```ts
unmount: () => void;
```

`void`
