# 类型别名: Query

```ts
type Query = (container: HTMLElement, ...args: any[]) => 
  | Error
  | HTMLElement
  | HTMLElement[]

  | null;
```

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `container` | `HTMLElement` |
| ...`args` | `any`[] |

  \| `Error`
