# 函数: GlobalPropsConsumer()

```ts
function GlobalPropsConsumer(props: ConsumerProps): ReactNode;
```

提供 `lynx.__globalProps` 的 [Consumer](https://react.dev/reference/react/createContext#consumer) 组件。
只有在 `globalPropsMode: 'event'` 时才需要，并与 [GlobalPropsProvider](GlobalPropsProvider.mdx) 一起使用；在默认的 `'reactive'` 模式下，它会直接用 `lynx.__globalProps` 调用 `children`，更新通过整体重新渲染生效。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `props` | `ConsumerProps` |

## 返回

`ReactNode`
