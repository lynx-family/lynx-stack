# 函数: InitDataProvider()

```ts
function InitDataProvider(props: object): ReactNode | Promise<ReactNode>;
```

提供 `initData` 的 [Provider](https://react.dev/reference/react/createContext#provider) 组件，
需要把 JSX 包裹在它里面

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `props` | \{ `children?`: `ReactNode`; \} |
| `props.children?` | `ReactNode` |

## 返回

`ReactNode` \| `Promise`\<`ReactNode`\>

## 示例

```ts
import { root } from "@lynx-js/react"

function App() {
  return (
    <InitDataConsumer children={(initData) => <view>...</view>}/>
  )
}

root.render(
  <InitDataProvider>
     <App/>
  </InitDataProvider>
);

```
