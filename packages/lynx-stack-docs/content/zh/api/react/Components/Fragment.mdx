# 函数: Fragment()

```ts
function Fragment(props: FragmentProps): ReactNode;
```

让你在不使用包装节点的情况下对元素进行分组。

## 参数

| 参数 | 类型 |
| ------ | ------ |
| `props` | `FragmentProps` |

## 返回

`ReactNode`

## 参阅

[React Docs](https://react.dev/reference/react/Fragment)

## 示例

```tsx
import { Fragment } from '@lynx-js/react';

<Fragment>
  <text>Hello</text>
  <text>World</text>
</Fragment>
```

```tsx
// Using the <></> shorthand syntax:

<>
  <text>Hello</text>
  <text>World</text>
</>
```
