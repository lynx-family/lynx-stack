# Global Events

ReactLynx 提供了一系列全局事件，让开发者可以监听并响应应用级别的状态变化。你可以使用 [useLynxGlobalEventListener](../Hooks/useLynxGlobalEventListener.mdx) Hook，在组件中轻松订阅这些事件。

## onGlobalPropsChanged

当 [`lynx.__globalProps`](https://lynxjs.org/api/lynx-api/lynx/lynx-global-props) 对象发生变化时，会触发 `onGlobalPropsChanged` 事件，随后自动重新渲染整个页面。
这对于需要响应全局配置变化（如主题、语言等）的组件很有用。

因此，`onGlobalPropsChanged` 主要用于处理**与 UI 渲染没有直接关系**的副作用，例如数据获取。

该事件的回调函数不接收任何参数；你可以直接从 [`lynx.__globalProps`](https://lynxjs.org/api/lynx-api/lynx/lynx-global-props) 读取最新状态。

```tsx
import { useLynxGlobalEventListener } from '@lynx-js/react';

function App() {
  useLynxGlobalEventListener('onGlobalPropsChanged', () => {
    console.log('Global props changed:', lynx.__globalProps);
    // You can perform data fetching or other operations here
  });

  return <view>...</view>;
}
```

## onDataChanged

当客户端更新 [initData](../Hooks/useInitData.mdx) 时，会触发 `onDataChanged` 事件。

[useInitData](../Hooks/useInitData.mdx) 是一个响应式 Hook，当 `initData` 发生变化时会自动触发组件重新渲染。
`onDataChanged` 事件主要用于处理**与 UI 渲染不直接相关**的副作用，例如日志记录、数据分析或执行其他命令式操作。

```tsx
import { useLynxGlobalEventListener } from '@lynx-js/react';

function DataChangeLogger() {
  useLynxGlobalEventListener('onDataChanged', (data) => {
    console.log('initData changed:', data);
    // You can perform data reporting or other operations here
  });

  return <view>...</view>;
}
```
