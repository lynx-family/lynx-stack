# environments

```ts
optional environments?: Record<string, EnvironmentConfig>;
```

**`Lynx Default Changed`**

[Config.environments](/zh/api/packages/rspeedy/interfaces/Config.mdx#environments) 选项用于设置输出的 environment。

## 默认值

未设置该选项时，Rspeedy 会向 Rsbuild 传入 `{ lynx: {} }`。

## 备注

如果你没有使用 Lynx for Web，通常不需要此选项。

## 示例

- 为 Lynx 和 Web 使用不同的入口。

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  environments: {
    lynx: {},
    web: {
      source: { entry: { web: './src/index.web.jsx' } },
    },
  },
  source: {
    entry: './src/index.jsx',
  },
})
```

- 仅构建 Web 产物。

```ts
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  environments: {
    web: {
      source: { entry: { web: './src/index.web.jsx' } },
    },
  },
})
```
