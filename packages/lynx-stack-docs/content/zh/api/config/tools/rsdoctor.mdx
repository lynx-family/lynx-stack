# tools.rsdoctor

```ts
optional rsdoctor?: RsdoctorRspackPluginOptions;
```



[Tools.rsdoctor](/zh/api/packages/rspeedy/interfaces/Tools.mdx#rsdoctor) 用于控制 [Rsdoctor](https://rsdoctor.dev/) 的选项。

## 默认值

```ts
undefined
```

## 备注

设置 `RSDOCTOR=true` 可启用 Rsdoctor。启用后，Rspeedy 会在配置规范化阶段合并额外的插件默认配置。

## 示例

- 使用内置的 Rsdoctor。

```js
import { defineConfig } from '@lynx-js/rspeedy'

export default defineConfig({
  tools: {
    rsdoctor: {
      disableClientServer: true,
    },
  },
})
```

详见 [Rsdoctor - Configuration](https://rsdoctor.dev/config/options/options)。
