# output.sourceMap

```ts
optional sourceMap?: 
  | boolean
  | SourceMap;
```

**`Lynx Default Changed`**

[SourceMap](/zh/api/packages/rspeedy/interfaces/SourceMap.mdx) 用于配置是否为产物生成 source map，以及如何生成。

## 默认值

在 Lynx 构建中未设置该选项时，JavaScript source map 在开发环境使用 `'cheap-module-source-map'`，在生产环境使用 `'source-map'`；同时也会生成 CSS source map。所有 `.map` 资源都会在输出前被移除。
