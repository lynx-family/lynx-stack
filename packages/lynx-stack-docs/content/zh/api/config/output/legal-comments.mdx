# output.legalComments

```ts
optional legalComments?: "none" | "inline" | "linked";
```

**`Lynx Default Changed`**

[Output.legalComments](/zh/api/packages/rspeedy/interfaces/Output.mdx#legalcomments) 用于控制如何处理法律注释（legal comment）。

## 默认值

`'none'`

## 备注

这与 Rsbuild 不同，因为我们通常不希望 Lynx 产物中出现 `.LEGAL.txt` 文件。

可以通过以下选项之一配置该行为：

- `linked`：将所有法律注释提取到 `.LEGAL.txt` 文件中，并通过注释链接到该文件。

- `inline`：将所有法律注释保留在原位置。

- `none`：移除所有法律注释。
