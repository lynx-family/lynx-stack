# 配置概览

用于构建 Lynx 应用的选项，可在 `rsbuild.config.ts` 中配合 Rsbuild 与 `pluginLynx` 使用，也可在 `lynx.config.ts` 中配合 Rspeedy 使用。

import { OverviewGroup } from '@rspress/core/theme';

## Lynx

[`pluginLynx`](/api/packages/rsbuild-plugin) 为 Lynx bundle 添加的选项。使用 Rsbuild 时，将它们传给 `pluginLynx()`；使用 Rspeedy 时，在 `lynx.config.ts` 中设置。
