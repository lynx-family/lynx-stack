# Function: GlobalPropsConsumer()

```ts
function GlobalPropsConsumer(props: ConsumerProps): ReactNode;
```

The [Consumer](https://react.dev/reference/react/createContext#consumer) Component that provide `lynx.__globalProps`.
Only needed with `globalPropsMode: 'event'`, together with [GlobalPropsProvider](GlobalPropsProvider.mdx); in the default `'reactive'` mode
it calls `children` with `lynx.__globalProps` directly and updates come from a full re-render.

## Parameters

| Parameter | Type |
| ------ | ------ |
| `props` | `ConsumerProps` |

## Returns

`ReactNode`
