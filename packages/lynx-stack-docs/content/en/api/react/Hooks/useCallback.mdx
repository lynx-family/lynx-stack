# Function: useCallback()

```ts
function useCallback<T extends Function>(callback: T, deps: DependencyList): T;
```

`useCallback` will return a memoized version of the callback that only changes if one of the `inputs`
has changed.

## Type Parameters

| Type Parameter |
| ------ |
| `T` *extends* `Function` |

## Parameters

| Parameter | Type |
| ------ | ------ |
| `callback` | `T` |
| `deps` | `DependencyList` |

## Returns

`T`

## Version

16.8.0
