# Function: render()

```ts
function render<Q extends Queries = typeof queries>(ui: ReactNode, options?: RenderOptions<Q>): RenderResult<Q>;
```

Render into the page. It should be used with cleanup.

## Type Parameters

| Type Parameter | Default type |
| ------ | ------ |
| `Q` *extends* [`Queries`](../Interfaces/Queries.mdx) | *typeof* [`queries`](../Namespaces/queries.mdx) |

## Parameters

| Parameter | Type |
| ------ | ------ |
| `ui` | `ReactNode` |
| `options?` | [`RenderOptions`](../Interfaces/RenderOptions.mdx)\<`Q`\> |

## Returns

[`RenderResult`](../Type_Aliases/RenderResult.mdx)\<`Q`\>

## Example

```ts
import { render} from '@lynx-js/react/testing-library'

const WrapperComponent = ({ children }) => (
    <view data-testid='wrapper'>{children}</view>
);
const Comp = () => {
  return <view data-testid='inner' style="background-color: yellow;" />;
};
const { container, getByTestId } = render(<Comp />, {
  wrapper: WrapperComponent,
});
expect(getByTestId('wrapper')).toBeInTheDocument();
expect(container.firstChild).toMatchInlineSnapshot(`
  <view
    data-testid="wrapper"
  >
    <view
      data-testid="inner"
      style="background-color: yellow;"
    />
  </view>
`);
```
