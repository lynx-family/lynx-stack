# Function: format()

```ts
function format(val: unknown, options?: PrettyFormatOptions): string;
```

Returns a presentation string of your `val` object

## Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `val` | `unknown` | any potential JavaScript object |
| `options?` | [`PrettyFormatOptions`](../Interfaces/prettyFormat.PrettyFormatOptions.mdx) | Custom settings |

## Returns

`string`
