# Interface: Options

Options for the Lynx Config rsbuild plugin.

## Properties

### compilerOptionsKeys?

```ts
optional compilerOptionsKeys?: string[];
```

The keys of compiler options to set.

***

### configKeys?

```ts
optional configKeys?: string[];
```

The keys of config options to set.

***

### dslPluginName2PkgName?

```ts
optional dslPluginName2PkgName?: Record<string, string>;
```

A map from DSL plugin name to its package name.

#### Example

```ts
{
  'lynx:react': '@lynx-js/react-rsbuild-plugin',
}
```

***

### upgradeRspeedyLink?

```ts
optional upgradeRspeedyLink?: string;
```

The link to upgrade Rspeedy.

***

### validate?

```ts
optional validate?: (input: unknown) => Config;
```

Custom validation function for the Lynx config.

#### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `input` | `unknown` | The input to validate. |

#### Returns

[`Config`](Config.mdx)

The validated Lynx config.
