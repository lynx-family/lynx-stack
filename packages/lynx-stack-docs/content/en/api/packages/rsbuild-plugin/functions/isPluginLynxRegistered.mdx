# Function: isPluginLynxRegistered()

```ts
function isPluginLynxRegistered(host: object, environments: string[]): boolean;
```

Whether the Lynx build engine is already registered.

## Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `host` | \{ `isPluginExists`: `boolean`; \} | The Rsbuild instance or plugin API to look it up on. |
| `host.isPluginExists` | - |
| `environments` | `string`[] | The names of the configured environments. |

## Returns

`boolean`

## Remarks

The engine is a global one. `isPluginExists` without an environment only
reports the global plugins, so it misses an engine a caller — `rslib`, for
one — registered on an environment instead.
