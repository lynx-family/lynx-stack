# Interface: LoaderOptions

The options of CSS extract loader.

## Properties

### emit?

```ts
optional emit?: boolean;
```

The same as [mini-css-extract-plugin](https://github.com/webpack-contrib/mini-css-extract-plugin/tree/master?tab=readme-ov-file#emit).
Control whether emit the CSS to filesystem.

- If `true`(default), emits a file (writes a file to the filesystem).

- If `false`, the plugin will extract the CSS but will not emit the file.

It is often useful to disable this option for server-side packages.

#### Default Value

```ts
true
@public
```

***

### esModule?

```ts
optional esModule?: boolean;
```

The same as [https://github.com/webpack-contrib/mini-css-extract-plugin#esModule](https://github.com/webpack-contrib/mini-css-extract-plugin#esModule).
By default, `@lynx-js/css-extract-webpack-plugin` generates JS modules that use the ES modules syntax.
There are some cases in which using ES modules is beneficial,
like in the case of module concatenation and tree shaking.

***

### layer?

```ts
optional layer?: string;
```

The layer of the CSS execution.

#### Remarks

This should be combined with `experiments.layers`.
