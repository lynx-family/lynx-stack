# Interface: FlingGestureConfig

Configuration interface for FlingGesture.
Fling gesture recognizes fling (swipe) gestures.

## Extends

- [`BaseGestureConfig`](BaseGestureConfig.mdx)

## Indexable

```ts
[key: string]: unknown
```

## Properties

### direction?

```ts
optional direction?: "up" | "down" | "left" | "right";
```

Direction of the fling gesture

***

### enabled?

```ts
optional enabled?: boolean;
```

Whether the gesture is enabled. Defaults to true.

#### Inherited from

[`BaseGestureConfig`](BaseGestureConfig.mdx).[`enabled`](BaseGestureConfig.mdx#enabled)

***

### numberOfPointers?

```ts
optional numberOfPointers?: number;
```

Number of pointers (fingers) required. Defaults to 1.
