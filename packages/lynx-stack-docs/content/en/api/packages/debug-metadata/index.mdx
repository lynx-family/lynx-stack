# Module: @lynx-js/debug-metadata

[npm](https://www.npmjs.com/package/@lynx-js/debug-metadata) · [Source](https://github.com/lynx-family/lynx-stack/tree/main/packages/tools/debug-metadata) · [Changelog](https://github.com/lynx-family/lynx-stack/blob/main/packages/tools/debug-metadata/CHANGELOG.md)

Schema types for the Lynx `debug-metadata.json` format.

Zero runtime dependencies. Safe to consume from any Node.js context —
rsbuild plugins, dev-server middleware, reverse-symbolication services,
CLI tools, etc. Read the JSON with `JSON.parse` and cast to
[DebugMetadataAsset](interfaces/DebugMetadataAsset.mdx); for field-by-field lookups (`?field=…`
style queries), use the `FIELDS` registry and `resolveField`
dispatcher.
