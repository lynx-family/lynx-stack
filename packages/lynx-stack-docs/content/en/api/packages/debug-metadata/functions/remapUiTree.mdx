# Function: remapUiTree()

```ts
function remapUiTree(root: UiNode, loadMetadata: DebugMetadataLoader): Promise<RemappedUiNode>;
```

Reverse-resolve a UI node tree dumped by the Lynx engine.

Every node carrying both a `nodeIndex` and a `debugMetadataUrl` whose
`uiSourceMap` knows that index is annotated with [UiSourceLocation](../interfaces/UiSourceLocation.mdx)
fields (`repo`, `source`, `line`, `column`). All other fields — and nodes
that cannot be resolved — pass through verbatim. The input is not
mutated; a new tree is returned.

## Parameters

| Parameter | Type |
| ------ | ------ |
| `root` | [`UiNode`](../interfaces/UiNode.mdx) |
| `loadMetadata` | [`DebugMetadataLoader`](../type-aliases/DebugMetadataLoader.mdx) |

## Returns

`Promise`\<[`RemappedUiNode`](../interfaces/RemappedUiNode.mdx)\>
