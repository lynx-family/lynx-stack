# Function: buildUiSourceMapLookup()

```ts
function buildUiSourceMapLookup(uiSourceMap: UiSourceMapData): Map<number, Omit<UiSourceLocation, "repo">>;
```

Build a `nodeIndex -> {source, line, column}` lookup from a
[UiSourceMapData](../interfaces/UiSourceMapData.mdx). The payload is column-oriented: `uiMaps[i]`
is the nodeIndex, and the matching `mappings[i]` entry holds
`[sourceIndex, line, column]`, with `sourceIndex` indexing `sources`.

## Parameters

| Parameter | Type |
| ------ | ------ |
| `uiSourceMap` | [`UiSourceMapData`](../interfaces/UiSourceMapData.mdx) |

## Returns

`Map`\<`number`, `Omit`\<[`UiSourceLocation`](../interfaces/UiSourceLocation.mdx), `"repo"`\>\>
