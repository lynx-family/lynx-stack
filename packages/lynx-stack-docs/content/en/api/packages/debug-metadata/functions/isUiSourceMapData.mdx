# Function: isUiSourceMapData()

```ts
function isUiSourceMapData(value: unknown): value is UiSourceMapData;
```

Runtime check that a parsed value matches [UiSourceMapData](../interfaces/UiSourceMapData.mdx)'s
load-bearing shape — an object with `sources`, `mappings` and `uiMaps`
arrays. Guards against `debugMetadataUrl`s that resolve to JSON of a
different (or older) format.

## Parameters

| Parameter | Type |
| ------ | ------ |
| `value` | `unknown` |

## Returns

`value is UiSourceMapData`
