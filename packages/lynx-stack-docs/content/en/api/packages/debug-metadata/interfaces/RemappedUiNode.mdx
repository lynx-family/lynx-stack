# Interface: RemappedUiNode

A [UiNode](UiNode.mdx) after reverse-resolution. Nodes whose `nodeIndex` is
known to their `debugMetadataUrl`'s UI source map gain the
[UiSourceLocation](UiSourceLocation.mdx) fields; all others are returned verbatim.
