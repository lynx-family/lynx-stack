# Interface: SourceMapDebugSource

Source Map v3 debug data attached to a JS / CSS artifact.

## Properties

### filename

```ts
filename: string;
```

Basename of the `.map` file, e.g. `main-thread.js.map`.

***

### key

```ts
key: string;
```

Identifier that platform-side reverse symbolication uses to match
this map. Defaults to the producing chunk's hash, matching the
`release` the `__DEBUG_METADATA_RELEASE__` banner reports at runtime.

***

### kind

```ts
kind: "source-map";
```

***

### map

```ts
map: SourceMap;
```

Full Source Map v3 payload.

***

### path

```ts
path: string;
```

Bundler-relative path of the `.map` file, e.g. `.lynx/main/main-thread.js.map`.
