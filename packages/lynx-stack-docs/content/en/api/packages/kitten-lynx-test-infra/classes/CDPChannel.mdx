# Class: CDPChannel

A stateless CDP (Chrome DevTools Protocol) channel for sending commands
to a specific Lynx session.

Each `send()` call is a short-lived request/response via the `Connector`.
Channels are cached per session ID using `WeakRef` to allow reuse.

## Constructors

### Constructor

```ts
new CDPChannel(
   _connector: Connector, 
   _clientId: string, 
   _sessionId: number
): CDPChannel;
```

Constructs a new CDP Channel strictly bound to a single Lynx session.

**Note for Agents:**
Favor using `CDPChannel.from()` over manually newing up a channel, as `from()` handles
WeakRef caching to minimize memory footprint.

#### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `_connector` | `Connector` | Low-level ADB transport controller. |
| `_clientId` | `string` | Bound devtool target identification string. |
| `_sessionId` | `number` | Narrowly scoped Lynx view session ID. |

#### Returns

`CDPChannel`

## Methods

### send()

```ts
send<T extends keyof Protocol>(method: T, params: Protocol[T]["params"]): Promise<Protocol[T]["return"]>;
```

Dispatches a strongly-typed Chrome DevTools Protocol (CDP) method command and awaits its return block.

**Agent Usage:**
This is the beating heart of all interactions in `kitten-lynx`. Instead of maintaining a socket,
every `send(...)` call constructs a self-contained ADB request and awaits the isolated response.

**Typings:**
Notice that the generics strictly bind to the `Protocol` interface defined at the top of this file.
If you need to invoke a CDP command that TypeScript rejects, you must update the `Protocol` interface first!

#### Type Parameters

| Type Parameter | Description |
| ------ | ------ |
| `T` *extends* keyof `Protocol` | The literal string name of the CDP method (e.g., `'DOM.getDocument'`, `'Page.navigate'`). |

#### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `method` | `T` | The command to send to the Lynx devtool server. |
| `params` | `Protocol`\[`T`\]\[`"params"`\] | A strongly-typed payload object required by the CDP method. |

#### Returns

`Promise`\<`Protocol`\[`T`\]\[`"return"`\]\>

A promise resolving to a strongly-typed response object matching the expected return structure of the `method`.

***

### from()

```ts
static from(
   sessionId: number, 
   clientId: string, 
   connector: Connector
): CDPChannel;
```

Retrieves or instantiates a stateless `CDPChannel` for a specific Lynx session.

**Design pattern (For Agents):**
This testing library uses a **stateless** CDP architecture to avoid hanging Websocket connections
over unstable ADB links. Channels are cached per `sessionId` via `WeakRef` to reduce allocations.

#### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `sessionId` | `number` | The numeric Lynx devtool session ID assigned by the Lynx runtime. |
| `clientId` | `string` | The unique device-port identifier for the client app (e.g., `"emulator-5554:40121"`). |
| `connector` | `Connector` | The active `Connector` instance powering the ADB transport. |

#### Returns

`CDPChannel`

A `CDPChannel` reference bound to the requested session.
