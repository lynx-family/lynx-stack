# Interface: AddComponentElementConfig

Controls whether to add wrapper elements for components

## Properties

### compilerOnly

```ts
compilerOnly: boolean;
```

Whether to only add component element during compilation

#### Example

Note that this only take effects on `Component` imported from [CompatVisitorConfig.oldRuntimePkg](CompatVisitorConfig.mdx#oldruntimepkg).

```js
import { defineConfig } from '@lynx-js/rspeedy'
import { pluginReactLynx } from '@lynx-js/react-rsbuild-plugin'

export default defineConfig({
  plugins: [
    pluginReactLynx({
      compat: {
        addComponentElement: { compilerOnly: true }
      },
    })
  ],
})
```
