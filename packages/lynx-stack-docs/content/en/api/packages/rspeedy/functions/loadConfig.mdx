# Function: loadConfig()

```ts
function loadConfig(loadConfigOptions: LoadConfigOptions): Promise<LoadConfigResult>;
```

Load the build config by the config path.

## Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `loadConfigOptions` | [`LoadConfigOptions`](../interfaces/LoadConfigOptions.mdx) | the options of `loadConfig` method. |

## Returns

`Promise`\<[`LoadConfigResult`](../interfaces/LoadConfigResult.mdx)\>

Build config.

## Example

```ts
import { loadConfig } from '@lynx-js/rspeedy'

void async function () {
  const config = await loadConfig({ configPath: './lynx.config.js' })
  console.log(config);
}()
```
