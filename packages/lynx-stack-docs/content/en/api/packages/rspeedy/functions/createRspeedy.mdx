# Function: createRspeedy()

```ts
function createRspeedy(options: CreateRspeedyOptions): Promise<RspeedyInstance>;
```

The `createRspeedy` method can let you create a Rspeedy instance and you can customize the build or development process in Node.js Runtime.

## Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `options` | [`CreateRspeedyOptions`](../interfaces/CreateRspeedyOptions.mdx) | [CreateRspeedyOptions](../interfaces/CreateRspeedyOptions.mdx) |

## Returns

`Promise`\<[`RspeedyInstance`](../type-aliases/RspeedyInstance.mdx)\>

Rspeedy instance.

## Example

```ts
import { createRspeedy } from '@lynx-js/rspeedy'

void async function () {
  const rspeedy = await createRspeedy({})
  await rspeedy.build()
}()
```
