# Module: @lynx-js/rspeedy

[npm](https://www.npmjs.com/package/@lynx-js/rspeedy) · [Source](https://github.com/lynx-family/lynx-stack/tree/main/packages/rspeedy/core) · [Changelog](https://github.com/lynx-family/lynx-stack/blob/main/packages/rspeedy/core/CHANGELOG.md)

The document contains all the configurations of the `@lynx-js/rspeedy` package.

## Example

Use `lynx.config.ts` with [defineConfig](functions/defineConfig.mdx) to get better TypeScript intellisense.

```ts
import { defineConfig } from '@lynx-js/rspeedy'
export default defineConfig({
  source: { entry: './src/index.tsx' },
})
```
