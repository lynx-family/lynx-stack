# Module: @lynx-js/cache-events-webpack-plugin

[npm](https://www.npmjs.com/package/@lynx-js/cache-events-webpack-plugin) · [Source](https://github.com/lynx-family/lynx-stack/tree/main/packages/webpack/cache-events-webpack-plugin) · [Changelog](https://github.com/lynx-family/lynx-stack/blob/main/packages/webpack/cache-events-webpack-plugin/CHANGELOG.md)

A webpack plugin that caches Lynx native calls that arrive before an entry finishes starting up — on the background thread, and on the main thread for entries that start up asynchronously — and replays them once startup settles.
