# Interface: ExternalBundleLibConfig

Rslib config shape accepted by `defineExternalBundleRslibConfig`.

## Extends

- `LibConfig`

## Properties

### autoExtension?

```ts
optional autoExtension?: boolean;
```

Whether to automatically set the file extension based on [format](#format) option in the JavaScript output files.

#### Default Value

`true`

#### See

[https://rslib.rs/config/lib/auto-extension](https://rslib.rs/config/lib/auto-extension)

#### Inherited from

```ts
LibConfig.autoExtension
```

***

### ~~autoExternal?~~

```ts
optional autoExternal?: AutoExternal;
```

Whether to automatically externalize dependencies of different dependency types and do not bundle them.

#### Deprecated

Use `output.autoExternal` instead.

#### Default Value

`true` when [format](#format) is `cjs` or `esm`, `false` when [format](#format) is `umd` or `mf`.

#### See

[https://rslib.rs/config/lib/auto-external](https://rslib.rs/config/lib/auto-external)

#### Inherited from

```ts
LibConfig.autoExternal
```

### shims?

```ts
optional shims?: Shims;
```

Configure the shims for CommonJS and ESM output.

#### Default Value

```js
const defaultShims = {
  cjs: {
    'import.meta.url': true,
    'import.meta.dirname': true,
    'import.meta.filename': true,
  },
  esm: {
    __filename: false,
    __dirname: false,
    require: false,
  },
};
```

#### See

[https://rslib.rs/config/lib/shims](https://rslib.rs/config/lib/shims)

### wasm?

```ts
optional wasm?: Wasm;
```

Configure how Rslib handles `.wasm` modules.

This option can only be configured when `format` is `'esm'`.

#### Default Value

`{ mode: 'compile' }` when `bundle` is `true`; `{ mode: 'preserve' }` when `bundle` is `false`.

#### See

[https://rslib.rs/config/lib/wasm](https://rslib.rs/config/lib/wasm)

#### Inherited from

```ts
LibConfig.wasm
```
