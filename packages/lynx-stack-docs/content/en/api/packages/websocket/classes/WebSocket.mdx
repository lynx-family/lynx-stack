# Class: WebSocket

The implementation of [WebSocket](https://developer.mozilla.org/en-US/docs/Web/API/WebSocket)
for Lynx.

## Remarks

This only works in environment that has `NativeModules.LynxWebSocketModule`.

## Constructors

### Constructor

```ts
new WebSocket(
   url: string, 
   protocols?: string | string[], 
   options?: object
): WebSocket;
```

#### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `url` | `string` | The URL to which to connect; this should be the URL to which the WebSocket server will respond. |
| `protocols?` | `string` \| `string`[] | Either a single protocol string or an array of protocol strings. If it is omitted, an empty array is used by default, i.e. `[]`. |
| `options?` | \{ `headers?`: `Record`\<`string`, `string`\>; \} | Extra options for Lynx only. |
| `options.headers?` | `Record`\<`string`, `string`\> | - |

#### Returns

`WebSocket`

## Properties

### CLOSED

```ts
static CLOSED: ReadyState = ReadyState.CLOSED;
```

The connection is closed or couldn't be opened.

***

### CLOSING

```ts
static CLOSING: ReadyState = ReadyState.CLOSING;
```

The connection is in the process of closing.

***

### CONNECTING

```ts
static CONNECTING: ReadyState = ReadyState.CONNECTING;
```

Socket has been created. The connection is not yet open.

***

### OPEN

```ts
static OPEN: ReadyState = ReadyState.OPEN;
```

The connection is open and ready to communicate.

### protocol

#### Get Signature

```ts
get protocol(): string | undefined;
```

The WebSocket.protocol read-only property returns the name of the sub-protocol the server selected.

##### Remarks

This will be one of the strings specified in the protocols parameter when creating the WebSocket object,
or `undefined` until the connection is open.

##### Returns

`string` \| `undefined`

## Methods

### addEventListener()

```ts
addEventListener<T extends keyof EventMap>(type: T, callback?: (event: EventMap[T]) => void): void;
```

The `addEventListener()` method of the `EventTarget` interface sets up a function that will be called whenever the specified event is delivered to the target.

#### Type Parameters

| Type Parameter |
| ------ |
| `T` *extends* keyof [`EventMap`](../type-aliases/EventMap.mdx) |

#### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `type` | `T` | A case-sensitive string representing the event type to listen for. |
| `callback?` | (`event`: [`EventMap`](../type-aliases/EventMap.mdx)\[`T`\]) => `void` | The function that receives a notification. See [@lynx-js/websocket!EventMap](../type-aliases/EventMap.mdx) for details of events. |

#### Returns

`void`

***

### close()

```ts
close(code?: number, reason?: string): void;
```

The `close()` method closes the WebSocket connection or connection attempt, if any.

#### Parameters

| Parameter | Type |
| ------ | ------ |
| `code?` | `number` |
| `reason?` | `string` |

#### Returns

`void`

#### Remarks

If the connection is already [CLOSED](#closed), this method does nothing.

***

### ping()

```ts
ping(): void;
```

The `ping` method send an empty message to the server over the WebSocket connection.

#### Returns

`void`

#### Remarks

It will throw an exception if you call `ping()` when the connection is in the [CONNECTING](#connecting) state. If you call `ping()` when the connection is in the [CLOSING](#closing) or [CLOSED](#closed) states, it will silently discard the data.

***

### send()

```ts
send(data: string): void;
```

The `send` method send the specified data to be transmitted to the server over the WebSocket connection.

#### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `data` | `string` | The specified data to be transmitted. |

#### Returns

`void`

#### Remarks

It will throw an exception if you call `send()` when the connection is in the [CONNECTING](#connecting) state. If you call `send()` when the connection is in the [CLOSING](#closing) or [CLOSED](#closed) states, it will silently discard the data.
