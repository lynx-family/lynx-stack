# Type Alias: EventMap

```ts
type EventMap = object;
```

The `EventMap` describe the events that [@lynx-js/websocket!WebSocket](../classes/WebSocket.mdx) may fire.

## Properties

### close

```ts
close: Event<"close"> & object;
```

The `close` event is fired when a connection with a [@lynx-js/websocket!WebSocket](../classes/WebSocket.mdx) is closed.

##### code

```ts
readonly code: number;
```

##### reason


### error

```ts
error: Event<"error"> & object;
```

The `error` event is fired when a connection with a [@lynx-js/websocket!WebSocket](../classes/WebSocket.mdx) has been closed due to an error (some data couldn't be sent for example).

#### Type Declaration

##### message

```ts
readonly message: string;
```

### message

```ts
message: Event<"message"> & object;
```

The `message` event is fired when data is received through a [@lynx-js/websocket!WebSocket](../classes/WebSocket.mdx).

#### Type Declaration

##### data

```ts
readonly data: string;
```

***

### open

```ts
open: Event<"open">;
```

The `open` event is fired when a connection with a [@lynx-js/websocket!WebSocket](../classes/WebSocket.mdx) is opened.
