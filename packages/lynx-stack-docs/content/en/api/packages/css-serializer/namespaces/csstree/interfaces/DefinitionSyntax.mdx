## Methods

### generate()

```ts
generate(node: DSNode, options?: 
  | DSGenerateDecorateFn
  | DSGenerateOptions): string;
```

Generates CSS value definition syntax from an AST

#### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `node` | [`DSNode`](../type-aliases/DSNode.mdx) | The AST |
| `options?` | \| [`DSGenerateDecorateFn`](../type-aliases/DSGenerateDecorateFn.mdx) \| [`DSGenerateOptions`](DSGenerateOptions.mdx) | Options that affect generation |

#### Returns

`string`

#### Example

```ts
generate({type: 'Keyword', name: 'foo'}) => 'foo'
```

### parse()

```ts
parse(source: string): DSNodeGroup;
```

Generates an AST from a CSS value syntax

#### Parameters

| Parameter | Type | Description |
| ------ | ------ | ------ |
| `source` | `string` | The CSS value syntax to parse |

#### Returns

[`DSNodeGroup`](DSNodeGroup.mdx)

#### Example

```ts
parse('foo | bar') =>
   {
     type: 'Group',
     terms: [
       { type: 'Keyword', name: 'foo' },
       { type: 'Keyword', name: 'bar' }
     ],
     combinator: '|',
     disallowEmpty: false,
     explicit: false
   }
```
