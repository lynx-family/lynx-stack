# Interface: CreateOpenUiPromptLibraryOptions

Options for creating the headless OpenUI prompt library.

## Extended by

- [`BuildOpenUiSystemPromptOptions`](BuildOpenUiSystemPromptOptions.mdx)

## Properties

### componentGroups?

```ts
optional componentGroups?: ComponentGroup[];
```

Replace or extend the built-in component groups.

***

### componentNames?

```ts
optional componentNames?: readonly string[];
```

Limit built-ins to these names. Custom `components` are still appended.

***

### components?

```ts
optional components?: OpenUiPromptComponent[];
```

Replace or extend the built-in component set.

***

### root?

```ts
optional root?: string;
```

Override the root component name. Defaults to `'Stack'`.
