# Function: useGetFieldValue()

```ts
function useGetFieldValue(): (formName: string | undefined, name: string) => any;
```

Get a form field value from the form state context.

## Returns

(`formName`: `string` \| `undefined`, `name`: `string`) => `any`

## Example

```tsx
const getFieldValue = useGetFieldValue();
const name = getFieldValue("contactForm", "name");
```
